# 写作规范

> **提案稿**：POV、章数等条目以 `docs/07` 的最终决策为准；确认后回来改这一行。
> 声纹与样例见 `docs/09-声音与节奏.md`；canon/AU 见 `docs/05`。

## 一、叙述

- **人称**：第三人称限知，过去时。**每章一个 POV**（方案见 D3）；只写这个人能感知、能推断的东西。
- **限知边界**：POV 不在场的事不写；不写「其实纳西妲早就知道……」；不用上帝视角解释规则。写作包里必须写清「本章这个人看不到什么」。
- **两个世界互相不可解释**：提瓦特 的人看プリパラ，只会说「像……」；プリパラ 的人看提瓦特，只会说「这是新舞台吗」。**永远不出现「其实那是同一个世界」的旁白。**
- **文笔**：优美、偏诗意，允许文绉绉；但美来自准确的细节和节奏，不来自形容词。一段只做一件事。
- **引号**：正文对白与引语一律用普通“”，不用「」。文档里的术语强调可以保留「」。
- **短插曲**：允许用「***」隔开的短插曲（另一边的动静、观众席、羊），每章合计不超过 1/4；插曲只给限知，不解释全部。
- **数字**：日期、时间、较大的确切数量用阿拉伯数字；固定搭配（一下、两下、三件事）用汉字；同一段不混排。
- **不说脏话**：急的时候用贫嘴、叹气、动作。

## 二、章节结构

- 每章 8,000–16,000 字，写作目标，不是验收指标；章节完整优先，初稿后不为字数回头删改。
- 开头尽快进场景，不用大段 recap；用物品、天气、称呼、伤口唤起前情。
- 场景之间用空行或「***」，不写「与此同时」。
- 每章至少：
  - 一个推进关系的场景；
  - 一个推进「门/时间」的场景（这一夜在流逝）；
  - 一个「只有这个角色才会做」的细节；
  - 一个感官锚点（气味/温度/声音）。
- 结尾留钩子，但不靠「突然」。

## 三、对白

- 每句对白至少有一个功能：推进、暴露性格、制造冲突、给信息。
- 不用对白解释设定；让角色说人话，设定通过冲突与动作露出。
- **语言规则**（D12）：场内（舞台/プリパラ 领域）自动通意；场外不通。不通的时候用：手势、画画、唱歌、指东西、纳西妲的梦桥。**「听不懂」本身要有戏**，不要一笔带过。
- **日/法原词**：每章不超过 3 处，且必须让不懂的读者也能读懂语境。`まほちゃん` 的处理见 D10。
- 角色的口头禅是盐，不是主菜：每章每人最多 1–2 次。

## 四、术语

### 4.1 プリパラ 侧

| 中文 | 说明 |

| プリチケ | プリ券；入场与身份的凭证 |
| パキる | 刷卡（把プリチケ 在读卡器上刷过） |
| コーデ | 服装/整套造型 |
| メイキングドラマ | 演出小剧场（不是「过场动画」） |
| 応援棒（サイリウム） | 会随演出变色的荧光棒 |
| ボーカルドール | 歌偶；由心愿凝成的偶像存在 |
| バグ | 系统判定；只作为プリパラ 的用语出现，不写成电脑报错 |
| プリパリ | 巴黎对应的プリパラ |
| パルプス | 芙羽梨的故乡（阿尔卑斯对应） |

### 4.2 提瓦特 侧

死域、蕈兽、神之眼、净善宫、教令院、大巴扎、祖拜尔剧场、甘露花海、万种母树、伽乌迦那、花灵、灵光、灵光绝唱、慈心、染境、祭水之仪、离渡之仪、焚真之天象、厄歌莉娅、甘露、帕蒂沙兰。

### 4.3 不要写

- 系统面板、等级、HP、伤害数字、抽卡、命座、圣遗物、好感度。
- 「叮」「宿主」「任务奖励」「系统提示」。
- プリパラ 的界面写成 UI（不要写「屏幕上弹出……」）。
- 角色知道自己是作品角色。
- 「語尾」这个日文概念（中文改成「某种拖长音的撒娇腔」）。

## 五、描写

- **感官优先**：每场至少两个感官；先身体，后情绪。
- **舞台**：写灯的温度、地板的震、汗、观众的呼吸、应援棒由蓝变白的那一秒；**不写特效名词**。
- **花灵**：写重量（几乎没有）、温度（比空气凉一点）、光的质感（像露水里的太阳）；不写「她飘着，很可爱」。
- **ボーカルドール**：写法露露的实体化——写她「淡下去」的瞬间：边缘先透明，声音先远。
- **羊**：写毛的油、蹄子踩石头的响、铃铛。羊是家人，不是背景。
- **情绪**：用动作、物品、停顿；关键处可以短句直给。

## 六、节奏

- 一章至少一次「呼吸」：挤奶、煮茶、走路、看花、烤火。
- 高能之后给一个短场景收情绪，不要立刻切下一个大事件。
- 时间用相对标记：「演出前三天」「那一夜」「天亮之前」「花期的最后几天」。**两边都不写月份、季节、公元年。**
- **初稿后先做剧情逻辑核实**：因果、动机、信息状态、时间、伤势、承诺、道具；逻辑断裂先改结构，不先润色。
- **防漂移（定性）**：不比较段落平均长度、对话比例。觉得不像时，读 `docs/09` 的样例，重写开头 500 字。

## 七、内容分级

- **PG-13**：牵手、拥抱、额头碰额头、告白、贴很近但不做什么。
- **多边关系**：写知情、同意、边界、日常；不猎奇、不当噱头、不写「谁才是真爱」。
- **芙羽梨 × 法露露**：是亲密的闺蜜，不是情敌；不写雌竞。
- **纳西妲**：500 岁心智、神性、成人情感；不幼态化、不性化。
- **帕丽莎**：花灵，非人类非人形；不写人类婴儿的生理细节；她与花的婚姻是名分与爱情，不写性。
- **法露露**：不是人类女孩，不写她的身体细节；她的「情人」身份是词的浪漫，不是性。
- **暴力**：可以有疼、怕、血；不猎奇。
- **死亡**：不美化；不写「死了更好」。

## 八、Canon 的处理

- 读者默认熟悉两边原作：**不复述**。祭水之仪、Tricolore 的演出、4.2 审判、神偶像 GP，都用跳跃＋侧写，只写主观体验与关系增量。
- 两边的大事结果不改；改的是缝隙里的关系与这一夜的例外。
- 不写「原作角色长大后必然如此」的旁白认证；婚后生活是设定，不是论证。
- 出现原作角色时，先问一句：**这个人在 canon 里会不会这么说？** 不会，就改。

## 十、上下文管理

- **每章一个新会话**；不在一个会话里连续写多章。
- **固定配方**：`AGENTS.md` → `docs/09` → `docs/08-章节写作包/chXX.md` → `docs/10` 的事实账本 → 本章 1–2 个 canon 片段（≤500 字）。
- **不要加载**：上一章全文、整份大纲、整份 `05`、之前的对话历史。
- 写完一章更新 `docs/10`：事实账本、下一章钩子、已改设定；不贴正文。
