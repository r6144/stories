# 章节写作包

> 每章一份「开写前必读」的紧凑上下文。目标：每份 3k–4k 字，**章章等长、同序**。不靠指标锚定风格，靠固定上下文 + 声音锚点。
>
> **写作包是派生文档，不是事实来源。** 时间以 `docs/01` 为准，人物/信息状态以 `docs/03` 为准，规则以 `docs/04` 为准，canon/AU 以 `docs/05` 为准，决策以 `docs/07` 为准。写作包里的复述只为了「本章开写方便」；发现冲突，回到来源改，不要只改写作包。

## 用法

- 新会话写第 X 章时，只加载：`AGENTS.md` + `docs/09-声音与节奏.md` + `docs/08-章节写作包/chXX.md` + `docs/10` 的事实账本（300–500 字）。
- **不要**加载上一章全文、整份大纲、整份 `05-官设考据.md`、之前的对话历史。上一章的句子会把手感带偏。
- 写作包不是大纲的复制；它只包含**这一章**需要的：时间、地点、在场人物、POV、目标、beat、声音、canon、信息状态、不能写什么、结尾钩子。
- 写完一章后，更新 `docs/10-进度与决策.md` 的「事实账本」，再写下一章的写作包；不要把正文贴进账本。

## 本项目的特殊要求

- **每章一个 POV**：写作包必须写清本章是谁的眼睛，以及这个人**看不到什么**（限知边界）。
- **语言状态**：本章的对话是在「场内（自动通意）」还是「场外（不通）」；不通的时候怎么写（手势、画画、唱歌、纳西妲的梦桥）。
- **两边的时间**：本章属于哪一侧、离「那一夜」还有多久。
- **门的规则**：本章门是关着、开着、还是在关。
- **两个孩子的状态**：法露露离プリパラ 多久、帕丽莎离甘露多久（越久越淡）。

## 模板

```markdown
# chXX 标题

## 开写前一句话
## 上一章事实账本（300–500 字，不贴原文）
## 时间 / 地点 / POV（谁的眼睛；这个人看不到什么）
## 语言状态（场内通意 / 场外不通）
## 门的规则（关 / 开 / 正在关）
## 本章目标（3–5 条）
## 场景 beat
## 人物声音（只列本章出场）
## 声音锚点（1 页：原则 + 1 段叙述样例 + 1 段对白样例）
## Canon 锚点（只列本章用到的）
## 信息状态（谁知道什么；谁不知道什么）
## 不能写什么
## 开头选项 / 结尾钩子
## 引号与格式（正文用“”，不用「」）
## 需要时再核对
```
