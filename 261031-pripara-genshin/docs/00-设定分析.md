# 设定分析

> 派生文档。canon 事实以 `docs/05-官设考据.md` 为准，决策以 `docs/07-待确认问题.md` 为准。
> 本文只回答四个问题：这本书写什么、为什么这两个人像兄妹、两组 cp 怎么咬合、跨界怎么才不廉价。

## 〇、一句话

两边都结婚几个月之后，一场演出把两个「靠表演活下来的人」放到了同一个后台。

## 一、这本书要写的到底是什么

不是「两个喜欢的作品联动」，是**一个命题的两次证明**：

> **表演不是假的。被造出来的人，也可以是真的。**

两个世界的主角，都是「被造」的：

| 谁 | 被谁造 | 造来做什么 | 她自己的说法 |
|---|---|---|---|
| 紫京院响 | 财阀、事务所、观众 | 当「最高のプリンス」 | 「この世は舞台　人は皆役者」 |
| 芙宁娜 | 芙卡洛斯 | 当五百年的「水神」 | 「我演了五百年。……我连自己都骗过了。」 |
| 纳西妲 | 大慈树王（连名字都被抹掉了） | 当草神 | 「我是从一棵很大的树上长出来的一枝。」 |
| 法露露 | 所有人的「想成为偶像」 | 当ボーカルドール | 「我不记得是谁想要我。我只知道有很多人想要。」 |
| 帕丽莎 | 花海（花神／树王／厄歌莉娅的三份遗产） | 没有目的 | 「我是花海送给妈妈的。」 |

对照的是两个**没被造**的人：

- **芙羽梨**：被指定为「公主候补」，她**辞退了**。她不是谁的作品。
- **妮露**：被自设成「花神继承人」，但只继承美貌与舞蹈，**没有力量、没有神谕、没有使命**。她跳舞不为任何人。

于是全书的论点可以压成一句：**不演戏的人，教会被造的人「你可以是真的」。**

这也是为什么故事的推进力不能是「危机」，而必须是「相处」——被造的人不会因为打败谁而获救，只会因为被谁**看见**而获救。

## 二、为什么这两个人像兄妹

用户的直觉（「上辈子的兄妹」）不是拉郎，是**创伤同构**。逐条对照：

| 维度 | 紫京院响 | 芙宁娜 |
|---|---|---|
| 童年 | 父母海上遇风暴被报失踪；她失势那一夜，仆人与朋友立刻离开；第二天父母生还，所有人笑着回来 | 被造出来当神，从诞生起就没有「童年」，只有角色 |
| 那一夜 | 一个人在空宅里哭了一整夜 | 一个人在沫芒宫里演了五百年 |
| 得出的结论 | 「何が友達だ、何がトモチケだ」——他们爱的是钱 | 他们爱的是「水神」，不是我 |
| 应对方式 | 剪短头发，当王子；把「演」变成职业与铠甲 | 把「演」变成救命的技术；越怕越夸张 |
| 台词 | 「この世は舞台　人は皆役者」 | 「世界不过是一幕表演，众生亦不过是舞台上的演员」（欧庇克莱歌剧院的题词） |
| 象征 | 白百合（カサブランカ）、紫、蓝、法语、红茶、骨瓷杯 | 蓝白、水、歌剧、马卡龙、审判 |
| 最怕的事 | 有人因为「她这个人」回来，而不是因为「王子」 | 有人因为「水神」爱她，而不是因为「她」 |
| 差点不做人 | 想变成ボーカルドール，永远留在プリパラ | 五百年里，她几乎已经不是人 |
| 最后的选择 | **做人**（被芙羽梨、法露露拉回来） | **做人**（卸任、变老、会死） |

- 两个人共享同一句控诉：**「他们爱的是那个角色，不是你。」**
- 两个人共享同一种病：**越被爱越要演**，因为「被爱的那个」不是自己。
- 两个人共享同一种解药：**有人在她不演的时候还留下来**。响的解药是芙羽梨（看脸的人）+ 法露露（不 judge 的人）；芙宁娜的解药是纳西妲（知道真相还爱）+ 妮露（不懂表演所以不被骗）。

**最硬的一条证据是一句台词**：响 的旗号是「この世は舞台　人は皆役者」（这世上是舞台，人皆是演员）；而枫丹的欧庇克莱歌剧院上刻着「世界不过是一幕表演，众生亦不过是舞台上的演员」。**同一句莎士比亚，隔着两个世界、两种语言。** 这比任何前世设定都更像「上辈子的兄妹」——不是她们记得，是她们**说的是同一句话**。

所以「兄妹」成立，不是因为转世，而是因为**同一种伤的两条岔路**：一个选择了「不做人」，一个选择了「做人」，最后都回到了人这边。

**写法上的处理（建议）**：不要写成真转世。让她们自己认这个亲——芙宁娜在后台半开玩笑叫一声「兄长大人」，响顿了一下，应了。全书最好的「兄妹」证据是：**她们吵架的方式像兄妹**（互相拆台、互相护短、谁也不肯先服软），而不是任何前世设定。

## 三、两组 cp 的结构，以及它们怎么咬合

### 3.1 两组关系

| | プリパラ 侧 | 提瓦特 侧 |
|---|---|---|
| 组成 | 响 × 芙羽梨（婚）＋ 法露露（情人） | 纳西妲 × 妮露 × 芙宁娜（婚） |
| 性质 | 一段婚姻 + 一段自愿的、非生理的「情人」关系 | 三人无性浪漫婚姻 |
| 张力 | 芙羽梨是「看见真的人」，法露露是「不需要真的人」 | 一位神、一位前神、一位普通人 |
| 孩子 | 羊群（白山羊与紫山羊的后代） | 帕丽莎（花灵） |
| 舞台 | 三个人仍然同台，粉丝大半是 cp 粉 | 三个人各有各的舞台：梦、舞、歌 |

### 3.2 用户的对应关系，以及我要补的一层

用户的观察：
- 纳西妲 ≈ 芙羽梨（自然）＋ 法露露（AI），三人都是绿色系；
- 妮露是舞娘，而舞蹈正是プリパラ 的核心活动。

这层对应已经很好，我在它上面加两条，用来做**结构**而不只是趣味：

1. **芙羽梨 是全篇唯一的「测谎仪」。** canon 里她的能力不是力量，是**看脸**——祖父点破她「你有没有好好看他的表情」，她因此回去找响的「本当」。所以：芙宁娜的演技对全世界有效，对芙羽梨无效。第一次见面，芙羽梨就会说一句让芙宁娜后背发凉的话（「你在笑，可是你不高兴」）。这比任何神力都好用。
2. **妮露 是全篇唯一的「不为什么而跳」的人。** 响 跳舞是工作，芙宁娜 唱歌是救命，纳西妲 的梦是职责，法露露 的舞台是存在方式。只有妮露，跳舞是因为高兴。所以她能问出全书最扎人的问题：「你唱歌的时候，高兴吗？」——这个问题对响和芙宁娜都是暴击。

### 3.3 三组镜像（写场景时用）

- **被造者 × 被造者**：纳西妲 ↔ 法露露（都不知道造自己的人是谁）；芙宁娜 ↔ 响（都靠演活着）。
- **看的人 × 被看的人**：芙羽梨 ↔ 芙宁娜（看穿）；妮露 ↔ 响（不懂表演，所以不被骗）。
- **孩子 × 孩子**：帕丽莎 ↔ 小羊（都不是人，都被爱，都只能活在某个地方）。

## 四、跨界机制：三个方案，推荐第一个

### 方案 A（推荐）：舞台之门

**规则**：两个世界在「**大量心愿集中 + 一首完整的歌 + 一次承认**」的地方短暂相接。

- プリパラ 侧完全 canon：プリパラ 本来就是「大家想成为偶像」的心愿凝成的世界；观众的心愿会变成光；2222 年前的石板プリチケ 就供在 プリパリ 的ループル 里。
- 提瓦特 侧也 canon：祭水之仪 是「水 + 灵光 + 见证」的仪式；花灵 就是灵光与甘露的孩子。
- 于是「一场在ループル 前的 Tricolore live」与「一场在万种母树里的祭水之仪」在同一刻对上——不是因为魔法，是因为**两件事在结构上是同一件事**。

**硬约束（这是这个方案的价值）**：门只开**一夜**，从第一首歌到最后一首歌。天一亮、歌一停，门就关。没有「以后常来」，没有「两个世界合并」，没有「谁留在谁那边」。

**代价**（三条，写进 `docs/04`）：
1. プリパラ 的系统会把外来者判为**バグ**（canon 先例：第 87 话响被系统拖进异空间）。
2. 提瓦特 的地脉会把外来者判为**异物**（表现为「不合季节开的花」）。
3. 两个「只能在某个地方活」的孩子——法露露（ボーカルドール，只能在プリパラ）与帕丽莎（花灵，靠甘露）——离开自己的地方就会变淡。

第 3 条是全书的心脏：**两个家庭第一次见面，就同时发现「我们的孩子都不能出门」。**

### 方案 B：蝴蝶

响 的紫色蝴蝶监视机器人穿过地脉，被纳西妲 截获。优点是轻、可爱、有 canon 道具；缺点是「一只机器人打通两个世界」太随意，撑不起长篇。

### 方案 C：梦

纳西妲 的梦境接住一段プリパラ 的信号，两边在梦里见面。优点是低成本、不需要解释物理；缺点是「梦」会削弱「舞台是真的」这个主题，而且容易写成「一觉醒来什么都没有」的廉价结局。

**结论**：用 A，把 B 当作 A 的**前兆**（蝴蝶先出现，是门要开的信号），C 只作为纳西妲 的一句判断（「这不是梦。梦没有这么重。」）。

### 语言问题（必须提前定）

プリパラ 是全世界都有分店、各国偶像同台的世界，**场内自动通意**是 canon 友好的；提瓦特 侧则没有这个方便。建议：

- **在舞台上 / 在プリパラ 的领域里**：自动听懂。
- **在舞台外（パルプス 的草甸、甘露花海）**：要靠纳西妲 的梦桥，或者手势、画画、唱歌。

这条规则一石三鸟：给了一个漂亮的限制（**只有在台上才能好好说话**）、解释了为什么高潮必须是一场演出、也让「谢幕」变成了真正的告别。

## 六、只有这篇才会有的场景（写的时候优先保）

1. **法露露 喝羊奶**。canon：她最喜欢的食物是牛奶。阿尔卑斯山上，她端着一碗刚挤的羊奶，认真地说「这个牛奶，和プリパラ 的不一样」。
2. **响 的骨瓷杯一直在裂**。canon：她受惊时杯子会裂。山上冷、海拔高、羊会撞桌子——她的杯子一天裂一个，最后她干脆用搪瓷缸，被芙羽梨笑。
3. **芙宁娜 纠正响的法语**。响 唱〈Mon chouchou〉，芙宁娜 听完说「你的法语有枫丹廷口音」；响 说「枫丹廷是什么」；两个人第一次意识到对方来自另一个「法国」。
4. **芙羽梨 一眼看穿芙宁娜**。第一次见面，芙羽梨 递给她一杯热羊奶，说「你在笑，可是你不高兴。」芙宁娜 端着杯子，半天没说出话。
5. **帕丽莎 想嫁给玛格丽特**。canon 花灵会嫁给花。她在パルプス 的草甸上看见一整片玛格丽特，当场宣布要娶它们；芙羽梨 认真地教她怎么跟花说话；纳西妲 在旁边算「这算不算重婚」。
6. **妮露 三分钟学会プリパラ 舞**。响 教她一段，她一遍就会，还加了须弥的旋转；响 破防：「你有舞台的身体。」
7. **纳西妲 问法露露「你想要什么」**。法露露 想了很久，说「我不知道。以前没有人问过。」——全书最重要的一句。
8. **响 对芙宁娜说「你演的那五百年，是真的」**。不是安慰，是判决。
9. **芙宁娜 叫响「兄长大人」**。舞台腔，半开玩笑；响 停了一拍，说「嗯」。
10. **安可**。门要关了，观众（两个世界的观众）一起喊安可；两家人返场，唱一首谁都没听过的歌。

## 七、风险与陷阱

| 风险 | 表现 | 不能写成什么 |
|---|---|---|
| 世界合并 | 「其实提瓦特是プリパラ 的一个区域」 | 两个世界各自完整；门是例外，不是通道 |
| 力量外挂 | 纳西妲 随手开传送门；芙宁娜 还能控水 | 纳西妲 只能做梦桥、不能开门；芙宁娜 只有神之眼，力量很小 |
| 萌化 | 纳西妲 写成小孩；法露露 写成宠物 | 纳西妲 500 岁、有边界；法露露 是「人」的一种，不是吉祥物 |
| cp 争宠 | 芙羽梨 吃醋、法露露 抢人、妮露 和 芙宁娜 争 | 两组关系都是知情同意的；不写雌竞、不写「谁才是真爱」 |
| 翻译糊弄 | 所有人无障碍聊天 | 场内通意、场外不通；靠纳西妲/手势/唱歌 |
| 时间线 | 两边日期混着写 | プリパラ 侧只写「第几天/演出前」，提瓦特 侧只写「第几天」；不写公元年 |
| 双 canon 期待 | 只服务一边粉丝 | 两边的名场面各给一次，不偏袒 |
| 廉价伤感 | 分别时大哭、许诺「一定再见」 | 不承诺再见；留下东西（プリチケ、花、羊铃）就够了 |

## 八、Canon / AU 速查（详见 `docs/05`）

**纯 canon**：プリパラ 的舞台机制、ボーカルドール、系统判バグ、石板プリチケ、山羊、响 的性别与创伤、芙羽梨 看脸与羊、法露露 的来历；花灵的来历（花神/树王/厄歌莉娅/西摩格）、祭水之仪、甘露、万种母树；芙宁娜 是人类且已卸任、纳西妲 是树王之枝且世界不记得树王、妮露 是舞者。

**AU（自设，需登记）**：
1. 两边都已结婚数月（原作没有婚后时间线）。
2. 响 与芙羽梨 婚后住在パルプス，羊群是那两只山羊的后代。
3. 法露露 以「情人」身份与两人同住，并能在现实世界长时间实体化（canon 只有最终话一次奇迹）。
4. 妮露 是花神选的继承人，只继承美貌与舞蹈，无力量、不知情（沿用 exchange 项目）。
5. 帕丽莎 是三人婚礼上诞生的花灵女儿（沿用 exchange 项目）。
6. 芙宁娜 在 3.6 当过祭水之仪的媒介（沿用 exchange 项目）。
7. 花灵离开甘露花海会衰弱（canon 未明说）。
8. 舞台之门（本书的核心机制）。
