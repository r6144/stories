# 《安可》（暂定名）

《プリパラ（美妙天堂）》×《原神》跨界同人长篇。

> 两边都结婚几个月之后，一场演出把两个「靠表演活下来的人」放到了同一个后台。

## 一句话

紫京院响 与 芙宁娜，一个演了「王子」，一个演了五百年的「水神」；她们都以为自己爱的与被爱的都不是本人。这一夜，舞台把两个世界叠在了一起——然后在天亮前分开。

## 两组人

- **プリパラ 侧**：紫京院响 × 绿风芙羽梨（婚），法露露（情人）；家住芙羽梨的故乡パルプス，放羊；三人仍以 Tricolore 同台。
- **提瓦特 侧**：纳西妲 × 妮露 × 芙宁娜（三人无性浪漫婚姻），女儿帕丽莎是花灵。
