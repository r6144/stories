# 反应釜与婚纱

《魔法纪录 魔法少女小圆外传》同人，前篇 5 章。

19 岁的有机化学研究生篠原真帆，身高 140 厘米，看起来像小学生。她在一台中试反应釜的安装现场，认识了工程师环匠——一个丧偶多年、带着两个女儿的男人。她嫁给了他，成了环家的"小新娘"，被 15 岁的彩羽和 11 岁的羽衣当作妹妹宠爱。两个月后，匠死于魔女引发的意外。真帆签下契约，穿上像婚纱的战衣，第一次和姐妹并肩。

- 主角：真帆（原创）
- 舞台：神浜市
- 篇幅：5 章，每章 1.2–1.7 万字
- 基调：温暖亲情，轻微童话感，12+
- 状态：设定分析与大纲完成，等确认 `docs/07` 的 D1–D14 后开写
