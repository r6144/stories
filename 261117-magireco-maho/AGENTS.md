## 项目

《反应釜与婚纱》，《魔法纪录 魔法少女小圆外传》同人，前篇 5 章，每章 1.2–1.7 万字。

19 岁的有机化学研究生真帆（原创）嫁给丧偶工程师环诚，成为环家两个魔法少女姐妹的"小妹妹 / 小新娘"；两个月后诚死于魔女引发的意外，真帆签约成为魔法少女，与彩羽、羽衣第一次并肩战斗。

当前阶段：ch01 已修订（真帆的性格、研究线、数字口径）；ch02 卡已建（`docs/08-章节写作包/ch02.md`），等新会话开写正文。

## 红线

1. **婚姻无性、无恋爱、无身体接触。** 分房睡；没有拥抱和亲吻；他最多替她拿高处的东西。她是主动求婚的一方，他是设边界的一方。
2. **不幼态化、不凝视。** 真帆的身体是事实，不是伤口；她基本没有不满。写尺寸与不便，不写性感；不写"她其实很成熟所以可以"这种辩护。
3. **她不是母亲。** 法律上是继母，实际是妹妹 / 姐姐式的家人。成长是"能负责"，不是"当妈"。
4. **彩羽 × 八千代只到吻痕。** 不写身体、不写夜晚；写热度与恐惧。
5. **不复活诚。** 真帆问过，拒绝了；理由是她知道那不是他，也不是她要的东西。
6. **魔法少女不游戏化。** 不写数值、面板、等级；丘比只说必要的。
7. **死亡有独立重量。** 不是签约的开关；她先办丧事，再签约。
8. **不说教。** 主题让物件说：手套、照片、汤、闹钟、标签。
9. **真帆的科研不缺席。** 每章至少一场实验室或研究的戏；她是研究生，不是全职新娘。
10. **12+。** 不写性、血腥、猎奇；战斗伤是淤青、扭伤、划伤。
11. **婚姻不是背景板。** 小女儿 / 小新娘 / 平等挚友三种关系要写足、无缝切换；两个月至少四场只有两个人的戏。

## 文体（摘要，详见 `docs/06`）

- 第三人称限知，过去时，全程真帆 POV。
- 文笔柔和、克制；段落偏长，避免碎句成段。
- 童话感要有，但不滥；多数时间是实验室的精确。
- 她的孩子气是尽责之后的放松，不是被误认后的抗议；写撒娇之前，先写她做完了什么。
- 化学 / 工业术语少而准，长在动作上。
- 引号用“”，嵌套用‘’。
- 不写年份；用月份、星期、"那天"。
- 数字按 `docs/06` §五：日期钟点金额用阿拉伯，引语里的数量用汉字，叙述 10 以下用汉字；同一时间点不混排。

## 工作流（每章固定）

1. **新会话**。一个会话只写一章；不在同一会话里连写两章。
2. **按配方读**（顺序、长度每章一样）：
   - `AGENTS.md`
   - `docs/08-章节写作包/chXX.md`
   - `docs/10` 的进度表 + 本章账本 + 全局事实
   - canon 片段 1–2 段（≤500 字）
   - `docs/09-声音与节奏.md`（**最后读**）
3. **写开头 300–500 字**，对照 `docs/09` §一 的三段；不像就重写开头，不往后拖。
4. **写本章**：几场，场场有转折；先逻辑，后润色；不跳场景。
5. **一致性**：只对本章卡 §7 与 `docs/10` 账本，逐条过；不重读全文。
6. **声音（按需）**：只在"读起来不像"时做；对照 `docs/09`，不做指标统计。
7. **收尾**：`docs/10` 账本覆盖式更新（≤800 字）→ 进度表改状态 → 卡标"已写" → 提交 `[chXX] ...`。
8. **下一章**：新会话；先写下一张卡（带上一章账本），再开写。

## 上下文卫生

- **不加载**：上一章正文、整份 `00`/`02`/`03`/`05`/`07`、之前的对话。
- 卡与账本是蒸馏物：卡管"这一章怎么写"，账本管"已经发生了什么"。
- 风格不靠"再提醒一遍"：靠 `docs/09` 放最后、靠每章同样的配方、靠开头校准。
- 新事实：先写进 `docs/10` 账本；涉及 SSOT 的，再改 `docs/01`/`03`，最后回正文。
- 文档只记约束；字数、行号、逐条改动进 commit message。

## Git（沙箱内）

本地命令一律：

    git -c core.hooksPath=.git/no-hooks -c core.fsmonitor=false <子命令> ...

- 只 `add` 本项目内的明确路径；禁止 `-A`、`-u`、`commit -a`。
- 本项目不含图片；若 `status` 出现 `.png`，停下报告。
- 提交信息：`[docs] ...` / `[ch01] ...` / `[fix] ...`。
- 远端命令（push / fetch / pull）不带 `-c`；沙箱内 ssh 起不来，失败就报告用户。
