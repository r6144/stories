# 人物设定

> SSOT。称呼见 §十，知情见 §十一。正文以本文为准；发现冲突，以本文为准。

## 一、真帆

### 基本信息

| 项 | 内容 |
|---|---|
| 本名 | 篠原真帆（しのはら まほ）→ 環真帆 |
| 年龄 | 19 |
| 身高 | 140 cm |
| 身份 | 神浜市立大学 大学院 理学研究科 化学专攻 硕士 1 年；大槻研究室 |
| 出身 | 滨松市；独生女；15 岁离家读大学 |
| 生日 | 不使用 |

### 外貌

- 短发，齐耳，自己剪的，后颈总有几根没剪齐。
- 脸小，眼睛大而黑；不化妆，不戴首饰（婚后多一枚素圈）。
- 白大褂太大，袖口卷两折；私服是衬衫、长裤、运动鞋；冬天穿羽衣穿旧的毛衣。
- 手小，指尖有薄茧，很稳；腕细，肋骨隐约可见；站得直，坐着的时候脚常常够不到地。
- 声音轻、清楚，语速慢；讲到自己的研究时会变快。

### 经历

- 小学、中学都在滨松；初中时把高中的化学教材读完了。
- 15 岁通过大学入学考试，离家到神浜；住校两年，后租公寓。
- 18 岁提前毕业；19 岁读研，导师大槻。
- 研究：有机合成方法学（正文不展开具体反应）；手上有一个卡了半年的课题。
- 与家里：父母疼她但不黏她；每周打一次电话；过年回家。

### 性格

- 表层：安静、礼貌、乖、不添麻烦；被夸的时候笑，被让的时候接受。
- 里层：固执、精确、认死理；对"不懂装懂"零容忍；对"被可怜"过敏。
- 孩子气：喜欢甜食；喜欢被摸头（不承认）；把好东西留到最后吃；怕烫。
- 大人气：计划、记账、查资料、处理突发；别人慌的时候她反而冷静。
- 缺的东西：不会撒娇（后来学会一点点）；不会照顾人（后来学会）；不会玩（一直不太会）。
- 对身体：基本没有不满。从小就是这个尺寸，没经历过青春期，也不觉得少了什么；被当成小孩、要反复解释"我是研究生"时嫌麻烦，但不算大问题。旁人为她的外表宠她，她受用；她不执意证明自己不是小孩——先把大人该做的事做完，才安心当被宠的那个。
- 顺序：先尽责，后被宠。该她做的事没做完，她不太能安心撒娇；做完了，她会很自然地接受摸头、被喂饭、被叫真帆酱。被宠不是她争来的，是她"做完了"之后允许自己拿的。

### 习惯与小动作

- 思考时歪头；听人说话时手指在桌面上轻轻敲，像在数拍子。
- 记笔记；东西按大小排；筷子要摆齐。
- 吃饭慢；怕烫；喜欢把菜留一口到最后。
- 睡得少（契约前 5 小时，契约后 2 小时）；婚后一直睡女孩们的房间，靠门那边；半夜起来轻手轻脚，不吵醒她们；醒来第一件事是看当天的工作清单。
- 说谎时会先眨眼（羽衣发现的）。

### 语言

- 口头禅："嗯。""为什么？""我知道了。""没关系。""这个可以算一下。"
- 不用感叹号；激动时句子变短，词变专业。
- 不会说漂亮话；安慰人的方式是"我给你倒杯水"。
- 对女孩们：叫"彩羽""羽衣"；开玩笑叫过一次"彩羽姐姐"。

### 知识边界

- 懂：化学、实验安全、数据、计划、预算、说明书；不太认路。
- 不懂：做饭的火候、衣服的搭配、恋爱的身体、别人的暗示、流行、怎么安慰一个正在哭的人。
- 她的"不懂"不是蠢，是没学过；她学得很快，但有些东西学不会，比如"凭感觉"。

### 随身物

- 实验记录本（硬壳，方格纸，编号）。
- 黑笔、红笔各一支。
- 旧款手机；钱包；钥匙。
- 婚后：素圈。后来：灵魂宝石（戒指形态）。

### 魔法少女形态

| 项 | 内容 |
|---|---|
| 愿望 | "我不需要睡觉，也能一直保持清醒的头脑。" |
| 固有魔法 | 触媒：她理解的过程可以被加速；必须用手碰到；不能无中生有 |
| 武器 | 一根透明的长玻璃棒，像指挥棒，末端有一点光；近身时当短棍 |
| 服装 | 白色蕾丝短上衣（下摆到胸口下、露腰）、膝上短裙、隐约的肋骨、小白头纱、白手套、白短靴；一键换装 |
| 灵魂宝石 | 日常：左手中指的戒指；变身：领口的胸针，像一枚浮雕 |
| 战斗风格 | 后援 / 分析：看结构、找关节、加速彩羽的治愈、加速结界的崩解 |
| 弱点 | 体力、近身、恐惧；跑不快；手会抖 |

### 在故事里的功能

- 视角人物；读者通过她看这个家。
- 她的"多面"是主题本身：研究者 / 小妹妹 / 小新娘 / 主心骨 / 战士。
- 她的成长是"主心骨"从偶尔到随时，不是变成另一个人。

## 二、环诚

### 基本信息

| 项 | 内容 |
|---|---|
| 本名 | 環誠（たまき まこと） |
| 年龄 | 43 |
| 身高 | 185 cm |
| 职业 | 神浜化工機 株式会社 技術部 サービス課；高压釜、特种反应装置的现场安装、调试、维修 |
| 家庭 | 丧偶 7 年；长女彩羽、次女羽衣 |
| 生日 | 不使用 |

### 外貌与身体

- 高、宽肩、背直；短发夹白；晒得黑；眉毛浓。
- 手大，指节粗，虎口有旧疤；指甲剪得短，洗得干净。
- 工作服、安全鞋、工具箱；身上有金属和机油的味道，回家先洗澡。
- 笑的时候只有嘴角动一下；声音低、慢。

### 性格

- 话少；不擅长解释感情，擅长解释机器。
- 稳；遇到事情先看，再动手；不慌。
- 温柔是行动式的：修好、带来、留下、记得。
- 有边界感：不打听、不越界、不施舍。
- 对女儿们：笨拙地爱；不会说"我爱你"，会问"饭吃了没"。
- 对真帆：先是"这姑娘有意思"，再是"她一个人不容易"，再是"她懂我的话"，最后是"她是我们家的"。

### 出差

- 婚后他把能推的出差推掉：能当天回的当天回；必须过夜的压到一天。课里知道，也不说什么。
- 有一次去邻市两天，第二天下午就回来了（现场顺利，剩下的收尾交给同事）。行李还在玄关没开，他先去煮面。

### 前妻

- 七年前病逝；不写名字，正文用"她们的母亲""她"。
- 他偶尔提起，都是在做别的事的时候：她煮的汤盐总是少一点；她走的那年羽衣四岁；医院走廊的椅子是绿的。
- 他不说"爱"，也不说"忘了"。真帆听着，像女儿听父亲讲母亲；她从不拿自己跟她比。

### 与真帆的关系

- 他从来没有追求过她；是她求婚。
- 他答应的理由：这个家需要一个会留下来的人；女儿们需要一个年纪相近的女性；她需要一个位置。他不觉得这是爱情，也不假装是。
- 他给的边界：分房；她的研究不能停；她随时可以走；对外人，他是她丈夫，不躲不藏。
- 他从不评价她的身体；最多说"你太瘦了，多吃点"。
- 他留给她的东西：一枚素圈、一双手套、一个工具箱、一个姓、两个女儿。
- 他的旧婚戒：用链子挂在脖子上，藏在衬衫里。真帆只看见过一次。

### 三种关系的切换

他不"扮演"丈夫，也不"扮演"父亲；他只是同时把她当小女儿、当小新娘、当一个可以商量事的人。三种关系在同一场戏里切换，不需要过渡：

- **小女儿**：她够不到柜子，他伸手拿下来；她熬夜，他把灯关掉一半，说"明天再说"；她吃得少，他把鱼夹到她碗里。她不觉得被冒犯，因为她本来就不介意被当小孩。
- **小新娘**：她等他回家，给他留一盏门灯；他晚归，她把饭热了两次；她补他磨破的工作服，针脚歪歪扭扭；区役所的职员叫她"环太太"，她没反应过来，他叫了一声"真帆"，她才回头。
- **平等挚友**：他在厨房桌上摊开检验报告，她凑过去看，问"这个壁厚是按哪年的标准"；她给他讲她的反应，他听懂三分之一，说"这个我不懂，但听起来很难"；他教她用扭力扳手，"先用手拧到不动，再用扳手"；她学得快，他说"你手稳"，她高兴得像被夸的小孩。

**关键**：这三种关系不是三段，是一段。他一边回答她关于法兰的问题，一边把她的椅子往炉边挪；她一边讲她的课题，一边伸手够不到杯子，他顺手递过去。他们自己从不觉得奇怪——尴尬只来自旁观者。

### 与女儿们

- 彩羽：他依赖她，也愧疚；他知道她太懂事。
- 羽衣：他宠她，但不会说；他记得她小时候医院的走廊。
- 他死前没有说破。他知道女儿们夜里在做危险的事（晚归、湿鞋、焦痕、伤），不知道那些词；他从不问，也不让真帆看见他问。这是他带走的，也是真帆再也问不到的。

### 死

- 12 月 6 日，临海工业区的现场；魔女的结界压过来，吊装物坠落；送到医院时已经。
- 遗物：手机、钱包、工具箱、手套；口袋里有一张买鱼的收据——他确实去了超市。
- 他不留遗言。这是他最后的"不麻烦别人"。

### 语言

- "嗯。""大丈夫。""我看着办。""路上小心。""饭吃了没。"
- 解释机器时会用手比划；"这个要先用手拧到不动，再用扳手"。
- 叫真帆"真帆"；叫女儿"彩羽""羽衣"。

## 三、环彩羽

### 基本信息

| 项 | 内容 |
|---|---|
| 年龄 | 15 |
| 身高 | 156 cm |
| 学校 | 神浜市立大附属中学校 3 年 |
| 志愿 | 护士 |
| 魔法少女 | 愿望"治好妹妹的病"；固有能力"倒带"（治愈）；武器手弩、匕首 |
| 恋爱 | 与八千代交往（AU） |

### 性格

- 温柔、认真、老好人；过度在意别人；关键时刻很强。
- 家务全能；做饭有"灵魂"；照顾妹妹和爸爸。
- 逞强；不给人看伤口；自责型。
- 对真帆：当妹妹宠；也当"可以说话的大人"。

### 声音

- "嗯。""没事的。""真帆酱。""饭要好好吃。"
- 累的时候句子变短；哭的时候不出声。

### 在故事里

- 家的温度；真帆的对照；"被照顾的人"与"照顾人的人"的互换。
- 父亲死后，她第一次崩；真帆第一次当主心骨。
- 她羡慕真帆的"轻"；真帆心疼她的"重"。

### 与八千代

- 在战斗里认识；热烈、沉重、有身体；只写到吻痕。
- 她怕八千代死；八千代怕她死；两个人互相舔伤口。

## 四、环羽衣

### 基本信息

| 项 | 内容 |
|---|---|
| 年龄 | 11 |
| 身高 | 143 cm（比真帆高 3 cm） |
| 学校 | 神浜市立大附属学校 5 年 |
| 魔法少女 | 今年春天起；固有能力"能量的回收与转交"（支援型）；愿望不展开；武器燕型魔法阵 / 风筝 |
| 朋友 | 里见灯花、柊音梦（同岁；病友、青梅竹马） |

### 病历史

- 三人幼时都确诊复杂先心病（医学上治疗难度大）；小时候控制得住，约一年前（10 岁左右）开始加重。
- 去年冬天，彩羽许愿治好羽衣；今年春天，羽衣、灯花、音梦一起许愿，改善了魔法少女的处境，三人也不再受疾病困扰。
- 没有小丘比事件，没有被世界遗忘的那一段。
- 父亲知道女儿住过院、病过、后来好了；不知道愿望。这是彩羽替他挡住的部分。

### 性格

- 天然、直接、认真；会说出让人脸红的话。
- 幼时体弱，在医院住过；因此比同龄人安静，也比同龄人懂"离别"。
- 善于发现别人的好；不讨厌人。
- 对真帆：当同龄玩伴；喜欢摸她的头；把旧衣服给她穿。

### 声音

- "真帆酱好小。""为什么？""下次再来。""爸爸会冷吗？"
- 小声，但清楚；不撒娇，除非对姐姐。

### 在故事里

- 让真帆"被当作孩子"的快乐；也让真帆第一次想保护谁。
- 她的病历史是家里的旧伤；父亲不知情的那部分，是彩羽的秘密。
- 她和灯花、音梦的"结婚宣言"是家里的笑料；真帆自己也喜欢童话，顺着她说婚宴和糖，不问重婚。

## 六、里见灯花、柊音梦

- 11 岁，羽衣的病友、青梅竹马；灯花聪明、直、嘴快；音梦安静、爱写故事。
- 三人一起住过院，一起许愿，一起成为魔法少女；关系紧密到有自己的暗语。
- 两人都说"长大要娶羽衣"；羽衣说"两个都嫁"。
- 前篇只出现在对话里；最多一次电话或一次门口打招呼。
- 不写 Magius 的组织与主线；不写她们战斗。

## 七、丘比

- 白色，猫一样，红眼，背上有环；声音平，礼貌，不带感情。
- 不撒谎，但也不主动说全；问题比答案多。
- 叫真帆"你"；"恭喜"只说一次。
- 被问到不该给的东西时，它会停一下、把话说得很少（"可以""不会""那要她们自己许"）；那是它唯一的"为难"，不是心软。
- 它的可怕在于：它说的都是真的。
