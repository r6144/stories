# 章节写作包

> 每章一张卡，开写前读，写完标状态。卡 ≤3k 字；不复制 `00`/`02`/`03`/`05` 的内容，只写"本章要用的"。
> ch02–ch05 在上一章定稿后写：卡要带着上一章账本的新事实，保持新鲜。

## 卡的固定结构（每章相同，长度相近）

1. 一句目标
2. 时间 / 地点 / 在场 / POV
3. 节拍（几场，每场一个转折）
4. 本章的坑
5. 物件与回声（旧物件 + 新物件）
6. 章末钩子
7. 不能忘（知情、日期、称呼、伤势、承诺）
8. 开写提示（本章最像哪段锚）

## 开写配方（固定顺序、固定长度）

1. `AGENTS.md`（约 4k 字）
2. 本章卡 `docs/08-章节写作包/chXX.md`（≤3k）
3. `docs/10` 的进度表 + 本章账本 + 全局事实（≤1k）
4. canon 片段 1–2 段（≤500 字）
5. `docs/09-声音与节奏.md`（约 1.5k，**放最后**，最近）

总计约 10k 字，每章一样。**不加载**：上一章正文、整份 `00`/`02`/`03`/`05`/`07`、之前的对话。

## 写完的动作

1. **一致性**：只对本章卡 §7 与 `docs/10` 账本，逐条过；不重读全文。
2. **声音（按需）**：只在"读起来不像"时做；对照 `docs/09` §一/§五，不做指标统计。
3. **收尾**：账本覆盖式更新（≤800 字）→ 进度表改状态 → 本章卡标"已写"。
4. **提交**：`[chXX] ...`。
5. **下一章**：新会话；先写下一张卡（带上一章账本），再开写。

## 新会话开场（复制这一段）

> 读 `261117-magireco-maho/AGENTS.md`，按"开写配方"依次读 `docs/08-章节写作包/chXX.md`、`docs/10` 的进度表 + 本章账本 + 全局事实、`docs/09-声音与节奏.md`，然后写第 X 章。不要读上一章正文，不要读整份 00/02/03/05/07。

## 为什么这样排

- **风格放最后**：前面的卡和账本再长，最后读到的是声音锚，近因效应站在风格这边。
- **每章同样的长度**：上下文结构不变，模型不必每章重新适应"这一章该读多少"。
- **不读上一章**：风格漂移多半来自"上一章的惯性"；用账本代替正文，既省 token 又防漂移。
- **卡与账本都是蒸馏物**：卡管"这一章怎么写"，账本管"已经发生了什么"。
