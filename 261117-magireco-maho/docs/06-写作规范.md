# 写作规范

> 文体、尺度、术语、交稿清单。写之前读一遍；改的时候按 §十二 过一遍。
> 风格不用指标管理：下面偶尔出现的数字是结构或格式（章节、分级、场合），不是文风考核。

## 一、叙述

- **第三人称限知，过去时，全程真帆 POV。** 不写别人的内心；别人的情绪通过动作、语气、沉默、位置来写。
- 不写"她不知道的是……""与此同时，在另一个地方……"。真帆不在场的事，要么她后来听说，要么不写。
- 顺叙为主。回忆要短；不写长篇倒叙。
- 真帆的叙述是精确的：她注意尺寸、时间、顺序、数量。情绪上来时，精确会掉——数字消失，句子变短，这是她的"失控信号"，可以用，但别当技巧反复用。
- 不写"她感到……"的总结句；写身体先于情绪：手抖、胃里发凉、耳朵发热、脚够不到地。

## 二、段落与句子

- 段落偏长，一段只做一件事；避免一句一段的碎法，也避免一段里塞三件事。
- 对话独立成段；对话之间用动作、停顿、环境隔开。
- 比喻从实验室、工业、家务里取（法兰、冷凝水、面糊、螺丝扣）；不用"像樱花一样""像星星一样"这类套话。
- 少用"仿佛""宛如"；能直说就直说。
- 不写排比句堆叠；少用"不是……而是……"的句式。

## 三、对话

- 用动作代替"他说""她说"；对话之间要有动作、停顿或环境，不要连成墙。
- **一轮一段，但一轮要有东西**：每轮对话至少带一处信息、一个动作或一次情感变化。空应答（"嗯。""好。""谢谢。""对。"）不单独立段——并进动作段（"她嗯了一声，把碗放正。"），或在后面接上内容（"嗯。三个底物都过了八十。"）。
- 连续几轮都是点式短应答，就合并或改写；全章的"空应答"以零为目标。
- 不写解释性台词；人物不解释自己的动机。
- 不写大道理；少写格言，要有，也必须是那个人会说的话。
- 真帆的话短、完整、常带"嗯"，"嗯"后面通常跟着内容；诚的话更短，常以"嗯"开头；彩羽的话暖，常带"没事的"；羽衣的话直，常带"为什么"；八千代的话慢，句尾轻；丘比的话平，不带语气词。
- 沉默是对话的一部分。允许"她没有回答""他看了她一会儿"。

## 四、称呼与日语词

- 只用"真帆酱""环先生""爸爸"三个带亲称 / 敬称的词；不出现"さん""ちゃん"的原文。
- "小姐"只用于森对真帆。
- 地名、校名用中文：神浜市、神浜市立大学、神浜市立大附属中学校、神浜市立大附属学校、三日月庄、临海工业区。
- 机构名：神浜化工機。
- 展会名"プロセス産業展"在 ch1 出现两次（传单、记录本各一次），之后一律用"工业展览会"。
- 不写罗马字；不写英文缩写（NMR、GC 之类），需要时写"核磁管""色谱"。

## 五、数字与日期

分三条管：**现实的日期钟点金额**、**引语**、**叙述**。

- **日期、钟点、金额 → 阿拉伯**：6月19日、7月底、5月中旬、16号、上午9点、6点40分、3200元。年份写全（本项目仍不写年份）。
- **引语（对话、信件、内心话）里的数量 → 汉字**：走了一个多月、今年七岁、我才十七岁、只能拿一支、守了二十多天。引语里的日期、金额、专名仍用阿拉伯（"5月4日的票""600块"）；钟点算日期一类，也用阿拉伯（"6点半"）。
- **叙述**：10 以下用汉字（三分钟、四天、半瓶、两只鞋、第三次）；10 及以上和统计数用阿拉伯（29天、47天、30分钟、21个月、37个英文词、24听、第651天）。约数用汉字（二十多天、十几步、三十多岁）；百、千、万的修辞数用汉字（五百年、上百年、百米、上万人），金额除外（2万摩拉）。
- **不混排**：同一个时间点不在"点/分"之间混用——写"6点40分"或"六点四十分"，择一；本书统一阿拉伯，即"6点40分"。
- 日期不加空格：正文写"6月3日"，不写"6 月 3 日"；文档里为了好读可以留空格。
- 百分数用阿拉伯加 %：41%、47.5%；引语里念出来，用汉字："百分之四十一"。
- 实验室的量随叙述规则：三毫升、250毫升、两克、15克；不用 mL / g。
- 生活量词用汉字：两碗饭、三个人、一副碗筷、一杯茶。
- 日期不写年份、不写"平成""令和"。
- 时间用"早上""傍晚""夜里10点""天快亮的时候"。

## 六、尺度（12+）

- 不写性；不写身体细节；不写"夜晚"。
- 吻痕可以写，只写"印子"，不写过程；三句话内结束。
- 拥抱可以：女孩们之间、姐妹之间；真帆与诚之间没有拥抱、没有亲吻、没有牵手。
- 不写血腥：伤是淤青、划伤、扭伤、擦破；不写断肢、内脏、大量出血。
- 不写猎奇；魔女不恶心化，使魔可以荒诞，但不恐怖片。
- 不写脏话；不写歧视性语言。
- 不消费死者：不写尸体、不写抢救细节、不写临终遗言。

## 七、化学与工业

- 术语少而准；只写长在动作上的；不解释原理。全章十个以内；ch1 的十个：冷凝管、法兰、通风橱、视镜、爆破片、溶剂、除气、夹套、油浴、单峰。
- 可用：通风橱、冷凝管、法兰、爆破片、压力表、回流、萃取、旋转蒸发仪、高压釜、中试装置。
- 不写配方、不写可被模仿的危险操作；小事故的处理只写"关热源、开通风、覆盖、等人"。
- 实验室里不吃不喝；吃喝、休息都在学生室。废液不在实验室里清空，提到废液间再倒。
- 不写"纳米""量子""超导"这类科幻词。
- 数字要像真的：她量的是"三毫升"，不是"一点"；但不要连续报数。

## 八、魔法少女

- 不写数值、等级、技能名、冷却时间、面板。
- 结界用感官写：气味（旧纸、铁锈、消毒水）、温度（比外面冷）、声音（电流、钟摆、广播）、光（日光灯闪）。
- 魔女不拟人化；使魔可以有荒诞的礼貌（"您有预约吗"）。
- 变身：ch5 正写一次；其余一笔带过（"她握住戒指"）。
- 灵魂宝石：恐惧点到为止；"容器"的讨论别展开。
- 悲叹之种：一颗就够；不写净化过程。

## 九、死亡与葬礼

- 不写临终遗言；不写抢救；不写尸体。
- 写物件、手续、人的动作：鞋、手套、收据、印章、表格、香、遗像、多摆的一副碗筷。
- 葬礼不写过多宗教流程；写香、照片、低声、黑衣服、火葬场的走廊。
- 悲伤是延迟的：在无关的时刻袭来（看到他的拖鞋、超市里他常买的鱼）。
- "她梦见他"只写一次，且短。

## 十、每章结构

- 3–5 场；每场一个转折；场与场之间用时间跳，不写过渡段。
- 章末钩子要软：一个物件、一句话、一个动作；不用悬念，不用"然而，她不知道……"。
- 每章至少一场实验室 / 研究的戏（ch4 可以是被电话打断的实验）。
- 每章至少一个"只有真帆会做"的动作（用手电照法兰、给悲叹之种贴标签、把筷子摆齐）。
- 每章至少一处孩子气，至少一处可靠；两者不要在同一段里。顺序常常是先可靠、后孩子气；反过来也行，但她会不安。

## 十一、婚姻的写法

- 三种关系同场切换：小女儿、小新娘、平等挚友；不点破，不解释，不总结"他们像父女也像夫妻"。
- 亲密不靠身体：留灯、递茶、补衣服、记班表、教工具、把椅子往炉边挪。"他替她拿高处的东西"是这段婚姻最重要的动作，重复几次，每次分量不同。
- 称呼即关系：他叫她"真帆"；她叫他"诚"；外人叫"环太太"；女孩叫"真帆酱"。同一场戏里可以让两种称呼撞在一起（区役所那场）。
- 婚姻要有自己的戏，不只是"和女孩们一起"的戏：ch3 的登记与第一个早晨；ch4 的第一个星期、班表、补工作服、星期天的车库、最后一次早饭。至少四场只有两个人。
- 不写主妇化：她不做全部家务，不做便当（彩羽做），不放弃研究；她的"妻子"身份只在纸面上和签字时最重。
- 不写性、不写身体接触、不写"同房"的暗示；分房是第一天就说好的事，不需要反复解释。
- 不写"她其实很成熟，所以这段婚姻没问题"；她的选择不需要辩护，读者自己会看见。

- [ ] 时间：与 `docs/01` 一致

- [ ] 知情：没有穿帮（实验室不知道魔法少女；诚不知道）
- [ ] 尺度：12+；无性、无血腥、无猎奇
- [ ] 术语：少而准，不长在解释上
- [ ] 说教：无；主题在物件和动作里
- [ ] 科研：本章有实验 / 研究
- [ ] 真帆：至少一处孩子气，至少一处可靠
- [ ] 童话感：有，但不滥
- [ ] 引号：正文用“”，嵌套用‘’
- [ ] 年份：无
- [ ] 数字：按 §五（日期钟点阿拉伯；引语汉字；叙述 10 以下汉字、10 及以上阿拉伯；同一时间点不混排）
- [ ] 段落：没有连续碎段；对话没有连成墙
- [ ] 婚姻：至少一场只有两个人的戏；三种关系至少各出现一次
- [ ] 身体：尺寸是事实，不是伤口；没有怜惜或调侃的腔调
