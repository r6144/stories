# 写作规范

> 文体、尺度、术语、交稿清单。写之前读一遍；改的时候按 §十一 过一遍。

## 一、叙述

- **第三人称限知，过去时，全程真帆 POV。** 不写别人的内心；别人的情绪通过动作、语气、沉默、位置来写。
- 不写"她不知道的是……""与此同时，在另一个地方……"。真帆不在场的事，要么她后来听说，要么不写。
- 顺叙为主。回忆每次不超过一页；不写长篇倒叙。
- 真帆的叙述是精确的：她注意尺寸、时间、顺序、数量。情绪上来时，精确会掉——数字消失，句子变短，这是她的"失控信号"，可以用，但每章不超过两次。
- 不写"她感到……"的总结句；写身体先于情绪：手抖、胃里发凉、耳朵发热、脚够不到地。

## 二、段落与句子

- 一段 3–6 句；避免连续五段都是 1–2 句的碎段。抒情段可以长，但一段只做一件事。
- 对话独立成段；对话之间用动作、停顿、环境隔开。
- 比喻每章 3–5 个，从实验室、工业、家务里取（法兰、冷凝水、面糊、螺丝扣）。不用"像樱花一样""像星星一样"这类套话。
- "仿佛""宛如"每章不超过 2 次。
- 不写排比句堆叠；不写"不是……而是……"超过 2 次。

## 三、对话

- 用动作代替"他说""她说"；连续对话超过四句，中间必须有一个动作或环境。
- 不写解释性台词；人物不解释自己的动机。
- 不写大道理；金句每章不超过一句，且必须像那个人会说的话。
- 真帆的话短、完整、常带"嗯"；匠的话更短，常以"嗯"开头；彩羽的话暖，常带"没事的"；羽衣的话直，常带"为什么"；八千代的话慢，句尾轻；丘比的话平，不带语气词。
- 沉默是对话的一部分。允许"她没有回答""他看了她一会儿"。

## 四、称呼与日语词

- 只用"真帆酱""环先生""爸爸"三个带亲称 / 敬称的词；不出现"さん""ちゃん"的原文。
- "小姐"只用于森对真帆。
- 地名、校名用中文：神浜市、神浜市立大学、神浜市立大附属中学校、神浜市立大附属学校、三日月庄、临海工业区。
- 机构名：神浜化工機。
- 展会名"プロセス産業展"只出现一次（ch2 开头），之后用"工业展览会"。
- 不写罗马字；不写英文缩写（NMR、GC 之类），需要时写"核磁管""色谱"。

## 五、数字与日期

- 年龄、身高、温度、时间、金额、页码用阿拉伯数字：19 岁、140 厘米、120 度、6 月 3 日、三十分钟。
- 生活量词用汉字：两碗饭、三个人、一副碗筷、一杯茶。
- 实验室的量：用汉字 + 单位（三毫升、两克），不用 mL / g。
- 日期只用"6 月 3 日""12 月 6 日"；不写年份、不写"平成""令和"。
- 时间用"早上""傍晚""夜里十点""天快亮的时候"。

## 六、尺度（12+）

- 不写性；不写身体细节；不写"夜晚"。
- 吻痕可以写，只写"印子"，不写过程；三句话内结束。
- 拥抱可以：女孩们之间、姐妹之间；真帆与匠之间没有拥抱、没有亲吻、没有牵手。
- 不写血腥：伤是淤青、划伤、扭伤、擦破；不写断肢、内脏、大量出血。
- 不写猎奇；魔女不恶心化，使魔可以荒诞，但不恐怖片。
- 不写脏话；不写歧视性语言。
- 不消费死者：不写尸体、不写抢救细节、不写临终遗言。

## 七、化学与工业

- 每章术语不超过 3 个；必须服务动作或情绪；不解释原理。
- 可用：通风橱、冷凝管、法兰、爆破片、压力表、回流、萃取、旋转蒸发仪、高压釜、中试装置。
- 不写配方、不写可被模仿的危险操作；小事故的处理只写"关热源、开通风、覆盖、等人"。
- 不写"纳米""量子""超导"这类科幻词。
- 数字要像真的：她量的是"三毫升"，不是"一点"；但不要连续报数。

## 八、魔法少女

- 不写数值、等级、技能名、冷却时间、面板。
- 结界用感官写：气味（旧纸、铁锈、消毒水）、温度（比外面冷）、声音（电流、钟摆、广播）、光（日光灯闪）。
- 魔女不拟人化；使魔可以有荒诞的礼貌（"您有预约吗"）。
- 变身：ch5 正写一次；其余一笔带过（"她握住戒指"）。
- 灵魂宝石：恐惧点到为止；"容器"的讨论不超过三句。
- 悲叹之种：一颗就够；不写净化过程。

## 九、死亡与葬礼

- 不写临终遗言；不写抢救；不写尸体。
- 写物件、手续、人的动作：鞋、手套、收据、印章、表格、香、遗像、多摆的一副碗筷。
- 葬礼不写过多宗教流程；写香、照片、低声、黑衣服、火葬场的走廊。
- 悲伤是延迟的：在无关的时刻袭来（看到他的拖鞋、超市里他常买的鱼）。
- "她梦见他"最多一次，且不超过半页。

## 十、每章结构

- 3–5 场；每场一个转折；场与场之间用时间跳，不写过渡段。
- 章末钩子要软：一个物件、一句话、一个动作；不用悬念，不用"然而，她不知道……"。
- 每章至少一场实验室 / 研究的戏（ch4 可以是被电话打断的实验）。
- 每章至少一个"只有真帆会做"的动作（用手电照法兰、给悲叹之种贴标签、把筷子摆齐）。
- 每章至少一处孩子气，至少一处可靠；两者不要在同一段里。

## 十一、交稿清单

- [ ] 逻辑：因果、动机、谁知道什么，能一条条说通
- [ ] 时间：与 `docs/01` 一致
- [ ] 称呼：与 `docs/03` §十 一致
- [ ] 知情：没有穿帮（实验室不知道魔法少女；匠不知道）
- [ ] 尺度：12+；无性、无血腥、无猎奇
- [ ] 术语：≤3 个；不长在解释上
- [ ] 说教：无；主题在物件和动作里
- [ ] 科研：本章有实验 / 研究
- [ ] 真帆：至少一处孩子气，至少一处可靠
- [ ] 童话感：1–2 处，不滥
- [ ] 引号：正文用“”，嵌套用‘’
- [ ] 年份：无
- [ ] 段落：没有连续碎段；对话没有连成墙
