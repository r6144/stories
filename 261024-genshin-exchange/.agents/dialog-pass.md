# 对话清理会话模板（D83）

**一句话启动**：按 `docs/07` D83 与本文档清理 `正文/chXX.md`。

一个会话只做一章。不要在本会话里接着做下一章。

## 固定上下文（只读这些）

1. `docs/07-待确认问题.md` 的 D83 一节（含“单音节应答不单独成段”“应答句去重”两条补充）。
2. `docs/06-写作规范.md` 的 3.3（6 条）与 3.2（6 条）。
3. `docs/09-声音与节奏.md` 的「四、反面样例」两条（含空转对白那条）。
4. `tools/out/chXX.audit.md`（候选清单；行号 = 正文行号）。
5. 本章正文，分块读：`read` 每次 400 行，用 audit 的行号直接跳。

不读：整份大纲、整份 `docs/05`、其它章正文、上一轮对话历史。

## 动手顺序

1. **先清 C1（一段换人）**：把不同说话人的话拆成独立段。只加空行，不增删内容；拆完读一遍，确认归属语没被拆断。

2. **再清单音节应答（最容易做坏的一步）**：`嗯／哦／欸／哎／是／好` 这类一声应答**不单独成段**。三种改法：
   - 并回对方段作叙述（“林志远嗯了一声”“周慧点了下头”）；
   - 换成动作，优先用**现场已有的物件**（茶壶、抽屉、手里那支没点的烟、门锁、碗），不要凭空加道具；
   - 直接删，让段落空白承担沉默。

   只留 3–5 处独立成段：承担转折的（“她没死。”之后那一声）、仪式与喜剧节拍（“愿意”“哎”“欸？”“我！”）。其余一律收掉。

3. **应答句去重**：把“嗯”换成叙述之后，不要一个模板用到底。同一种应答说法全章 ≤ 2 次，`嗯了一声` **至多 1 处**（带引号的「“嗯”了一声」另算，那是“他发出的那个声音”）。
   - 换法顺序：现场物件的动作 → 点头／没有反对／没接话／应了一声 → 换句式（“她把纸翻过去”“他过了一会儿才开口”）。
   - 判断标准是“这个人此刻会做什么”，不是“换个同义词”。同一个人反复用同一个小动作，比反复用“嗯”更假。

4. **清 A1/A2**：`X看着 ta。`／`X没有说话。`／`X沉默了一会儿。` 独立成段的，改成动作、并入邻段或删。**有后文回响的沉默保留**，每章留 1–2 处。

5. **最后清 B1/B2（空转回合）**：相邻两轮没有新信息的，合并成一句或改成叙述。判断标准只有一条：删掉这一轮，读者会不会少知道什么、少感觉到什么。两样都不少，就删。

6. **不做的事**：不改情节/canon/信息状态；不动 canon 台词；不改人物声纹（芙宁娜的三拍、纳西妲的比喻、妮露的短句）；不引入「」；不为字数删节拍；不为变而变（第 3 步只在确有重复时做）。

## 工具调用（省 step）

- **同一条消息里一次发出多条 `read`／`edit`**；不要一处一停。同一文件的多处独立改动（字符串互不重叠）也可以同批发出。
- 改完**统一跑一次** `dialog-verify`，不要改一处跑一次。
- 需要核对“只改了这些字”时，用逐字符 diff（`git show HEAD:…` 去掉空白后与工作区比对），不要通读全文找茬。

## 验收

```powershell
pwsh -File tools\dialog-verify.ps1 -Chapter XX
```

- `FAIL`：必须修（引号不配对、出现「」、连读空行、相邻重复段）。
- `换人` 必须为 0。
- `短看着`／`没说话`／`沉默` 各 ≤ 2。
- `单字段` 参考值：一章十几个到二十出头都正常（“愿意”“哎”这类节拍算数）；**连续三段以上都是单字段**就是问题，回去做第 2 步。脚本只报数，不设硬阈值。
- `答句` ≥ 3 会报警（同一种应答说法用了 3 次以上），回到第 3 步分散。
- 汉字变化：**−5% 以内**；允许小幅增加（把“嗯”换成动作会多几个字，ch15 是 +0.3%）。

## 收尾

1. `git status --short` 确认只改了本章与相关文档。
2. `git commit -m "[fix] 对话清理：chXX"`。
3. 在 `docs/10-进度与决策.md` 加一行：章号、主要手法、汉字/段数/对话段/单字段/答句的前后数字。不贴原文。
4. 更新 `tools/out/baseline.csv`（`pwsh -File tools\dialog-audit.ps1 -WriteBaseline`），让下一章的对比基准是清理后的状态。
