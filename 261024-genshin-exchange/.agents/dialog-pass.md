# 对话清理会话模板（D83）

**一句话启动**：按 `docs/07` D83 与本文档清理 `正文/chXX.md`。

一个会话只做一章。不要在本会话里接着做下一章。

## 固定上下文（只读这些）

1. `docs/07-待确认问题.md` 的 D83 一节（约 15 行）。
2. `docs/06-写作规范.md` 的 3.3（4 条）与 3.2（6 条）。
3. `docs/09-声音与节奏.md` 的「四、反面样例」两条（含空转对白那条）。
4. `tools/out/chXX.audit.md`（候选清单；行号 = 正文行号）。
5. 本章正文，分块读：`read` 每次 400 行，用 audit 的行号直接跳。

不读：整份大纲、整份 `docs/05`、其它章正文、上一轮对话历史。

## 动手顺序

1. **先清 C1（一段换人）**：把不同说话人的话拆成独立段。只加空行，不增删内容；拆完读一遍，确认归属语没被拆断。
2. **再清 A1/A2**：`X看着 ta。`／`X没有说话。`／`X沉默了一会儿。` 独立成段的，改成动作、并入邻段或删。**有后文回响的沉默保留**，每章留 1–2 处。
3. **最后清 B1/B2（空转回合）**：相邻两轮没有新信息的，合并成一句或改成叙述。判断标准只有一条：删掉这一轮，读者会不会少知道什么、少感觉到什么。两样都不少，就删。
4. **不做的事**：不改情节/canon/信息状态；不动 canon 台词；不改人物声纹（芙宁娜的三拍、纳西妲的比喻、妮露的短句）；不引入「」；不为字数删节拍。

## 验收

```powershell
pwsh -File tools\dialog-verify.ps1 -Chapter XX
```

- `FAIL`：必须修（引号不配对、出现「」、连读空行、相邻重复段）。
- `换人` 必须为 0。
- `短看着`／`没说话`／`沉默` 各 ≤ 2。
- 汉字变化在 −5% 以内。
- `含3引号` 只作参考：同一个人停顿三次可以留，不必强拆。

## 收尾

1. `git status --short` 确认只改了本章。
2. `git commit -m "[fix] 对话清理：chXX"`。
3. 在 `docs/10-进度与决策.md` 加一行：章号、主要手法、汉字/段数/对话段的前后数字。不贴原文。
4. 更新 `tools/out/baseline.csv`（`pwsh -File tools\dialog-audit.ps1 -WriteBaseline`），让下一章的对比基准是清理后的状态。
