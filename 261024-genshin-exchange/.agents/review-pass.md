# 审校会话模板

> 一章一次，只读本章与本章卡。目标：剧情逻辑核实，不改声音、不为字数改文。

## 固定上下文（只读这些）

1. `AGENTS.md`
2. `docs/06-写作规范.md`（§十 交稿清单）
3. `docs/09-声音与节奏.md`（只在明显漂移时用）
4. `docs/08-章节写作包/chXX.md`（本章卡）
5. `docs/10-进度与事实账本.md` 的本章账本
6. 正文 `正文/chXX.md`
7. 需要核对时：`docs/01`（时间）、`docs/03` 十三（信息状态）、`docs/05` §四/§五、`research/canon-任务剧情.md` 的对应 §2.x

**不要加载**：其它章全文、整份 `docs/02`、整份 `docs/07`、之前的对话历史。

## 动手顺序

1. **对照本章卡**：目标 3–5 条是否都落地；beat 有没有缺、有没有多出卡里没写的大段。
2. **信息状态**：按卡和 `docs/03` 十三核对"谁知道什么"，找穿帮（尤其妮露、派蒙、林尼、阿蕾奇诺）。
3. **时间/地点**：与 `docs/01` 对齐；六天/七天这类脚程是路线差还是速度差，别写成赶路能力。
4. **道具/伤势/承诺**：卡里"物件/承诺"列的每一样，在正文里有没有交代去向；跨章承诺有没有回收。
5. **canon/AU**：卡里"本章的坑"逐条对照；改 canon 结果的一律不接受。
6. **只改必须改的**：结构断裂先改结构；润色与声音不动。

## 验收

- 卡里的每个目标都能在正文找到对应场景；找不到的，要么补，要么改卡（说明为什么不做）。
- 卡里"本章的坑"逐条过一遍，没有违反。
- `docs/01`/`docs/03` 与本账本三处不冲突。
- 引号是“”；数字按 `docs/06` §一。
- 改动后跑 `pwsh -NoProfile -File tools\docs-lint.ps1`。

## 收尾

1. `git status --short` 确认只改了本章与相关文档。
2. `git commit -m "[fix] chXX 审校：一句话说明"`，具体改了什么写进提交正文（不进 docs）。
3. 更新 `docs/10` 的本章账本（只记事实变化，覆盖式）；进度表里把本章内容状态改成"已审（D 编号）"。
4. 决策若新增：`docs/07` 加一行；卡的"坑"补一条。
