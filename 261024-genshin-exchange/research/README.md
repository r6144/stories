# research/

考据笔记与来源摘录。

- `docs/05-官设考据.md` 是整理后的来源清单与原文摘录，优先看那里。
- 本目录按日期放章节前的二次核对笔记：
  - `2026-10-24-森林书与兰那罗料理.md` — 第 2 章森林书/料理线来源与取舍。
- 本目录用来放：
  - 章节写作前的二次核对笔记（例如 4.7 完整对话的关键句）；
  - 需要反复查的设定对照表；
  - 不进入正文的参考材料。
- `research/raw/` 与 `research/cache/` 已在 `.gitignore` 中忽略，用来放临时抓取的原文/JSON，不提交。

## 原则

1. 不把二创当 canon。
2. 引用官方文本要短；大段原文只做内部参考，不放进正文。
3. 不确定的设定标“待考”，不要硬编。
4. 每章开写前，至少核对一次该章涉及的 canon 任务文本。
