# 风格基线

> 目标不是「每章数字一样」，而是「读起来是同一个人写的」。写完一章，用 `tools/style_metrics.ps1` 看一眼；偏离太多就回来看样例，重写开头 500 字找感觉。

## 一、目标区间

| 指标 | 目标 | 警告线 |
|---|---|---|
| 单章字数 | 9,000–11,000 | <8,000 或 >12,000 |
| 段落平均长度 | 100–180 字 | <70 或 >250 |
| 短段落（<40 字）占比 | <15% | >25% |
| 长段落（>350 字）占比 | <10% | >20% |
| 对话比例（引号内字数/总字数） | 35%–45% | <25% 或 >55% |
| 平均句长 | 18–30 字 | <14 或 >36 |
| 连续短段落 | 不超过 3 段 | 连续 5 段以上 |

> 注意：对话密集的场景（争吵、告白、婚礼誓词）可以短暂超出；不要为了指标把对白写成大段说明。

## 二、风格样例（叙述）

> 这是「感觉」的样例，不是正文；写的时候不要照抄，只找节奏。

死域没有风。不是安静，是风走到边界就停了，像被什么看不见的东西含住。紫色的雾贴着地面，慢慢地、有耐心地长，长过树根，长过石头，长过一具还温热的身体。她闻见甜味，先是熟透的果子，后来是铁锈，最后是一种说不清的、像旧书发霉的甜。她知道那是什么——游戏里，它叫侵蚀；在这里，它只是疼，从手指开始，一寸一寸往里走。

派蒙在身后喊她的名字。她想回头，脖子却像被谁按住了。那些蕈兽并不快，甚至称得上笨拙；可她每一次抬剑，都像在挥一截不属于自己的骨头。她听见自己喘气，听见剑刃砍进菌盖的闷响，听见远处有人跑过来，裙摆擦过草叶。然后，世界从边缘开始变黑。

她最后看见的，是一截红色的头发。有人把她翻过来，手掌贴在她胸口，像在确认什么。那双手很暖。她想说「别救我了」，可嘴里只涌出一口黑色的水。再后来，连疼也远了。

## 三、风格样例（对白）

> 纳西妲的比喻、妮露的短句、芙宁娜的舞台腔，要能不看名字也分得出来。

「你觉得，梦和现实的区别是什么？」纳西妲问。

妮露想了很久，久到手里的甜汤都快凉了。「梦里的花，闻不到味道。」她说，「现实里的花，就算不好闻，也是真的。」

「哦？」芙宁娜把杯子放下，声音像在舞台上，「那我呢？我演了五百年，算梦还是算现实？」

纳西妲看着她，没有笑。「算你。演了五百年，也是你。」

## 四、防漂移检查

每写完 2 章，做一次：

1. 跑 `tools/style_metrics.ps1`，和上表对比。Windows 默认执行策略可能拦 .ps1，用：
   `powershell -NoProfile -ExecutionPolicy Bypass -File tools/style_metrics.ps1 -Path 正文/ch01.md`
2. 读本章开头 500 字 + 上一章开头 500 字，看语气是否一致。
3. 搜「仿佛」「似乎」「某种」「说不清」「不知道过了多久」；如果一章超过 5 次，删掉一半。
4. 看对话：把角色名遮住，能不能靠语气认出是谁。
5. 看段落：有没有连续 5 段以上都是一两句话；如果有，合并/扩写。
6. 看 canon：有没有把任务流程写成流水账；有没有大段解释读者已经知道的事。

## 五、如果漂移了

- **变短、变快、像大纲**：回到样例，重写开头 500 字；把「她做了什么」改成「她感觉到什么」；加一个感官锚点。
- **变长、变腻、像散文**：删形容词，删比喻，保留一个最准的；把大段心理改成动作/对白。
- **对白变多、像剧本**：把连续对白拆开，加动作/环境/停顿；每 6–8 句对白插一个叙述段。
- **人物声音混**：回到 `docs/03-人物设定.md` 的「声音」节，各写三句只有他会说的话，贴在本章开头，写完删掉。
