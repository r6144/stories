# 官设考据

> 目的：把「官方说过什么」和「我们编了什么」分开。写正文时，canon 部分尽量贴；AU 部分要自洽，且不能反过来污染 canon 角色的核心。
>
> **本文是 canon/AU 的唯一来源（SSOT）。** 其他文档提到 canon/AU 时只做索引；发现冲突以本文为准。改设定先改本文的「Canon / AU 对照表」，再改派生文档与正文。

## 一、来源等级

| 等级 | 来源 | 用法 |
|---|---|---|
| A | 游戏内任务文本、角色故事、角色语音、官方 PV | 最高依据；可直接引用/改写 |
| B | HoYoWiki、BWIKI 任务页/角色页、Project Amber 数据库 | 用来核对 A；引用时注明 |
| C | 官方版本前瞻、版本新闻、开发者访谈 | 时间/版本信息 |
| D | 玩家考据、攻略、论坛 | 只作线索；不单独作为 canon |

本文主要使用 B 级来源 + A 级文本摘录；关键处标注「待考」。

### 2.10 荧的知识边界（本文 AU）

- 荧在现实世界通过女主的电脑知道《原神》存在，但她是旅行者，不是宅女；对游戏不感兴趣，也怕「提前知道提瓦特未来」造成时间悖论。
- 她刻意回避 3.0 之后的剧情；她不知道女主在提瓦特经历了什么，也不知道穿越机制。
- 她在婚礼当天早上回到提瓦特，先向派蒙承认「我不是她」；婚礼前，三人/派蒙把女主这一年零九个月告诉她。她不是从游戏里读到的，是从爱她的人口中听到的。
- 这样安排的好处：保留「荧不知道那边怎么了」的孤独；避免她变成「全知玩家」；让婚礼前的交流成为情感场景，而不是信息 dump。

## 五、二创陷阱

1. **「168 次轮回」**：游戏没有确切数字；派蒙说的是「数不清」。可以写女主的弹幕记忆里有「168」这个梗，但不要当官方设定。
2. **「花神诞祭是时间循环」**：官方明确否定；是共享梦境 + 记忆删除/重建。女主知道这是共享梦境，不会把它当时间循环；不要让她或旁白把「重复的一天」写成时间循环。
3. **「神像复活是通用机制/纳西妲的能力」**：不是。纳西妲只能感知、报告；她不能随意复活。本文的复活是若娜瓦按天理规则特批的唯一一次「借命」；普通人死了就是死了。
4. **「若娜瓦是死神/反派」**：她是四影之一、死之执政；不是「冥王」，也不是「坏人」。她按规则办事。
5. **「芙宁娜是厄歌莉娅的女儿」**：不是。厄歌莉娅把职责交给芙卡洛斯；芙宁娜是芙卡洛斯造的人类容器。花灵把她视为「继承者」是信仰层面；本文用「芙卡洛斯/芙宁娜一体两面」来解释。
6. **「芙宁娜其实有隐藏力量」**：没有。她的价值不在力量。
7. **「帕丽莎是人类婴儿/女主转世」**：不是。她是花苞所生的新花灵，非人类、非人形、非怀孕；不是女主的转世/替身。
8. **「纳西妲是小孩」**：外形是孩童，心智是 500 岁的神。不要幼态化。
9. **「妮露是傻白甜」**：她单纯，但不傻；她的直觉和勇气很强；她有自己的判断。
10. **「命运的织机可以穿越/复活/实现愿望」**：不是。它创造/植入记忆；本文的穿越是副作用。
11. **「荧在现实世界用元素力」**：不能。她的身体是普通人；她只能靠经验和体力。
12. **「婕德是芭别尔的亲生女儿」**：不是。婕德的母亲是优菲·欣迪，父亲是哲伯莱勒；芭别尔是收养/接纳她的主母。芭别尔骂她「叛徒的女儿」「杂种狗」，最后婕德取回母姓。
13. **「芭别尔是纯恶/纸片反派」**：不是。她确实用信仰做权力、杀人、把婕德交给人做实验；但她也确实把婕德当女儿（扭曲的爱），也确实想给沙漠带来学校、书籍、国家。不要洗白，也不要写成哈哈大笑的恶人。
14. **「哲伯莱勒只是失踪/被芭别尔的人接走」**：不是。他在 3.1 结尾先在御座上用祷文反杀萨梅尔（假胜利），后为阻止取得权柄的萨梅尔、打开圣显厅大门，主动进入「永恒的梦乡」，与萨梅尔同归于尽，只留下斧头；婕德之后**自己去塔尼特投奔**。
15. **「婕德杀光了所有塔尼特人」**：不要这么写。部族作为共同体灭亡，有人逃/活；游戏里她杀穿营地、杀芭别尔，但不是「一个不剩」的猎奇屠杀。
16. **「妮露是花神转世/女儿/血脉」**：不是。她只是花神祝福过的凡人：美貌、舞蹈、在塔尼特保护她的直觉；没有超自然力量、神谕、使命、权力；她永远不知道。
17. **「花神=草神/树王」**：不是。花神是娜布·玛莉卡塔，赤王/大慈树王的友人；甘露花海是厄歌莉娅的遗体/甘露，不是花神的。花神的永恒绿洲在千壑沙地。
18. **「3.6 祭水之仪是芙宁娜开大」**：不是。仪式的主力是斯露莎/灵光/母树/甘露；芙宁娜是媒介/承认，纳西妲是见证，妮露是舞，林晚是记忆。
19. **「纳西妲在 3.6 全知/解决一切」**：不是。她能听见母树的疼，但不能替代花灵的仪式；她也会判断错、也会害怕。
20. **「6.6 的婕德后续/柯莱花神碎片」**：林晚的知识截止 5.8 前瞻，不知道 6.6；本文不写、不引用、不矛盾。柯莱的花神碎片与妮露的祝福是两码事。
21. **「那先朱那是纯恶」**：不是。他是「用荣耀做权力」的人，和芭别尔互为镜像；他的诉求有可悲之处，手段不可取。
22. **「婕德是疯批美人」**：不是。她的暴力是芭别尔塑造的；她仍有温柔、幽默、对奔奔的爱、对朋友的忠诚。写她的可怕，也要写她的可爱。
23. **「婕德一开始就允许林晚说芭别尔坏话」**：不是。两人是相互的好友，但塔尼特剧情开头的婕德会把「主母」和「朋友」分得很清；一码归一码，她不会让林晚当她的面否定芭别尔。
