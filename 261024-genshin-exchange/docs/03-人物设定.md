# 人物设定

> 写每章前先看「信息状态」表。人物知道什么、不知道什么，比人物说什么更重要。
>
> **本文是人物与信息状态的唯一来源（SSOT）。** 其他文档提到「谁知道什么」时只引用；发现冲突以本文的信息状态表为准。

## 一、女主（林晚）

### 基本信息

| 项 | 设定 |
|---|---|
| 年龄 | 22 岁 |
| 学历 | 二本，国际贸易专业，刚毕业 |
| 居住 | 和父母同住，老小区，自己的房间 |
| 职业 | 深渊主播，直播间「晚风打深渊」，观众不多，收入勉强够饭钱 |
| 感情 | 直女，没有恋爱经验；喜欢妮露 × 纳西妲的 CP（粉丝/同伴的喜欢，不是爱情）；手机壁纸是两人同人图 |
| 游戏知识 | 到 5.8 前瞻为止；知道伊涅芙的外表/技能，不知道 5.8 剧情/活动；熟悉 3.0–4.7 剧情、角色、机制 |
| 穿越身份 | 荧（身体、名字、社会关系） |
| 真实结局 | 2027-04-19 借命到期，现实世界身体死亡；意识回到现实后即刻死亡 |

### 外貌

现实里的她：普通身高，微胖，黑发，戴眼镜，常年熬夜的黑眼圈，手指有键盘茧。她的房间很乱：外卖盒、充电线、妮露立牌、纳西妲挂件、写着「今天一定投简历」的便签（没动过）。

提瓦特里的她：荧的身体，金发金瞳，比她自己高，比她自己瘦，手臂有旅行留下的疤。她第一次照镜子时，既觉得「好漂亮」，又觉得「这不是我」。

### 性格

- **观察力强**：直播练出来的，能同时看弹幕、看 boss 抬手、看血条；在提瓦特，她先看人的手和眼睛。
- **自嘲**：用玩笑化解尴尬；越紧张越贫。
- **心软**：嘴上说「我只是来看剧情的」，实际上看到别人受苦就忍不住。
- **控制欲**：她以为「知道剧情」就等于「知道怎么让人幸福」；这是她最大的毛病。
- **怕死**：她死过一次，所以比谁都怕死；但她也比谁都清楚，自己这条命是借的。

### 想要 / 需要

- **想要**：活下去；看到妮露/纳西妲/芙宁娜幸福；看到婚礼。
- **需要**：接受自己只是故事里的一段插曲；学会「不控制」；学会被爱，也学会告别。

### 弧光

1. **第一章**：我死了，又醒了。我以为我在做梦，可这不是梦。
2. **第二章**：我可以靠知道剧情活下去。
3. **第三章**：为什么剧情不按我知道的走？
4. **第四章**：原来我不能替别人醒来。
5. **第五章**：原来「知道」和「改变」是两回事。
6. **第六章**：原来没有力量的人也能救场。
7. **第七章**：原来有些痛是必须的。
8. **第八章**：原来我可以只是「在场」，不做红娘、不做英雄。
9. **第九章**：原来我的故事也可以只是一个睡前故事。
10. **第十章**：原来她们记得我。

### 声音

- 内部：吐槽多，短句，游戏术语乱飞；「这要是游戏，我早闪了。」
- 外部：对长辈用敬语；对同龄人半开玩笑；对妮露会放软；对纳西妲会认真；对芙宁娜会接梗。
- 紧张时：说话变快，重复「没事没事」；真正难过时：不说话，或者只说「嗯」。
- 不说脏话。急的时候靠贫嘴、叹气、把耳机拉下来，不靠粗口。
- 她不会说漂亮的抒情句；她的深情藏在行动里（做饭、修设备、记住别人的口味）。

### 关键台词方向

- 「我不是荧。但我在努力不辜负她的身体。」
- 「我知道结局。可我不知道怎么让你们走到结局。」
- 「你不是没有力量。你只是没有机会用你自己。」
- 「如果这就是我的睡前故事，那它是个好故事。」

### 她留下的东西

- 给妮露：一双舞鞋（鞋底缝了她的名字）。
- 给纳西妲：一本手写故事书（她知道的提瓦特故事，但写成童话）。
- 给芙宁娜：一顶小皇冠（「你可以不当神」）。
- 给派蒙：一封信 + 一张留影机照片（四人+派蒙的合照）。
- 给父母：一封寄不到的信（荧后来在现实世界找到）。

## 二、荧（原版）

### 基本信息

| 项 | 设定 |
|---|---|
| 身份 | 旅行者，降临者；寻找哥哥 |
| 性格 | 温柔、好奇、坚韧、护短、有点促狭 |
| 现实世界身份 | 林晚的身体；健身教练、户外领队 |
| 回归 | 2027-04-19，女主死亡同一刻，回到提瓦特；婚礼当天早上在派蒙身边醒来 |
| 游戏知识 | 知道《原神》存在、女主是玩家；不玩、不主动看 3.0 后剧情；不知道穿越机制；婚礼前从三人口中得知女主的经历 |

### 现实线的荧

她醒来在一个没有元素力、没有魔物、没有派蒙的世界。她的第一反应不是恐惧，是**观察**：窗外的楼、墙上的钟、桌上的手机、门口的父母。

她很快学会：
- 手机、电梯、超市、外卖；
- 「上班」是什么；「工资」是什么；
- 怎么假装一个 22 岁的普通女生。

她学不会/不想学：
- 为什么人不能带剑；
- 为什么肉要切好才能吃；
- 为什么父母这么容易担心。

她的成长：
1. **适应身体**：女主的身体不强壮，她开始锻炼；后来成为健身教练。
2. **适应和平**：没有魔物，但有别的东西要保护（父母、驴友、陌生人）。
3. **适应身份**：她不是「林晚」，但她可以是「父母的另一个女儿」。
4. **回归**：她带着 1 年 9 个月的现实记忆回到提瓦特；她更安静，更珍惜人。

### 声音

- 对世界：好奇、直接；「这个怎么用？」「为什么不能带剑？」
- 对父母：一开始客气，后来自然；叫「爸、妈」时有点笨拙。
- 对驴友：可靠、简短、命令式；「跟紧我。」「别回头。」
- 对提瓦特的朋友：温柔，带一点疲惫；她见过太多离别。

### 关键台词方向

- 「我不是你女儿。但如果你愿意，我可以试着做。」
- 「这里没有魔物，但你们也会受伤。我还是想保护人。」
- 「我回来了。……我是不是错过了什么？」

## 三、妮露

### 基本信息

| 项 | 设定 |
|---|---|
| 身份 | 祖拜尔剧场舞者，「花神之舞」表演者 |
| 家庭 | 普通须弥家庭，父母宠爱；没上过教令院 |
| 元素 | 水元素神之眼；单手剑 |
| 性格 | 温柔、热心、单纯、关键时刻极勇敢 |
| 本文关系 | 女主第一个朋友；纳西妲的恋人；芙宁娜的挚友；帕丽莎的妈妈之一 |
| 婚姻 | 与纳西妲、芙宁娜是无性浪漫关系；有爱、有承诺、有日常，没有人类式生理欲望 |

### 她的核心

妮露不擅长「知识」，但她擅长**用身体理解人**。她不会说「元素反应」，但她知道什么时候该伸手、什么时候该退后、什么时候该把水交给草。

她的舞蹈不是表演，是**语言**：她说不出「我喜欢你」，但她可以跳给你看。

### 弧光

1. **第一章**：她背回一具尸体；明知她已经死了，还是把她背到神像前——不是相信神像能复活，而是相信草神也许听得见。
2. **第二章**：她学会绽放；她第一次为「活着的人」跳舞。
3. **第三章**：她在梦里；她不知道自己在做梦。
4. **第四章**：她自己醒来；她跳最后的舞。
5. **第五章**：她在教令院门前跳舞，明知会被抓。
6. **第六章**：她握住芙宁娜的手；她不知道芙宁娜没有力量，但她知道她害怕。
7. **第七章**：她陪芙宁娜度过崩溃；她不说大道理，只做饭。
8. **第八章**：她筹备婚礼；她想要一个「大家都在」的婚礼。
9. **第九章**：她在婚礼前知道女主已经走了；她等的是荧，也是那个「借来的旅人」留下的空位。
10. **第十章**：她嫁给纳西妲/芙宁娜；她记得女主；她成为帕丽莎的妈妈。

### 声音

- 软，短句，语气词多：「欸」「唔」「嘿嘿」。
- 紧张时重复对方的话：「你、你说什么？」
- 认真时突然很直：「我喜欢你。不是信徒那种喜欢。」
- 不会用比喻；她的比喻都是身体/舞蹈/食物。

### 关键台词方向

- 「你回来了。你回来了就好。」
- 「我不知道神像能做什么。我只是想，草神大人也许听得见。」
- 「我不知道元素反应是什么，但你让我跳，我就跳。」
- 「她值得有人陪。不是作为神，是作为她。」
- 「你是我最好的朋友。就算你骗过我，你也是。」

## 四、纳西妲

### 基本信息

| 项 | 设定 |
|---|---|
| 身份 | 小吉祥草王，草神，智慧之神；500 岁 |
| 身体 | 孩童外形；心智是 500 岁的神 |
| 性格 | 温柔、好奇、自省、孤独、爱用比喻、对自己是否合格充满怀疑 |
| 本文关系 | 女主的共谋/朋友；妮露的恋人；芙宁娜的恋人；帕丽莎的妈妈之一 |
| 婚姻 | 无性浪漫；她是神，不是人类，没有人类式生理欲望；不写性，不幼态化 |

### 她的核心

纳西妲是「被关在笼子里的神」：她能看见所有人，却很少有人看见她。她习惯了做「答案」、做「工具」、做「须弥的监护人」。三人关系让她第一次承认：她也可以被照顾。

**重要**：她的恋爱线必须写出 500 岁的心智、神性的孤独、成人式的克制。不写身体，不写性，不幼态化。她的爱是「我终于可以在一个人面前，不做神」。

### 弧光

1. **第一章**：她感应到异常；她跟若娜瓦谈判；她救了一个不该救的人。
2. **第三章**：她在梦里测试女主；她知道她不是荧。
3. **第四章**：她告诉女主「不能替别人醒来」；她和女主约定不剧透。
4. **第五章**：她被救；她第一次用自己的身体走路；她说「先做好自己，再做神明」。
5. **第六章**：她看见芙宁娜的伪装；她第一次对另一个「神」产生共情。
6. **第七章**：她在审判中按住女主的手；她知道不能改；她陪芙宁娜崩溃。
7. **第八章**：她接受妮露/芙宁娜的爱；她学习「被爱」。
8. **第九章**：她在穿越结束的那一刻知道女主走了；她给女主留婚礼座位。
9. **第十章**：她结婚；她成为帕丽莎的妈妈；她写下一个「借来的旅人」的故事。

### 声音

- 轻，慢，喜欢比喻：梦、书、树、月亮、鸟。
- 不常说重话；认真时句子变短。
- 会突然说一句很冷的笑话；然后自己先笑。
- 对妮露：温柔，带一点纵容；对芙宁娜：锋利，带一点逗；对女主：像朋友，也像更年长的神。

### 关键台词方向

- 「比喻是可以用已知理解未知的工具。」
- 「你不是变量。你是客人。」
- 「我不能替你醒来。但我可以在这里等你醒。」
- 「先做好自己，再做神明。」
- 「她借来的那段时间，是我们三个人最富有的日子。」

## 五、芙宁娜

### 基本信息

| 项 | 设定 |
|---|---|
| 身份 | 枫丹的「水神」（扮演者）；人类；4.2 后获得自由/神之眼 |
| 性格 | 戏剧化、骄傲、怕孤独、善良、爱吃甜食、喜欢小动物 |
| 本文关系 | 纳西妲的恋人；妮露的挚友；女主的朋友/「第一个不讨厌的旅行者」；帕丽莎的妈妈之一 |
| 婚姻 | 无性浪漫；不写性，不写身体细节 |
| 花灵的视角 | 花灵把芙卡洛斯与她视为「一体两面」，因此承认她是厄歌莉娅的继承者、祭水之仪的媒介 |

### 她的核心

芙宁娜是「用表演活下去的人」。她演了 500 年，演到忘了自己本来是什么样。她最怕的不是死，是「没有用」「不被需要」「被看穿」。

3.6 的祭水之仪是她第一次**不以表演的方式**被需要：她站在那里，害怕，但还是站着。那一刻，她不是「水神」，她是芙宁娜。

### 弧光

1. **第六章**：她独自到甘露花海；她戴着面具；她被花灵允许；她第一次「有用」。
2. **第六章**：她握住妮露的手；她哭；她第一次被人鼓励「你可以」。
3. **第七章**：审判；她的谎言被拆穿；她崩溃；她自由了，也空了。
4. **第七章**：纳西妲/妮露/女主围住她；她第一次不用演。
5. **第八章**：她筹备婚礼；她想要歌剧/蛋糕/所有人的注意；她学习「被爱不需要表演」。
6. **第十章**：她结婚；她戴着小皇冠；她成为帕丽莎的妈妈；她笑得很真。

### 声音

- 夸张、舞台腔、感叹号多；「哦，我亲爱的旅行者——」
- 紧张时说更多话；真正难过时反而安静。
- 对甜食/戏剧/小动物会长篇大论。
- 对纳西妲：撒娇 + 认真；对妮露：互相吐槽 + 依赖；对女主：接梗 + 偶尔真心。

### 关键台词方向

- 「我没有力量。我一直都没有。」
- 「你们找错人了。……但如果是你们，我可以试试。」
- 「我演了太久，久到忘了不演的时候该怎么站。」
- 「你可以不当神。你可以只是芙宁娜。」

## 六、帕丽莎（Parisa）

### 基本信息

| 项 | 设定 |
|---|---|
| 名字 | 帕丽莎（Parisa，波斯语，意为「像花灵/仙女一样的」） |
| 身份 | 甘露花海的花苞所生的新花灵；纳西妲、妮露、芙宁娜的独生女儿 |
| 形态 | 类似斯露莎的花灵形态：小、轻、会飘，有花瓣/翅膀一样的结构；**不是人类，不是人形** |
| 诞生 | 婚礼上，甘露花海的花苞在三人誓词后绽开；不是怀孕，不是生理生育 |
| 性格 | 好奇、爱问「为什么」、喜欢花/水/音乐；会模仿三位妈妈 |
| 本文关系 | 三人的女儿；派蒙/荧的「侄女」；女主取的名字 |

### 她的核心

帕丽莎是「花海的祝福」，不是「女主的替代品」。她不是人类婴儿，不需要哺乳/尿布/人类生理细节；她是一个新生的花灵，像花一样从花苞里醒来，第一眼看见三个妈妈。

她的存在让「家」继续长：女主没能看到的婚礼，开出了一个新的生命。她不是女主的转世，也不是女主的替身；她是她自己。

### 声音

- 像小铃铛，短句，爱重复：「妈妈？」「为什么？」「花海记得她吗？」
- 她会把三个妈妈叫得不一样：妮露是「跳舞的妈妈」，纳西妲是「讲故事的妈妈」，芙宁娜是「唱歌的妈妈」。
- 她学说话时，会把「借来的旅人」说成「借来的花」；没有人纠正她。

### 关键台词方向

- 「妈妈，那个借来的旅人是谁？」
- 「花海记得她吗？」
- 「那我也是借来的吗？」——纳西妲：「不。你是花海送给我们的。」

### 写作提醒

- 不写人类婴儿的哭声/哺乳/生理细节；她的「婴儿期」是花灵的成长期。
- 不让她承担「女主转世」的功能；她是新角色，不是复活。
- 她的出现要让婚礼更甜，而不是更沉重。

## 七、派蒙

### 基本信息

| 项 | 设定 |
|---|---|
| 身份 | 旅行者的向导/伙伴 |
| 性格 | 贪吃、爱吐槽、关键时刻可靠；对旅行者有极强依恋 |
| 本文关系 | 第一个知道女主不是荧的人；女主的锚；读者的心 |

### 弧光

1. **第一章**：她飞去维摩庄找妮露，来回近 1 小时；她回来时女主已经死了；她哭，觉得是自己飞得不够快。
2. **第二章**：她接受女主；但她还是想「原来的旅行者」。
3. **第三章/第四章**：她跟着女主循环；她开始叫女主「晚晚」。
4. **第五章**：她陪女主救纳西妲；她第一次说「你也是我的旅行者」。
5. **第八章**：她帮女主筹备婚礼；她隐隐知道女主有事瞒她。
6. **第九章**：她睡在女主旁边；她不知道女主已经走了；婚礼当天早上，她第一个见到荧，听她承认。

## 九、若娜瓦

### 基本信息

| 项 | 设定 |
|---|---|
| 身份 | 死之执政，四影之一，掌管死亡 |
| 性格 | 平、慢、冷、疲惫；像档案管理员；不是反派 |
| 本文功能 | 借命的规则来源；线结的调查者；结局的收线人 |

### 她的规则

- 她不能随意改变生死；她只能「借」和「收」。
- 她借命，不是因为善良，是因为「线结」可能影响整块布；她要查。
- 她查了 1 年 9 个月；最后发现是命运织机的副作用。
- 她收线时不会解释太多；她按规矩办事，但她会记住这条线。

### 声音

- 平，慢，少形容词；「生」和「死」像「借」和「还」。
- 偶尔好奇：「你为什么不逃？」
- 她不吓人；她只是**没有温度**。

### 关键台词方向

- 「身体是降临者的。灵魂不是。死亡记录有，归处没有。」
- 「先借她一条命。等织机查清，再收。」
- 「借来的，终究要还。」
- 「这条线，我记住了。」

## 十三、写作提醒

1. **妮露不是工具人**：她有自己的父母、老师、剧场、恐惧；她不是「红娘 KPI」。
2. **纳西妲不是外挂**：她不能预知一切；她也会错；她的智慧是「理解」，不是「全知」。
3. **芙宁娜不是卖萌**：她的戏剧化是盔甲；她的真心话很短。
4. **派蒙不是宠物**：她的忠诚和嫉妒都是真的；她也会难过。
5. **父母不是背景**：他们有自己的生活、担心、偏见、爱。
6. **荧不是替代品**：她有自己的 1 年 9 个月；她回到提瓦特后，不是「女主的替身」。
7. **女主没有恋爱线**：她是直女，对三人是粉丝/同伴/家人的喜欢；不要写她暗恋、争风吃醋、加入三人关系。
8. **三人是无性浪漫**：不写性、不写身体细节；纳西妲不是人类，不幼态化。
9. **帕丽莎不是人类婴儿**：她是花灵，不是怀孕/生育；不写人类婴儿的生理细节；她不是女主的转世。
7. **若娜瓦不是反派**：她只是规则；她的冷酷比恶意更可怕。
