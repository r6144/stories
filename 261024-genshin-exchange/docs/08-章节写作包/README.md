# 章节写作包（本章卡）

> 每章一张卡，**≤3k 字**，只写本章独有的东西：目标、beat、人物边界、本章的坑、钩子。
>
> **卡是派生文档，不是事实来源。** 时间→`docs/01`，人物与信息状态→`docs/03`，规则→`docs/04`，canon/AU→`docs/05`，决策→`docs/07`，上一章事实→`docs/10`。卡里不复制这些内容，只写“见 `docs/0X` §Y”。声音在 `docs/09`，文体在 `docs/06`，卡不重复。

## 用法

- 写/改第 X 章，只加载：`AGENTS.md` + `docs/06` + `docs/09` + **本卡** + `docs/10` 的本章账本。
- 卡里“需要时核对”只给章节号，去对应文件读那一小节，不整份加载。
- 卡里不写正文句子、不写行号、不记字数——那些在正文和 commit message 里。

## 模板

```markdown
# chXX 标题

> 状态：… ｜ 正文：`正文/chXX.md`
> 时间以 `docs/01` 为准，人物与信息状态以 `docs/03` 为准，canon/AU 以 `docs/05` 为准，决策以 `docs/07` 为准。本卡只写本章独有的东西。

## 一句话
## 时间 / 地点 / POV
## 本章目标（3–5 条）
## Beat（10–13 条，一条一个画面或事件）
## 人物与写法边界（只列本章出场、且容易被写错的）
## 本章的坑（不写什么、易错点）
## 结尾钩子
## 需要时核对（只给章节号）
```
