# 章节写作包

> 每章一份「开写前必读」的紧凑上下文。目标：3k–5k 字，够写完一章，不用加载整份设定集。

## 用法

- 新会话写第 X 章时，只加载：`AGENTS.md` + `docs/08-章节写作包/chXX.md` + `docs/06-写作规范.md`。
- 如果写作包里说「需要核对：……」，再去读对应的 `docs/01` / `docs/03` / `docs/04` / `docs/05` 的具体小节，不要整份加载。
- 写作包不是大纲的复制；它只包含**这一章**需要的：时间、地点、在场人物、目标、beat、声音、canon、不能忘的信息状态、不能写什么、结尾钩子。
- 写完一章后，更新 `docs/10-进度与决策.md`，再写下一章的写作包。

## 模板

```markdown
# chXX 标题

## 开写前一句话
## 时间 / 地点 / POV / 字数
## 本章目标（3–5 条）
## 场景 beat（带字数）
## 人物声音（只列本章出场）
## Canon 锚点（只列本章用到的）
## 信息状态（谁知道什么）
## 不能写什么
## 开头选项 / 结尾钩子
## 风格提醒
## 需要时再核对
```
