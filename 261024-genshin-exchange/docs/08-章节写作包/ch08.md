# ch08 甘露花海

> 状态：已审（D66/D69/D70）｜ 正文：`正文/ch08.md`
> 时间以 `docs/01` 为准，人物与信息状态以 `docs/03` 为准，canon/AU 以 `docs/05` 为准，决策以 `docs/07` 为准。本卡只写本章独有的东西。

## 一句话

3.6 压成节点；芙宁娜半途以私人身份来访，第一次在超自然事件里“有用”——不是力量，是承认。林晚在甘露雨里把阿迪勒交出去：不是忘掉，是可以继续。

## 时间 / 地点 / POV

- **时间**：第 191 天廊下 → 等三十多天 → 约 221 天象可见＋祖尔宛传话 → 224 出发 → 231 到花海（3.6）→ 约 240 仪式。现实线 2026-03 第一周（插叙）。
- **地点**：须弥城 → 千壑沙地最东端 → 铁穆山 → 花海/万种母树 → 锋刃林/跋松顶 → 荼泥黑渊渊底 → 染境 → 圣莲 → 花海北侧山口。
- **POV**：林晚（主）；芙宁娜短插段（厄歌莉娅）；现实线荧（山雨）。

## 本章目标

1. 走完 3.6，canon 压成节点，只写林晚视角的增量。
2. 芙宁娜隐去水神身份，以“被水承认的人”参与；有用的是承认/见证，不是发力。
3. 三人结缘；妮露全程不知她的身份与力量（D70）。
4. 林晚的治愈：阿迪勒之死的愧疚被雨接住，不是遗忘。
5. 埋 4.0–4.2：她知道审判会来，不能说；“我救不了你，但我可以陪你”。

## Beat

1. 廊下（191）：糖（碗/干花/铃/“这次我信”）；“偶遇”被纳西妲看穿；她听见西边的疼，千壑沙地是盲区；花海是花灵地盘，等她们开口；妮露“可是她们在疼”；派蒙闻到“甘露在烧”。
2. 又等三十多天＋约 221：教令院交接/调旧档/妮露排剧场；天象从须弥城可见；祖尔宛借燃烧的甘露传话；“我是去赴约”；224 出发，不带随从。
3. 途中（第 4 天傍晚，西线最东端；与 ch07 南线不是速度差）：废弃塔尼特哨站/“水。井。路。家。”的石板/井边写字的孩子；纳西妲的沙漠欠账（“对的方法，本来应该由教令院给她”）；妮露“一间也是开始”；阿迪勒的名字按住不说。
4. 铁穆山：裂缝/灰余晶；斯露莎（“谒颂主”“白飘飘”）；那先朱那以灵光绝唱/离渡之仪要她“成为光”；林晚看见芭别尔，不当面揭穿。
5. 花海·祖尔宛：认出纳西妲；闻出林晚“带着血”；双角的花冠要斯露莎/米希尔/拉沙鲁；母树像枯树桩；美里有疼。
6. 锋刃林/跋松顶：米希尔（荆棘/净罪巡礼）、拉沙鲁（跋尔松/困）；那先朱那守着俱利鼓；斯露莎唱四遍，两人跟上，额前长出双角的光。
7. 芙宁娜到访：祖尔宛说祭水要“被水承认的人”；朴素、破鞋，克洛琳德送到北侧山口，只放她一个；花灵认水不认名字，称“厄歌莉娅的后裔”；她怕母树；妮露递饼；纳西妲认出她；林晚差点说漏，被按住。
8. 现实线（2026-03 第一周）：荧带小团走山路遇暴雨，把外套罩在病愈女孩头上；山脚胸口发闷——“有人在她看不见的地方难过，而她过不去”。
9. 斯露莎要效仿西摩格牺牲；芙宁娜第一个说“不”（在斯露莎身上看见自己；只说“还有别的路”）；纳西妲“你的价值不在你的死”；林晚只讲婕德。
10. 进母树：荼泥黑渊渊底 → 母树上方 → 进入（下 → 上 → 再下）；染境里纳西妲听见母树的疼；妮露跳舞，祖尔宛认出花神之舞，与纳西妲交换眼神，不说。
11. 染境：哲伯莱勒的背影/塔德菈的声音/阿迪勒的脸；慈心不是神识；她念“阿迪勒”，慈心让她“带着他”。
12. 祭水之仪（母树内圣莲）：“我是芙宁娜。我替枫丹的水，承认这片甘露。”不称神、不发力；“我没有力量”只在厄歌莉娅幻象里；妮露的舞是“花”；三花灵唱灵光绝唱；先开花，再下雨；斯露莎活着（“吾辈的花还开着吗”）；天象熄灭。
13. 雨后：芙宁娜累倒（是人的累，不是把力量给出去）；妮露煮甜汤、问“喜欢吃什么”（蛋糕）；纳西妲/芙宁娜深谈“我也不配”——必须妮露不在场（D70）。
14. 坦白：阿迪勒（第二次杀人；妹妹妮娜；洗三天手）；纳西妲“可以陪你记得”；芙宁娜“我知道什么是不得不”；妮露“以后别一个人洗”；甘露里洗手，血洗掉、记忆没有；手还会抖；她说“我可以继续”。
15. 结尾：芙宁娜请求保密（“他们会以为天象是我熄灭的”）；对妮露只说“我来这里是我自己的事”，妮露答“你说不要问，我就不问”；祖尔宛给她开全的白花，“下次来，穿你自己的衣服”；“我不是原来的荧”，她答“我知道。你演戏不如我”；雾外克洛琳德等；信走商队。

## 人物与写法边界

- **芙宁娜**：不称神、不发力；舞台腔是薄防御，害怕要真；不肯领不是自己做的功劳；“我没有力量”只对厄歌莉娅说；4.2 前没得救。
- **妮露**：不知她的身份/力量（D70），只当普通枫丹客人；不能靠“没听见”含糊；能打（品梦一刻水/草合击）；不知自己的花神祝福，不说“花神之力”。
- **纳西妲**：不全知；千壑沙地是盲区；等花灵开口；认出芙宁娜≠知道她没力量；不替花灵做主。
- **林晚**：不是英雄，是“记得的人”；不能施法；对芙宁娜无浪漫箭头；知道结局、不知道代价（甘露会烧、雨是冷的）。
- **祖尔宛/花灵**：认水不认名字；“被遗忘是好事”；看出妮露的花神祝福，不说；只能借甘露传话。
- **斯露莎**：骄傲嘴硬，“吾辈”；不是纯搞笑；不能真死；不抢戏。
- **那先朱那**：不是纯恶；与芭别尔互为镜像；林晚不恨他，只不成为他。
- **派蒙**：鼻子灵/馋，不是超自然感知；讨厌沙漠还是去了（“你上次回来，手都洗破了”）。

## 本章的坑

- 不复述 3.6 流程：canon 写快，芙宁娜与林晚写慢；时间/路线按 D66。
- 不改 canon 结局：斯露莎活着、天象熄灭、雨落；“不靠牺牲”是结果，不是口号。
- 不让芙宁娜开大/称神/领功劳；不写她已得救。
- 妮露的知情边界（D70）：所有“神/没有力量”的对话避开她（深谈放到她打水时）；不能靠“她没听见”。
- 祭水之仪在母树内圣莲，不在花海外；进母树走荼泥黑渊渊底（下 → 上 → 再下），不是树皮孔洞。
- 慈心不是神识；染境是梦，不是关卡；里面的人是母树取下的记忆，不是灵魂。
- 治愈不是“一切都好了”：手还会抖；甘露洗掉血，不洗掉记忆。
- 阿迪勒是第二次杀人（第一次是艾方索）；妮娜是他妹妹，“救了她”不能抵；不是爽点。
- 花灵新娘只侧面（D69）：祖尔宛那朵只开一半的花/斯露莎嘴硬/米希尔荆棘/拉沙鲁跋尔松；留给 ch15。
- 千壑沙地是过场（D57）：不改 3.4/3.6；阿迪勒留到花海才说；ch07 南线与 ch08 西线不是速度差。
- 不写 6.6 婕德后续/柯莱花神碎片；不写系统/等级/命座；林晚不说脏话；提瓦特不写月份/季节。

## 结尾钩子

芙宁娜回枫丹，雾外克洛琳德等着；信走商队（每月一次）；林晚知道 4.0–4.2，决定“陪你”；“等水开始涨的时候”。
