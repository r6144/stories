### 一、4.4 沉玉祝珑（525～530，约 600～650 行）

**新动线（只走一遍）**：遗珑埠（到，信已读）→ 翘英庄（老陆头/罗叔/阿金/茶山/妮露到）→ 锦落庭（浮锦）→ 遗珑埠（小茂/沃特蒙泰涅/灵渊第一次）→ 积雾浦/伏仙洞/悬练山（三灵珠、浮锦坦白）→ 赤望台（投珑）→ 遗珑埠（老陆头下来接小茂、告别、包茶）→ 璃月港。

**关键改动**：投珑之后**不回翘英庄**。老陆头担心小茂，已经在遗珑埠等了两天；阿金、罗叔的告别、包茶、“机器的事我再想想”都在埠头完成。妮露也在这里回须弥，临走说“下次你带我去你家那边看看”（回收茶山那句）。

### 二、海灯节 + 闲云传说任务（532～537，约 800～900 行，本章主体）

**Canon 流程（读者熟悉，全部 summary）**：万民堂吃饭时偶遇远黛与漱玉（祖孙来问拼桌）→ 行秋打听（远黛当过侠客）→ 萍姥姥（歌尘浪市真君）→ 漱玉讲秘密 → 望舒客栈（魈）→ 绝云间北部 → 庆云顶（远黛）→ 回奥藏山，闲云讲真相 → 跟随回忆探知真相＋妖邪 → 远黛恢复记忆、化为白鹤 → “两天后”去璃月港找闲云 → 好梦留影神机 → 漱玉与旅行者做梦 → 闲云安慰 → 漱玉拜师。

**本文重点**（不重复 canon）：
- 林晚**知道**远黛的全部：白鹤、化形药只保十年、背约、健忘、闲云以血炼药、涂白自己驮小漱玉治病；她也知道漱玉父母因公殉职（canon 末尾纸条，正文不提前说破）。她什么都不能说。
- 她看的是：漱玉给奶奶夹菜、挑鱼刺、擦嘴；远黛把孙女叫成另一个名字，叫完自己愣住；漱玉笑一下，说“奶奶，我是漱玉”。
- 闲云对漱玉/申鹤/甘雨的“亦师亦母”，让林晚想自己的父母。不要写成林晚当场哭；她是回到住处才哭的。

**Beat sheet**：

1. **璃月港（532）**：海灯节开幕；港口的灯、人、卖花的、写春联的；林晚一个人，派蒙替她高兴。她来万民堂是因为游戏里见过这家店——香菱、卯师傅、锅巴；她要一碗龙须面。
2. **万民堂（532 晚）**：闲云（人形、红框眼镜、唠叨）带着申鹤进来；申鹤安静吃面；派蒙小声叫“那个女人”；漱玉和远黛来问能不能拼桌。远黛看着闲云，若有所思；闲云问“我们见过吗”；远黛说“你的眼镜……我好像见过”。林晚全知道，什么都不说。这桌饭要写得暖、挤、有油烟味。
3. **林晚的视角（532 夜）**：漱玉送奶奶回家，林晚送她们一段；漱玉在巷口说“奶奶有时候会变成一只白鹤。我见过”。她不敢跟别人说；她想求闲云收她做徒弟——“这样奶奶忘了，我也能替她记着”。这句话是本章钥匙。林晚想起自己十一岁那年。
4. **寻访（532～534，压缩）**：行秋（远黛当年的侠名/一把剑）；萍姥姥（“她收弟子，像养女儿。养大了，又怕她们飞”）；望舒客栈（魈，短，“她的事，让她自己想起来”）；绝云间/庆云顶（远黛的旧地，她几乎想起来；闲云远远看着；林晚替她拿包袱）。这些用一段一段的小场景带过，不写成攻略。
5. **奥藏山（535～536）**：闲云讲真相（白鹤/化形药/十年/背约/“我没有怪她”/“她把十年过成了一辈子”）；回忆压成一段（林晚跟着远黛的记忆，看见年轻的远黛和那个天衡方士，看见她选择留下）；妖邪出现，林晚护住漱玉和远黛（不写打怪，只写她挡了一下、手在抖）；远黛恢复记忆，选择变回白鹤——她走进雾里，变成一只鹤飞走；漱玉喊她，闲云抱住漱玉。
6. **好梦（537，“两天后”）**：见下节。
7. **霄灯（537 夜）**：海灯节正夜。漱玉写“奶奶”，林晚写“爸 妈”，闲云写“故人”。灯升上去；漱玉问“她们看得见吗”，闲云说“看得见”；林晚也问“我爸妈也看得见吗”，闲云说“看得见”——她不知道林晚问的是另一个世界的人。这一幕的戏剧反讽**不要点破**。
8. **拜师与告别（537 夜～538）**：漱玉求闲云收她（canon），闲云答应；林晚知道会发生，只是看着。闲云对林晚说“你也是。遇到难处，来找我”；林晚说“好”。她知道自己兑现不了这句，但不写“最后一次”（D36）。

## 好梦的设计（本章最关键的一场）

- **机器**：闲云的好梦留影神机，铜匣/灯/齿轮/仙曲；不解释原理，只写声音与光。
- **漱玉的梦**：奶奶是她记得的样子（人，不是鹤），在老家灶前做饭；奶奶说“奶奶要出趟远门”；漱玉说“带我”；奶奶说“你要留在这里，替奶奶看着”。醒来时她在笑，笑到一半才哭。
