# ch14 花海之约

> 开写前必读。本章 = 甘露花海婚礼（三人的誓词/空位/花灵/茶/舞/歌/书）+ 帕丽莎诞生 + 现实世界 2027 年 5 月的悼念与 7 月的退信 + 荧留在提瓦特的新生活 + 收束。**婚礼要甜，悲伤要安静；不要让读者觉得这份幸福是拿女主的命换来的。**

## 开写前一句话

她没能走进的婚礼，花海替她开完了；她写下的故事退回人间，落在两个一直在等她回家的人手里。

## 上一章事实账本（300–500 字，不贴原文）

第 13 章：4.7「睡前故事」。林晚回维摩庄（她 651 天前醒来的地方），送走只活在记忆里的卡利贝尔；织机完成，她意识到自己是被织进来的那根线。旧死域前，她确认自己当年没打过那些蕈兽；神像前道谢，说「不算浪费，就是不划算」。夜宿木屋，给三人/父母/派蒙写信，没拿出给林尼的那封（只有「谢谢你」）。第 +650～651 天赶路，黄昏到甘露花海；三人在准备婚礼；阿托莎的祝福带到；纳西妲送她到客棚，「明天见」。夜，若娜瓦收线：「借来的，终究要还」「这条线，我记住了」。现实 2027-05-01，荧在山区带队遇强对流，救下 6 人后猝死（医学无法解释）。第 +652 天清晨，荧在花海派蒙身边醒来；「是我。不是她。」三人已知；她们用物件把林晚的 651 天告诉荧；决定婚礼继续；「那就结给她看」「替她看完整场」。她们往花丛深处走，婚礼台子在前面，三把椅子摆得整整齐齐。

## 时间 / 地点 / POV

- 提瓦特：第 +652 天（婚礼当天，白天到夜）甘露花海；之后数月，甘露花海/须弥/维摩庄。
- 现实：2027-05（死、告别式、头七、母亲节、表彰、直播间）→ 2027-07（继承手续、邮箱、退信、阅读、回信）。
- POV：荧（婚礼，主）→ 女主父母（现实，独立小节）→ 荧/纳西妲（数月后，尾声）。现实线不写超自然解释；提瓦特线不写月份/季节。

## 本章目标

1. **婚礼**：写足「甜」——三人的誓词、茶、妮露的舞、芙宁娜的歌、纳西妲的书、派蒙的主持、花灵的歌、荧的位置。悲伤只放在空位、干花、舞鞋底的名字上；不哭丧。
2. **空位**：前排一把空椅，一朵压干的帕蒂莎兰（妮露第 5 章的旧物，去过塔尼特又回来）。三人不刻意回避；纳西妲在誓词里留一句「谢谢你，把我们带到彼此面前」，不提名字。
3. **帕丽莎**：誓词后花瓣落下，台角那个未开的花苞绽开；不是婴儿，是像斯露莎那样的小花灵；第一眼看见三个妈妈，第一声「妈妈」；名字是林晚生前取的。**背景设定（花灵嫁给花、上百朵花求婚、爱情是她的生命能源）只作轻笔，不展开。**
4. **不把幸福写成代价**：让角色自己拒绝「用命换来的」这个说法（芙宁娜/妮露的口气要轻，不要说教）；婚礼的甜来自爱、承诺、日常，不来自死亡。
5. **现实·5 月**：荧对危险没有责任；她因救人努力获得表彰，经济上也得到妥善补偿（一笔带过，不是重点）。父母早就觉得「这是穿越」；听到意外与医学难以解释的猝死，第一时间明白穿越结束了。他们悲伤，但不绝望、不裹足不前；分别思念女儿和荧。
6. **现实·7 月**：继承手续后拿到账号密码；邮箱里一封退信，正文是「这个故事本身」；SMTP 头信息怪异，没有地球规则可识别的发件人（技术细节一笔带过，可借年轻人/AI 之口）。父母由此知道女儿在提瓦特的经历：欣慰、伤感；包括林尼的爱情——高兴她得到真爱，比相亲对象温暖得多；心疼她爱得那么不容易。
7. **荧的新生活**：她留在提瓦特；和三人成为朋友/家人；学舞、听故事、吃蛋糕；慢慢拼出林晚的 651 天；她不是替代品，是见证人。包底那封没寄出的信（收件人「林尼」）她不拆、不寄。
8. **收束**：纳西妲把婚礼写进书，后来写成「借来的旅人」的童话；花灵唱它；帕丽莎听着长大。最后一句留白：花海没有等她，花海记得她，花海还在开花。

## 人物边界（先看这一节）

### 荧

- 她刚回到提瓦特，身体是自己的，记忆里有 651 天现实人生：手机、扫码、做饭、带团、父母、山路、雨。她对林晚几乎一无所知，只知道昨夜三人告诉她的那些。
- 她不是来「接班」的。她站在人群里，不知道自己算客人还是家人；派蒙拉她，妮露给她系围巾，芙宁娜给她头上插花，纳西妲说「你站在这里就好」。三个人都叫她「荧」，不叫她「林晚」。
- 她的悲伤是另一种：她没见过林晚，却欠她 651 天；她也不知道现实里的父母此刻以为她死了。她可以有一两次走神（想起山上的雨、母亲的外套），但不抢婚礼的情绪。
- 她的用处是具体的：帮妮露编辫子（编得不好）、端茶、拿书、拍照；她被帕丽莎问「你也是妈妈吗」，答「不是」，帕丽莎说「那你是朋友」。
- 声音：短、观察、命令；「为什么」「我来」「都上来了」；对三人客气而温柔，不套近乎。

### 纳西妲

- 她知道林晚死了；她也是三人里最早「知道」的那个（穿越结束那一刻，线断了）。她不解释，不安慰过度；她做具体的事：写书、泡茶、把空位摆好。
- 她的誓词要慢、准、有比喻，但不绕；她承认自己不会「过日子」，是妮露/芙宁娜教她的。
- 她对荧：温柔、不审视；「欢迎回来」之后，把荧当荧。
- 她不说「我知道未来」；她只说「我看见了某种可能」。

### 妮露

- 她嫁给纳西妲/芙宁娜；她记得林晚；她跳舞。她的悲伤在身体里：鞋底的名字、编到一半的辫子、多摆的一只杯子。
- 誓词短、具体、食物/身体/灯；「你们不用一直很厉害」。
- 她跳的那支新舞是第 5 章答应林晚的「新舞」；林晚没看到。她不说「为她跳」，只说「有个人没看到」。
- 她对荧：像对妹妹；教她舞步；「你踩我脚了」「再来」。

### 芙宁娜

- 她嫁给纳西妲/妮露；她戴林晚留下的小皇冠（「你可以不当神」）；她唱歌会跑调；她的誓词前半段舞台腔，后半段安静。
- 她拒绝「用命换来的」说法时最不客气，也最轻：「她要是听见，会翻白眼。」
- 她对荧：好奇、逗她；「你会唱歌吗」「不会我教你」；不把荧当林晚。

### 派蒙

- 主持婚礼；练习了很久；会哭，但会把流程走完；她是唯一同时爱着两个人的人。
- 对荧：「你赶上了」「你站我旁边」；不叫荧「晚晚」。
- 对帕丽莎：自称「派蒙阿姨」，得意。

### 帕丽莎

- 花灵，非人类、非人形；像斯露莎：小、轻、会飞，有花瓣/翅膀一样的结构，个头约一个成年人的头。
- 从花苞里开出；第一眼看见三个妈妈；第一声「妈妈」；出生就能记事、会说话；名字是林晚取的。
- 性格：好奇、爱问「为什么」、高兴就答应；她对「结婚」的理解是花灵的天性，不是人类婚嫁；**不写人类婴儿的哭声/哺乳/生理细节**。
- **背景设定只作轻笔**：花灵生来就是花的新娘；花不能走路，需要有人替它们记住春天；帕丽莎出生时有上百朵花向她求婚，她高高兴兴都答应了；以后每天都有花求婚。斯露莎/祖尔宛等也是花的新娘，但她们习惯了战斗与守护，爱情的成分被责任冲淡；帕丽莎在和平的须弥，能更充分地享受爱情。这些只在一两段里带过，不展开成设定说明。
- 不承担「女主转世/替身」的功能；她是她自己。

### 祖尔宛 / 斯露莎

- 祖尔宛主持祝福；提「花海三位母亲」（花神/大慈树王/厄歌莉娅）；她知道妮露身上的花神祝福，不说破；她说「花海有时候会送出新的花灵」。
- 斯露莎是「前辈」花灵；对帕丽莎好奇、得意；可以有一两句孩子气的话。

### 女主父母（现实线）

- 父亲林志远，母亲周慧；普通中年人；嘴硬心软；爱看剧、唠叨、做饭。
- **他们一直有「这是穿越」的感觉**：女儿一夜之间会做饭、叫「妈」叫得小心、不知道亲戚的名字、走路/握筷子的习惯变了；荧说过「我不是你女儿，但如果你愿意，我可以试着做」，母亲说「那就试着做吧」；父亲假装没听见。两个人都不问，因为怕一问，她就走了。
- 听到意外 + 医学难以解释的猝死，他们第一时间明白：穿越结束了。母亲说「她回去了」；父亲说「嗯」。他们知道走的是荧，也知道自己的女儿 21 个月前就已经不在了（或一直不愿承认）。
- 他们悲伤，但不绝望：母亲回去上班；父亲开始走路；他们去一次山脚，又回家；他们把直播间留着；他们分别思念女儿和荧（父亲想晚晚时看旧直播；母亲想荧时做她教的汤）。
- 对荧：他们知道那不是自己的女儿，但养了/一起生活了 651 天；母亲给她买过外套，父亲教过她开车；他们爱她，也知道她走了。
- 对林尼：读故事时才知道；高兴女儿被好好爱过；心疼她爱得那么难；「他不知道」这件事让他们沉默。

### 林尼

- 不出场；不知道林晚死；不收到信；不参加婚礼。他的「不知道」是这段恋情的结尾。可以只在父母读故事时被提及，以及荧在包底看到那封没寄出的信。

## 场景 beat

### 1. 婚礼的早晨（第 +652 天，甘露花海）

- 开场：花海的早晨从露水开始；荧在客棚醒来，派蒙已经在外头忙；花灵在挂花；三个人的眼睛都是红的，但都在笑。
- 妮露的舞鞋：鞋底缝着「林晚」；「她缝的。她说，这样她就在我脚底下。」「她还说，别踩太重。」
- 芙宁娜的小皇冠：尺寸不太对；「她量的时候一定在走神。」「她说，我可以不当神。」
- 纳西妲的书：空白的一本，她在写第一页；「今天的日子。以后怕忘。」
- 台角的花苞：白的，合得紧；荧碰了碰，凉的；纳西妲说「她给它取过名字，帕丽莎」。
- 空位：前排一把木椅，白布，椅面上一朵压干的帕蒂莎兰；荧问派蒙；派蒙说「一个朋友。一个借来的旅人」。荧不坐；派蒙让她站旁边。
- 荧被三人打扮：妮露给她系围巾，芙宁娜给她插花，纳西妲给她理头发；她们叫她「荧」。
- 荧帮妮露编辫子，编得不好；妮露笑「比她编得还差」；「她每次都编」。
- 祖尔宛/斯露莎/花灵到；祖尔宛对荧说「你就是另一个她」，荧说「我是荧」；祖尔宛说「我知道」。
- 不写「婚礼前的倒计时」；不写月亮/季节；用光、露水、花、茶、蛋糕。

### 2. 仪式（上午）

- 花灵的歌；客人坐在草地上；派蒙站在石头上主持，手里一片叶子（她的稿子）；她紧张，叶子掉了，斯露莎捡给她。
- 派蒙：「今天不许哭。她说的。」她自己先哭；客人笑。
- 三人一起走上小台，手牵手；妮露的鞋、芙宁娜的冠、纳西妲的书。
- 祖尔宛的祝福：花海三位母亲；「今天，花海把三个女儿嫁出去」；「愿你们的家，像花海一样，不需要围墙」。
- 三人的誓词（各一段，不要写成排比；每人的声音要能认出来）：
  - 纳西妲：承认自己不会过日子；承诺「问你，不替你决定」「把书放下」「在你不安的时候说，我在」；最后转向空位：「还有一个人，今天不在这里。……谢谢你，把我们带到彼此面前。」「我愿意。」
  - 妮露：短、具体；「记得你们什么时候饿，什么时候累」「你们不用一直很厉害」「灯我会留」「走远了我就去接；接不到，我就等」；「我愿意。」
  - 芙宁娜：舞台腔开头（「我演过很多场婚礼」），落到安静（「没有一次，是有人真的在等我回家」）；「我不演了。至少在家里不演」；「我唱歌会跑调，做饭会咸，早上起来头发很乱」；妮露/纳西妲插「愿意」；「我还没说完」「那你快说」「我愿意。」
- 三人一起说「我们愿意」。
- 茶：妮露倒四杯；三杯给三人，第四杯放在空椅前；茶是沉玉谷的；「她只投了茶」。
- 花瓣落下；花苞动；帕丽莎诞生（见 scene 3）。
- 荧的位置：她端着茶盘/拿着书，站在台侧；她不坐空位；纳西妲对她说「你站在这里就好。你是你自己」。

### 3. 帕丽莎（仪式高潮，但轻）

- 花苞一层层开；里面不是婴儿，是一个小小的花灵：花瓣一样的翅膀，轻，约一个成年人的头那么大；她睁开眼，第一眼看见三个妈妈。
- 第一声「妈妈」；三个人同时答应；妮露哭；芙宁娜哭得最响；纳西妲伸手接住她。
- 祖尔宛：「花海有时候会送出新的花灵。她是花海送给你们的。」不解释太多。
- 命名：纳西妲「她叫帕丽莎」；芙宁娜「她取的名字」；妮露「在她还没开的时候」；帕丽莎重复自己的名字。
- 花求婚：台边的花朝她弯下；斯露莎「它们在求婚」；帕丽莎「好呀」，一朵一朵答应；芙宁娜笑她「你比我还忙」；祖尔宛轻轻一句「花灵生来就是花的新娘。花不能走路，它们要有人替它们记住春天」。
- 荧与帕丽莎：帕丽莎「你是谁？」「我是荧。」「你也是妈妈吗？」「不是。」「那你是朋友。」「……嗯。」
- 派蒙「我是派蒙阿姨」；帕丽莎「派蒙阿姨」；派蒙得意。
- 不写「她像林晚」；不写「林晚转世」；不写人类婴儿细节。

### 4. 喜宴 / 舞 / 歌 / 书 / 照片

- 喜宴：茶、芙宁娜的蛋糕（太甜）、妮露的米圆塔、水果；派蒙吃撑；花灵喝露水；帕丽莎闻花。
- 芙宁娜的歌：新歌，四只杯子（早晨/夜里/走远的人/刚来的人）；她唱得不算好；妮露和声；纳西妲哼；帕丽莎转圈；花灵跟着。歌词只引 2–4 句，不要长。
- 妮露的新舞：第 5 章答应林晚的「新舞」；林晚没看到。上台前只说「这支舞，我练了很久。有个人没看到。」跳舞：脚踝、呼吸、衣摆、水声、花海的反应；跳到末尾，她重重踩一下鞋底，笑「踩着了」；纳西妲问「踩到什么了？」「一个名字。」
- 纳西妲的书：她写下「第 652 天。花海。晴。三个人结婚了。帕丽莎来了。蛋糕太甜。」；芙宁娜抗议；纳西妲说以后要把它写成一个故事：「一个借来的旅人，带来花，然后走了。」荧问「她会喜欢吗？」纳西妲「她会说，太狗血了。」
