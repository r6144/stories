# ch14 睡前故事

> 状态：已按 D64/D74/D81 修订 ｜ 正文：`正文/ch14.md`
> 时间以 `docs/01` 为准，人物与信息状态以 `docs/03` 为准，canon/AU 以 `docs/05` 为准，决策以 `docs/07` 为准。本卡只写本章独有的东西。

## 一句话

4.7 不是解谜，是送行：送卡利贝尔、送维摩庄、送自己。调查在维摩庄（643～645 天），她用六天走南线告别，651 天黄昏到花海，夜里死去；现实线荧救人，婚礼当天清晨回来。

## 时间 / 地点 / POV

- **时间**：4.7 第 643～645 天（维摩庄）→ 646～651 天南线六天 → 651 天黄昏花海 → 651 夜死 → 652 天清晨（两条线同一刻）。
- **地点**：维摩庄、村西旧死域/神像、南线（水天丛林、喀万驿、阿如村、活力之家、赤王陵、绿洲、塔尼特遗迹、铁穆山）、甘露花海、现实山区。
- **POV**：林晚（主）→ 若娜瓦（短插曲）→ 荧（现实/回归）。

## 本章目标

1. 走完 4.7：阿托莎、卡利贝尔、命运的织机、维摩庄被植入的记忆。
2. 让她意识到“这个故事太 meta”：她的穿越也是织机的副作用，织机完成，线要剪。
3. 让她平静地睡下：不恐惧、不怨恨，遗憾但满足；不是“值得”，是“不划算”。
4. 若娜瓦收线；现实线荧救最后一人后猝死。
5. 荧在婚礼当天清晨、派蒙身边醒来；婚礼前得知她的事；婚礼继续。

## Beat

1. 维摩庄委托：失踪的年轻人、阿托莎、巴兰、阿玛兹亚；她知道答案，只去送行。
2. 戴因：五大罪人、耕地机的眼睛、命运的织机；他被投放假记忆；藏宝地陷阱。
3. 卡利贝尔：睡前故事、给全村植入记忆、给丘丘人讲故事；“到了该休息的时候了”，消散。
4. 回村：阿托莎“我其实是被甩了吧”；纸花与祝福；画片；村民记忆被改成“父母接走他”。
5. 巡林站：访客簿上她自己四条、拉娜的工作笔记、三行训令、素达蓓、维摩庄的变化；教令院回话具体，但“管得慢”留着。
6. 锅边/树下：兰拉娜的新记忆、兰罗摩的树、“你每年都回来”；她没说“明年”。
7. 写信：三人、父母、派蒙；没有再写林尼——包里那封没拿出来。
8. 南线六天：水天丛林（蕈兽自己留住水）、喀万驿（迪希雅护货、水囊、盐）、阿如村（坎蒂丝、学堂、塔尼特遗民、远处看见妮娜不进去）、活力之家（成了医院、药钱记“路过的”）、赤王陵（远眺）、绿洲（婕德、奔奔、半条丝带、鹰羽）、塔尼特遗迹、铁穆山。
9. 睡下：651 天黄昏到花海；纳西妲送她到客棚“明天见”；她想起第一天、妮露的舞、纳西妲的比喻、芙宁娜的蛋糕、父母、林尼没变的那个魔术。
10. 若娜瓦：查了 651 天；织机完成、线头松了；“借来的，终究要还”“这条线，我记住了”。
11. 现实：2027-04-30 山区；卫星电话一格、周姨扭伤＋哮喘、包被冲下坡；报位置、救人、猝死；同伴只看见“猝死”。
12. 荧归来：652 天清晨；“是你吗”“是我。不是她”；纳西妲已知；三人告诉她这一年九个月；婚礼继续。

## 人物与写法边界

- **卡利贝尔**：成人神智、孩子般单纯、做错过事、不辩解；不是可怜小孩，也不是罪犯。他是林晚的镜子：都靠别人的记忆证明自己活过，区别是她借到了 651 天。
- **阿托莎**：不知道真相，以为他只是走了；不告诉她。声音轻、带笑、嘴硬，难过时先笑一下。
- **戴因**：简略；他的说明压成几段，林晚走神；“你的血亲”不是她的血亲，一两句带过。
- **婕德**：第 650 天绿洲当面给鹰羽；从运水队听说婚礼（36 人、三把椅子），基本尊敬、有点羡慕；不知道她要死；是她先说，林晚只确认。
- **妮娜**：阿如村学堂，远远看见，不进去、不说话、不相认。
- **坎蒂丝/迪希雅/活力之家**：不评价教令院好坏，只讲“以前/现在”；变化落在学堂、药箱、水价、祷词里，不写总结句。
- **荧**：短、观察、命令；她的死是“天灾 + 她的选择”，不是鲁莽。

## 现实线（本章是主线之一，不是插叙）

2027-04-30。荧带 7 人队进山；天气预报正常；卫星电话进沟后只剩一格；周姨冲上岩台时滑倒、脚踝扭伤，受凉后哮喘发作，装喷雾的包被冲下坡，荧下去取；她报出位置与人数，把最后一人送上去，坐下后猝死。不写打 120（救护车由救援队电台联系），不写超自然解释，同伴只看见“猝死”。她不是鲁莽——变天比预报快。

## 本章的坑

- 不解谜；不责怪卡利贝尔；不写“值得/圆满/完成使命”；她二十二岁，她想活。
- 不写“她其实没死”；帕丽莎不是她。
- 不写长篇遗言/正式告别；信是“以防万一”，不是遗书。
- 不写林尼赶到维摩庄/花海、不写他收到信、不写他出席婚礼。
- 若娜瓦不抒情、不解释规则；段落短、平。女主不知道她的名字，神像段只知道“有人在黑暗里说‘借’”。
- 现实线不写超自然解释；同伴只看见“猝死”。
- 三人不崩溃大哭：安静、有准备；可以红眼眶、可以沉默，最后要笑。
- 南线不写成游记/打卡：每站一个画面、一句话、一个动作；不写“须弥变好了”的总结句；不写“这是最后一次”。
- 赤王陵在西、圣显厅在北（悬在大坑上），两处；只远眺，不进去。
- 六天是路线不同 + 路上不歇，不是速度差。
- 记忆会淡去：她记得“织机完成了”和画片，不记得对话；派蒙只记得“一个眼睛很亮的人”。
- 荧的 POV：她不认识纳西妲与芙宁娜，认得妮露；不要让她知道提瓦特的 651 天。
- 不写 6.6、2026 战况、提瓦特月份季节。

## 结尾钩子

婚礼当天清晨；荧在派蒙身边；三人已经知道；婚礼继续——读者知道她走了，婚礼还没开始。
