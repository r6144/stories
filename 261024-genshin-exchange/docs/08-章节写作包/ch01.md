# ch01 第一天

## 开写前一句话

一个 22 岁的深渊主播，在 5.8 前瞻次日穿过屏幕，成了荧；她以为自己能靠游戏知识活下去，却在第一天就死在了死域里。妮露把她的尸体背到神像；纳西妲报告了异常；若娜瓦借给她一条命。她醒来，发现自己欠着一条命，而维摩庄的死域还在长。

## 时间 / 地点 / POV / 字数

- **时间**：2025-07-19 夜（5.8 前瞻次日）→ 提瓦特花神诞祭前 10 天。
- **地点**：现实世界女主的房间 → 维摩庄外森林 → 死域 → 维摩庄附近神像 → 维摩庄。
- **POV**：女主（主）；纳西妲/若娜瓦（短插曲，限知，不解释全部）。
- **字数**：10,000–11,000 字。

## 本章目标

1. 用最短篇幅建立女主的现实生活：22 岁、国贸毕业、待业、和父母住、深渊主播、妮露 × 纳西妲 CP 粉、直女、没有恋爱经验。
2. 让穿越发生得突然、物理、不可逆；她只知道 5.8 前瞻里的伊涅芙，不知道 5.8 剧情。
3. 让第一次死亡可信且可怕：不是「被蕈兽打死」，是「在死域里被一次次击中，侵蚀满了，身体从内部坏掉」。
4. 建立「借来的生命」规则：纳西妲感知/报告、若娜瓦查账、女主只听到碎片；神像不是许愿机。
5. 建立妮露：她是第一个接住女主的人，不是路人。
6. 结尾让读者知道：死域还在长，而女主第二天要去同一个地方。

## 场景 beat（带字数）

### 1. 现实·直播（2,000 字）

- 2025-07-19，5.8 前瞻次日。女主房间：外卖盒、旧笔记本、风扇、妮露立牌、纳西妲挂件。
- 直播「晚风打深渊」：观众不多，弹幕在聊昨晚前瞻里的新角色伊涅芙；她只知道伊涅芙的外表/技能，不知道 5.8 剧情，也没来得及看活动。她一边打深渊一边吐槽「我推的 CP 今天结婚了吗」。
- 她算这个月的饭钱/电费，发现刚好够，不用向父母开口——这是她唯一能理直气壮说「我没啃老」的地方。
- 父母在客厅看真人电视剧，母亲边看边骂反派，父亲假装不看、其实看得很投入；他们为她的工作吵架；母亲敲门让她早点睡；她敷衍。
- 她关播后登录，想再看一眼前瞻里的东西；屏幕闪过一行不像游戏 UI 的蓝白裂纹；她以为是显卡坏了；下一秒，房间的声音全部消失。
- **写法**：现实部分要短、密、有生活气；不要写太多游戏术语；她的房间要能让读者一眼认出「一个普通待业女生」。

### 2. 提瓦特·醒来（2,500 字）

- 潮湿的森林、腐甜的臭味、鸟叫。她趴在地上，脸埋在蕨类里。
- 派蒙喊「旅行者」；她抬头，看见一个漂浮的小人；她以为自己在做梦/整蛊。
- 身体不对：手臂有疤、腿更长、胸口更平、头发是金色的；她摸到自己的脸，尖叫。
- 派蒙以为她撞到头；她试图打开「菜单」「地图」「背包」，什么都没有；她开始恐慌。
- 远处传来孩子的哭声/村民的喊声；她看到紫黑色的雾、扭曲的树、红色的瘤。
- **写法**：身体 dysphoria 要具体：不是「胸变小了」这种概括，是「她低头，看见一截陌生的、被太阳晒成蜜色的手腕；她的痣不见了」。她尝试用游戏操作（按 M、开背包、切人）要写成手在空气里抓。

### 3. 死域·第一次死亡（3,000 字）

- 她认出死域：游戏里刷过无数次。她知道「侵蚀值」，但看不见条。
- 她冲进去救人（一个被困的村民/孩子）；她以为自己是荧，能打。
- 蕈兽不难，但她的身体不听话：挥剑太重、闪避慢半拍、元素力像被堵住。
- 第一次被击中：肩膀麻；第二次：手指不听使唤；第三次：她吐出一口黑色的水；她闻到自己的内脏在腐烂。
- 她听见派蒙在喊；她想说「别过来」；她倒下。最后的感觉是冷，像根须从骨头里长出来。
- 派蒙的哭声；脚步声；一个红发女孩把她翻过来；「坚持住」；她被背起来；视野摇晃；神像的光。
- **写法**：不要写「血条清空」；写身体。侵蚀不是毒，是「有东西从伤口往里长」。她死的时候不要英勇；她害怕、后悔、想吐。妮露的出现要像「有人把溺水的她拽出水面」，不是「救援队来了」。

### 4. 神像·若娜瓦的账本（2,500 字）

- 黑。不是昏迷的黑，是「没有梦」的黑。
- 她听见两个声音：一个轻而急（纳西妲），一个平而慢（若娜瓦）。
- 纳西妲：「她的记录不对。」若娜瓦：「身体是降临者的，灵魂不是。死亡记录有，归处没有。」
- 若娜瓦翻账本/线轴：这条线「不是这个织机上的」；「先借她一条命，等织机查清，再收。」
- 纳西妲：「她会记得吗？」若娜瓦：「会记得疼，不会记得全部。」
- 女主想说话，只发出气音；她听到「借」「还」「线结」「织机」几个词。
- 光；水；她猛地吸进一口气。
- **写法**：不要解释若娜瓦的完整规则；只给碎片。纳西妲不是「求情的小女孩」，她是「按规矩报告、但想救人」的神。若娜瓦不是「死神小姐姐」，她是「疲惫的档案管理员」。这段可以有一点神话感，但不要写成法庭辩论。

### 5. 维摩庄·醒来（1,500 字）

- 她在一张木床上醒来；妮露在拧毛巾；派蒙扑上来。
- 她第一句话：「我是不是死了？」妮露：「你回来了。」
- 她看见水盆里自己的倒影：荧的脸。她崩溃；妮露抱住她；派蒙在旁边手足无措。
- 妮露自我介绍；这是维摩庄；她把女主从死域背到神像；「神像发光了，然后你就活了。」
- 女主意识到：复活只发生在提瓦特。如果穿越结束，这具身体会恢复原状；现实世界里的她，会死。她没有说出来，只是把手按在胸口，确认心跳还在。
- 晚上，村民送来汤；女主吃不惯；妮露给她加糖；派蒙解释「旅行者以前不这样」。
- 女主告诉妮露：我不是原来的荧。妮露愣了一下，然后说：「那你现在是谁？」女主：「……一个不知道该怎么回去的人。」妮露：「那就先吃饭。」
- **写法**：这是全章的情感落点。妮露的「那就先吃饭」要轻，不要煽情；女主哭要克制，她不想在陌生人面前哭。

### 6. 结尾·死域还在（500 字）

- 窗外，维摩庄边缘的树林泛着紫光；一个村民说，死域又长大了，村里已经有人病倒。
- 妮露：「明天我陪你去看看。」女主：「你不怕吗？」妮露：「怕。但总不能让它长到村子里来。」
- 女主看着她，第一次觉得：也许我留下来，不是为了看剧情。
- **钩子**：她刚死过一次，明天要去同一个地方。

## 人物声音（只列本章出场）

### 女主（林晚）

- 内部：吐槽多，短句，游戏术语乱飞；「这要是游戏，我早闪了。」
- 外部：对长辈用敬语；对同龄人半开玩笑；对妮露会放软；紧张时说话变快，重复「没事没事」。
- 真正难过时：不说话，或者只说「嗯」。
- 她不会说漂亮的抒情句；她的深情藏在行动里。
- **不要**：让她一开始就接受穿越；让她用游戏知识秒杀；让她对妮露一见钟情（她是直女，对妮露是粉丝/同伴的喜欢）。

### 派蒙

- 吵，直接，食物比喻多；「呜哇」「欸嘿」「肚子饿了」。
- 对女主：从「旅行者」到「你」；她一开始以为女主是撞坏了头。
- 真正害怕时：声音变小，重复「怎么会」。
- **不要**：让她只会吃；她在本章是唯一试图救女主的人，她的恐惧要真。

### 妮露

- 软，短句，语气词多；「欸」「唔」「嘿嘿」。
- 紧张时重复对方的话；认真时突然很直。
- 她不是「傻白甜」；她看到女主死而复生，会怕，但她还是把人背到了神像。
- **不要**：让她一见面就完全信任女主；她的信任是「你救了村里的人/你也是受害者」，不是「你是穿越者好酷」。

### 纳西妲

- 轻，慢，比喻；「记录不对」「她不该死在这里」。
- 她不是全知；她只知道「信息不对」，不知道女主从哪来。
- **不要**：让她直接解释全部规则；让她复活女主（她只是报告/请求）。

### 若娜瓦

- 平，慢，少形容词；「借」「还」「记录」「线结」。
- 她不吓人，只是没有温度；偶尔一丝好奇。
- **不要**：让她抒情；让她变成反派；让她详细解释织机。

## Canon 锚点（只列本章用到的）

- **死域**：会累积侵蚀；侵蚀满了会死；需要清除死域瘤/枝节。本文用感官写，不写数值。
- **蕈兽**：不致命，但在死域里被击中会加速侵蚀。
- **维摩庄**：须弥雨林村庄；附近有死域（本文 AU 但合理）。
- **神像**：七天神像，连接地脉/元素/神明；须弥的是草绿色。神像不是通用复活术。
- **纳西妲**：3.0 时被囚禁在净善宫；能通过虚空/梦境/神像感知；她是七执政之一，发现异常必须报告天理/四影。
- **若娜瓦**：死之执政，四影之一；掌管死亡；不是反派。
- **命运的织机**：4.7 的装置；本章只出现「织机」这个词，不解释。
- **荧的身体**：金发金瞳、旅人服、剑；3.0 时已解锁草元素；但女主不熟练。

## 信息状态（谁知道什么）

- **女主**：知道剧情到 5.8 前瞻；知道自己死了；不知道借命的具体规则；不知道纳西妲/若娜瓦谈了什么；意识到「复活只在提瓦特，穿越结束我会死」。
- **妮露**：知道女主不是原来的荧；不知道她死过一次、不知道借命。
- **派蒙**：知道女主不是原来的荧；不知道借命；以为「旅行者被死域影响了」。
- **纳西妲**：知道女主的信息不对；知道借命；不知道具体哪天到期。
- **若娜瓦**：知道线结；开始调查。

> 注意：女主在本章**没有**告诉妮露「我会死」；她只说「我不是原来的荧」。妮露**没有**问「那原来的荧呢」——她先问「那你现在是谁」。这个顺序很重要。

## 不能写什么

- 不写系统面板、等级、HP、伤害数字、抽卡、命界。
- 不写「叮，获得……」「宿主」「任务奖励」。
- 不写「神像随便复活人」；不写「纳西妲有复活能力」。
- 不写女主用游戏知识秒杀蕈兽；她第一天就死了。
- 不写妮露是「工具人」；她有自己的判断和恐惧。
- 不写若娜瓦的长篇规则说明；只给碎片。
- 不写「女主其实没死/只是昏迷」；她真的死了，复活是借命。
- 不写「女主对妮露一见钟情」；她是直女，对妮露是粉丝/同伴的喜欢。

## 开头选项 / 结尾钩子

### 开头选项

1. **从直播间切入**：「晚风打深渊」的直播间里，只有 37 个人；她把最后一颗星打满，弹幕飘过一句「主播，5.8 前瞻看了吗」。
2. **从母亲敲门切入**：母亲在门外说「你爸把饭热了三次了」，她戴着耳机，没听见；屏幕上，伊涅芙的立绘一闪而过。
3. **从屏幕裂纹切入**：她伸手去够桌上的水杯，屏幕先裂了；蓝白色的光从裂纹里溢出来，像有人从另一面把布撕开。

### 结尾钩子

死域还在长；妮露说「明天我陪你去看看」。女主看着她，第一次觉得：也许我留下来，不是为了看剧情。

## 风格提醒

- 第三人称限知，过去时；不要全知。
- 优美、偏诗意；段落以 80–200 字为主，允许 200–350 字长段；不要一句一段。
- 现实部分可以快、短、密；提瓦特部分要慢下来，给感官。
- 读者默认熟悉 canon；不要解释「什么是死域」「妮露是谁」；用女主的反应带出。
- 女主内心可以偶尔用游戏术语，但要立刻被现实「翻译」或打脸。
- 情感真挚细腻；不要煽情；用动作/物品/停顿。
