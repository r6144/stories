# ch09 水上的魔术

> 状态：已审（D71/D73） ｜ 正文：`正文/ch09.md`
> 时间以 `docs/01` 为准，人物与信息状态以 `docs/03` 为准，canon/AU 以 `docs/05` 为准，决策以 `docs/07` 为准。本卡只写本章独有的东西。

## 一句话

她第一次遇到一个“知道角色、却不知道这个人”的人；4.0–4.1 压成节点，恋情从粉丝到同谋到恋人，她怕的不是他死，是他被“父亲”派出去、回不来。

## 时间 / 地点 / POV

- **时间**：空白期第 250～357 天（须弥）；4.0 第 357 天，第三天早上进海露港；传说任务第 370 天左右；4.1 第 399 天；第 435 天前后北上（`docs/01` 第五阶段）。
- **地点**：海露港 → 升降机/克莱门汀线 → 枫丹廷/德波大饭店 → 欧庇克莱歌剧院 → 塞萨尔工坊/墓园 → 梅洛彼得堡 → 布法蒂公馆/运河码头。
- **POV**：林晚（主）；现实线荧（插叙，2026 年 7 月最后一个星期）。

## 本章目标

1. 走完 4.0–4.1，压成 summary：只写林晚在场的增量，不写流程、解密、打怪。
2. 恋情从“粉丝”到“同谋”到“恋人”：不超过牵手/拥抱/送花/心动；聚少散多，没有正式告别。
3. 公子同人文做负片：4.0 商会初见是对照高潮，4.1 只闻其事迹；不洗白。
4. 壁炉之家的忠心成为恐惧来源；阿蕾奇诺按 canon 短暂出场；琳妮特不是情敌，是家人。
5. 结尾：林尼北上十天（不是告别）；枫丹落雨、水位上涨；4.2 要来，她不能说。

## Beat

1. 空白期·书信：须弥日常；芙宁娜与纳西妲/妮露通信（舞台腔转“我”，不揭身份）；林晚决定提前去枫丹。
2. 海露港初见：瀑布下；琳妮特在水边/预言；芙宁娜的“飞行物”审判；林尼火线气球解围；魔术口袋；红心 Q 变空白牌；她认得手法，还是屏息；升降机＋巡轨船进枫丹廷。
3. 歌剧院：芙宁娜在台上光芒万丈、手在抖；林尼演出前把帽子转半圈、拇指蹭帽檐，像在确认什么还在。
4. 水箱逃生→箱中换人（海尔希七排三号）→水箱落下砸碎箱子→考威尔尸体/海尔希失踪→那维莱特中止。
5. 次日审判：她做“代理人”，作证“三分钟”，被芙宁娜反用；她再用“没听见闷响”/胎海水/海尔希证词翻回；无罪。
6. 后台：他摘手套，手在抖；“魔术师不能让观众看见手抖”“我不是观众”；手覆手背；差一点吻，琳妮特的茶打断。
7. 卡布里埃商会：公子讨债、叫她“伙伴”、踩住欠债人的手；“湿了，手就不稳”；她差点说“我写过你”，没有。
8. 传说任务：工坊旧道具让她想起现实里的房间；墓园里他不演了，讲塞萨尔的第一句“手可以抖，别让人看见”；她握住他的手。
9. 定情不告白：回程街上，虹彩蔷薇别在耳后；她说“我不是你以为的那个人”，他说“我知道”；没有“我爱你”。
10. 4.1：那维莱特请她假扮囚犯（对外“扰乱公共秩序/临时移监”，最多三周）；林尼偷钱入狱卧底，琳妮特在狱中；她第一次看见他“工作”的样子。
11. 自由日：琳妮特被抓；他喊“莱欧斯利，出来！”，拒绝拿“父亲”当筹码，冲向莱欧斯利，希格雯麻醉枪；克洛琳德带菲米尼。
12. 监狱深处：旧误读（莱欧斯利≈贵族同类）→身世→被林尼护妹妹打动；她用游戏知识找管道，暴露“知道太多”，他没问；废弃区钢筋/空窗只写生理反应。
13. 布法蒂公馆：阿蕾奇诺刚与芙宁娜喝过茶（“水神的茶太甜了”）；“谢谢你照顾我的孩子”“你知道的，比一个观众该知道的多”；口头十天任务，信封留在桌上，她看见封蜡，不问。
14. 旅馆镜子：荧的脸；她想过他离开壁炉之家、她带他回须弥，然后不敢想；派蒙“荧又没见过他”。
15. 公馆门口短别·雨：马车；她给他写了“林晚”的空白卡，他给她一张牌“下次，我给你变一个真的”；她说“你会没事的”，自己听着像谎。

## 人物与写法边界

- **林尼**：舞台腔不过火；“亲爱的/我的朋友/小姐”；认真时短句；爱她但不承诺“以后”，只说“下次”；留在壁炉之家、仍是愚人众；不知穿越与死期；穿魔术师服，不穿制服、不戴面具。
- **林晚**：对林尼会放软、会结巴，越紧张越贫，这一次贫不出来；对公子会冷、会心虚、不敢看他的手。
- **琳妮特**：短句、平、毒舌；吃醋是表演；“这个家总得有人守着”是家人式玩笑；温柔在动作里（茶倒七分、留门）。
- **公子**：直、热、爱叫“伙伴”；魅力是“真诚地不在乎”；不洗白、不多写、不写同情与和解；不知道同人文。
- **阿蕾奇诺**：礼貌、准时、记得生日；不威胁林晚、不洗白；恐惧来自“结构”，不是反派。
- **芙宁娜**（短）：还在演；看见她与林尼也不点破；自己的秘密还在。
- **莱欧斯利/希格雯**：一个干、慢、带干燥的幽默，一个轻、甜、直接；不纯恶、不幼态化；“一个像铁，一个像糖”。

## 本章的坑

- 不复述 4.0/4.1 流程；不写解密/打怪/系统面板；魔术写“看/被看”，监狱写“湿/锈/窄”。
- 顺序 4.0 → 传说任务 → 4.1，不把 4.1 提前；商会公子在 4.0 内、传说任务之前。
- 公子不写神之眼托付（D73）；他被控/洗清/仍判有罪→送梅洛彼得堡；不写“跟那维莱特打了一架”。
- 林尼不写完美男友/霸道总裁；不让他知道穿越与死期；不安排正式告别、不写“我会等你”；他 4.2 还会回来，不写成永别。
- 阿蕾奇诺不写“真面目揭露”的震惊；“比一个观众该知道的多”只是察觉；不拿“壁炉之家在须弥的坏事”当旁白认证。
- 琳妮特不是情敌；不做百合/后宫；“我把你也娶了”是玩笑，不往下落实。
- 纳西妲/妮露留须弥，第 10 章才来；不要写进第 9 章观众席。
- 现实线只写荧：带更远的队、新闻里的战况与洪水、换台又换回；不写林尼、不让她知道恋情、不写 2026 年战况（D31）。
- 名字统一“布法蒂”，不写“法布蒂”。
- 不写性/身体细节；希格雯不幼态化；不写“事实夫妻”的性意味。
- 提瓦特不写月份/季节，只用“第 X 天”与“4.x”；现实线才写月份。
- 不写告别倒计时（D36）：她只说“总有一天会走”，不说“我可能看不到婚礼”。

## 结尾钩子

马车走了；“你会没事的”像谎；“下次”；码头、芙宁娜、水位又涨一格；4.2 要来，她不能说。
