# ch07 甘露花海

> 本文件是 `docs/02` 第七章的细化场景卡，属于**派生文档**。时间以 `docs/01` 为准，人物/信息状态以 `docs/03` 为准，规则以 `docs/04` 为准，canon/AU 以 `docs/05` 为准，决策以 `docs/07` 为准。

## 开写前一句话

林晚带着洗不掉的手来到甘露花海；她以为自己是来受审的，结果花海让她做的，是「记得，然后继续」。

**上一章事实账本**：塔尼特线结束；婕德杀穿部族、杀芭别尔、取回母姓、独自离开；林晚为救婕德第一次杀人；妮露得知部族覆灭，在空剧场跳了一支花神之舞；林晚带着婕德的告别/半条丝带/洗不掉的手回须弥。

## 时间 / 地点 / POV

- **时间**：第 6 个月（日期见 `docs/01`）。
- **地点**：甘露花海、荼泥黑渊、铁穆山、万种母树、染境。
- **POV**：林晚（主）；可切芙宁娜/纳西妲/祖尔宛的短插曲（合计不超过 1/4）；现实线荧的限知插叙。

## 本章目标

1. 走完 3.6「善恶的赫瓦雷纳」：花灵、斯露莎、祖尔宛、米希尔、拉沙鲁、万种母树、焚真之天象、祭水之仪；那先朱那按 canon 出场。
2. 芙宁娜**中途到访**：秘密前来，花灵允许；她是「媒介/承认」，不是发力者。
3. 纳西妲/妮露全程在甘露花海段；妮露的舞是「花」的那一半；纳西妲是「草/见证」；林晚是「人/记忆」；斯露莎仍是「勇者」。
4. 让芙宁娜第一次在超自然事件里「有用」：不是力量，是承认、见证、慈悲；她阻止斯露莎牺牲，也在斯露莎身上看见自己。
5. 三人结缘；妮露不知道芙宁娜的秘密；纳西妲知道；林晚知道；花灵知道。
6. 林晚的治愈：第一次杀人后的 guilt，在甘露之雨里被接住；不是遗忘，是「可以继续」。
7. 埋下枫丹 4.0–4.2 的痛：林晚知道芙宁娜的未来，但不能说。

## 场景 beat

### 1. 铁穆山·异象

- 林晚/纳西妲/妮露/派蒙循着「焚真之天象」到铁穆山；天空的紫色裂缝；灰余晶；花灵的警戒。
- 斯露莎登场：骄傲、嘴硬、其实很关心同伴；她认林晚为「谒颂主」；她叫派蒙「白飘飘」。
- 矫论团/毕洛；那先朱那；灵光绝唱；离渡之仪；他想借仪式重振学派、反攻教令院。
- 林晚在他身上看到芭别尔：用信仰/知识/荣耀做权力，愿意牺牲一个年轻人（斯露莎）。
- 斯露莎想效仿西摩格自我牺牲；纳西妲/妮露第一次听她说“牺牲”；林晚想起婕德。
- **写法**：铁穆山要荒、要热；那先朱那不是纯恶；不要让林晚当面揭穿他。

### 2. 甘露花海·祖尔宛

- 进入甘露花海；天空的裂缝在头顶；花灵的警戒；万种母树像一棵巨大的枯树桩。
- 祖尔宛：年老的花灵，慵懒、爱逗人、看透一切；她认出纳西妲是草神；她欢迎她们。
- 纳西妲能听见母树的疼；妮露觉得花海“像塔尼特的另一种梦”；林晚带着半条丝带/血的手。
- 祖尔宛解释「三之法则」：要斯露莎+米希尔+拉沙鲁；斯露莎还没有「双角的花冠」。
- **写法**：花海要美；但美里有疼；不要让纳西妲一上来就解决一切。

### 3. 芙宁娜·中途到访

- 芙宁娜出现：华丽、夸张、戴着「水神」的面具；她一个人；没有随从；衣服被沙尘弄脏。
- 花灵拦住她；祖尔宛认出她身上的「水神」气息/厄歌莉娅的继承者；花灵把芙卡洛斯与芙宁娜视为「一体两面」，水神的职位是连续的，所以允许她进入。
- 芙宁娜看到万种母树/焚真之天象；她的恐惧；她试图用「神明」的语气掩饰；纳西妲看穿。
- 林晚知道她的秘密；她差点说漏嘴；纳西妲阻止她。
- 妮露把芙宁娜当真正的神明，恭敬又好奇；芙宁娜被这种「不带审视的尊敬」刺痛。
- **写法**：芙宁娜的出场要像舞台，但她的害怕要真；不要让她一上来就“有用”。

### 4. 斯露莎·牺牲

- 斯露莎要效仿西摩格，用自己的全部换天象熄灭；祖尔宛说「等待命运，只有人类才会盲目而行」。
- 芙宁娜第一个说「不」——她演了 500 年，她知道“牺牲”有时只是不敢找别的路；她在斯露莎身上看见自己。
- 纳西妲说「你的价值不在你的死」；妮露握住斯露莎的手；林晚想起婕德。
- **写法**：不要让芙宁娜讲 500 年的秘密；她只能说“还有别的路”；斯露莎不听，但记住了。

### 5. 万种母树·染境

- 进入母树；染境；慈心；伽乌迦那；纳西妲听见母树的疼；妮露的舞/花；林晚的记忆/血；芙宁娜的承认。
- 纳西妲在母树里看见厄歌莉娅的残余/花灵的牺牲；她第一次对另一个“神”共情。
- 妮露在染境里跳舞；她不知道自己是花神传人，但花/水/光会回应她；祖尔宛看见，选择不说。
- 林晚在染境里看见婕德/哲伯莱勒/塔德菈；她把手上的血/半条丝带带进去；她第一次允许自己“记得”。
- **写法**：染境是梦；不要写成关卡；用花/水/光/记忆，不用战斗数值。

### 6. 祭水之仪

- 祖尔宛解释：母树积累了太多污秽；需要「水」的媒介；芙宁娜是厄歌莉娅的继承者。
- 芙宁娜：「我没有力量。」祖尔宛：「我们知道。但水神的位置，不是力量，是承认。」
- 芙宁娜拒绝/害怕；妮露握住她的手；「你可以的。」纳西妲把手放在母树上；林晚把婕德的名字/那首歌/半条丝带放在心里。
- 仪式：芙宁娜站在水边；她唱/念；她的眼泪掉进水里；妮露跳舞；纳西妲/斯露莎/灵光净化污秽；甘露之雨。
- 芙宁娜的视角（短插段）：她听见厄歌莉娅的记忆/水的声音；她第一次觉得「我被需要，不是因为我演得像，是因为我在这里」。
- 祖尔宛说「不靠牺牲也能够做到」；斯露莎活下来；焚真之天象熄灭。
- **写法**：仪式是合奏，不是芙宁娜开大；妮露的舞是“花”，不是“神力”；林晚不能施法，她只能在场。

### 7. 雨后·治愈

- 雨后；芙宁娜累倒；纳西妲照顾她；妮露给她甜汤；三人坐在花海里。
- 芙宁娜/纳西妲的第一次深谈：两个「扮演神明」的人；纳西妲说「我也经常觉得自己不配」；芙宁娜哭。
- 妮露/芙宁娜的友谊：妮露不问她力量的事；她问「你喜欢吃什么」；芙宁娜说「蛋糕」；妮露笑。
- 林晚坦白第一次杀人；她没有哭；她说「我杀了一个人」；纳西妲说「我不能替你原谅自己，但我可以陪你记得」；芙宁娜说「我知道什么是不得不」；妮露握住她的手。
- 林晚在甘露里洗手；血洗掉了，记忆没有；她第一次觉得「我可以继续」。
- **写法**：治愈不是遗忘；不要用“一切都好了”；让林晚的手还会抖。

### 8. 秘密·结尾

- 芙宁娜请求大家保密：不能让枫丹人知道她没有力量；不能让任何人知道她来过这里。
- 纳西妲/林晚/花灵答应；妮露不知道真相，但答应「不追问」。
- 林晚私下告诉芙宁娜：我不是原来的荧。芙宁娜看了她很久，说：「我知道。你演戏不如我。」两人都笑了；这是芙宁娜第一次不因「被看穿」而害怕。
- 芙宁娜回枫丹；她与纳西妲/妮露交换了通信方式；她第一次有「朋友」。
- 林晚知道 4.0 的剧情；她看着芙宁娜的背影，想：「我救不了你，但我可以陪你。」
- 钩子：枫丹；4.0；芙宁娜的审判。

## 人物声音（只列本章出场）

### 林晚

- 她带着塔尼特的后劲来；她的吐槽很少，句子更短；她在花海里第一次允许自己“不做什么”。
- 她对纳西妲会认真；对妮露会放软；对芙宁娜会接梗，但接得很轻。
- 她在仪式里不是英雄；她是“记住的人”。
- **不要**：用攻略解决 3.6；对芙宁娜有浪漫箭头；把治愈写成“失忆”。

### 妮露

- 软，短句；她对花海有本能的亲近；她不知道原因。
- 她的舞是“花”的那一半；她为草神跳舞，也为一路上所有教过她的人跳舞。
- 她不知道芙宁娜没有力量；她把她当神明/朋友；她的尊敬让芙宁娜刺痛。
- **不要**：说漏花神祝福；突然变成“花神本人”；工具人。

### 纳西妲

- 轻，慢，比喻；她能听见母树的疼；她不是全知。
- 她看出妮露的花神祝福，选择不说；她按住林晚的手，不让她再犯 3.0 的错。
- 她对芙宁娜有共情：两个“扮演神明”的人。
- **不要**：全知；说教；幼态；替斯露莎做仪式。

### 芙宁娜

- 夸张、舞台腔、感叹号；但她的害怕要真；她真正难过时反而安静。
- 她第一次不以表演的方式被需要；她阻止斯露莎牺牲，因为她在斯露莎身上看见自己。
- 她对妮露的“不带审视的尊敬”又疼又暖；她对林晚说「我知道。你演戏不如我。」
- **不要**：开大；卖萌；一直浮夸；没有安静的时刻。

### 斯露莎

- 文绉绉，爱用「吾辈」「谒颂主」；骄傲、嘴硬、爱被夸；其实很关心同伴。
- 她想牺牲自己；她最后活下来，成为真正的勇者。
- **不要**：纯搞笑；真的死；抢妮露/芙宁娜的戏。

### 祖尔宛

- 慢，轻，像讲故事；慵懒、爱逗人；「白飘飘」「等待命运」。
- 她知道花灵的历史；她看出妮露的花神祝福，不说。
- **不要**：全知；慈祥奶奶；工具人。

### 那先朱那

- 文绉绉；爱讲“争斗才是世界的本质”；有野心，也有可悲之处。
- 他和芭别尔互为镜像；林晚不能恨他，只能不成为他。
- **不要**：纯恶；搞笑反派；洗白。
