# ch07 沙丘

> 状态：已按 3.4 canon 重写（含 D57 责任种子、D66 路线） ｜ 正文：`正文/ch07.md`
> 时间以 `docs/01` 为准，人物与信息状态以 `docs/03` 为准，canon/AU 以 `docs/05` 为准，决策以 `docs/07` 为准。本卡只写本章独有的东西。

## 一句话

她带着妮露的丝带回塔尼特，发现婕德已成了芭别尔的刀：长老早死，她拦不住，还在替婕德找理由；绿洲的静美之后是部族的血，她第二次杀人，婕德取回母姓，独自离开。

## 时间 / 地点 / POV

- **时间**：3.4，第 147 天到塔尼特；塔德菈之死、终局与诀别在第 152～160 天；约第 160 天回须弥城。
- **地点**：须弥城 → 千壑沙地/塔尼特营地 → 遗迹巨像/峡谷 → 永恒绿洲 → 神的棋盘 → 居尔城 → 愚人众前哨 → 须弥城/大巴扎/净善宫。
- **POV**：林晚（主）；不切纳西妲/若娜瓦；现实线荧（2025-12，限知插叙）。

## 本章目标

1. 走完 3.4“比勒琪丝”：塔尼特、婕德、芭别尔、阿萨里格、利露帕尔、绿洲、塔德菈。
2. 让林晚看见婕德已经变了：婕德仍当她是朋友，但**不许她说芭别尔坏话**。
3. 让她知道三位长老（布列达/戈瓦法/忒雅）已死、她拦不住，而且替婕德找理由找得太顺；guilt 是“我把她一个人留在那里”。
4. 芭别尔摊牌；婕德杀穿塔尼特、杀芭别尔；林晚第二次杀人；诀别。
5. 妮露得知覆灭、空剧场一舞；带半条丝带回须弥，接甘露花海。

## Beat

1. 营地门口：婕德在等，比上次瘦、比上次静，还是叫“朋友”、还蹲下去擦奔奔壳上的纹路；营地里少了三顶帐子，名字没人提。
2. 学校与书：教令院旧章被刮掉一半，婕德说“主母有办法”；教认字的是芭别尔从雨林捡来的除名先生，算账她亲自教。林晚不语，婕德先说“你可以说沙漠不好”，再说“但别说主母”。
3. 第 2 天下午，擦奔奔处：林晚不问“是不是你杀的”，只说“布列达的帐子里还挂着一只药囊”；婕德答“主母说，他们挡了路”。林晚听见自己心里替她接话的声音，认得它。
4. 芭别尔接见：收下干花，说老舞者去年去世；看着腰间的魔瓶，派她们去绿洲“看看还剩什么”。她说“总有一天，须弥城的人会来求我们”——林晚想：她说的是账。
5. 巨像/峡谷：阿萨里格摊牌、索要镇灵，被婕德所杀；她拿到阿萨里格写给阿德菲的联姻密信。
6. 永恒绿洲（只去一次）：水不流、没有水声，虫停在花心；婕德放下笔记、斧头、照片，走开去陪父母；林晚念信与歌（12 行 3 段），婕德读末段。利露帕尔警告“有罗网在等着婕德”。
7. 回营报告：芭别尔表演“早知道阿萨里格有异心”，把婕德绑得更紧；次日奔奔被偷，两人抢回充能转化容器，在木箱里找到壳裂的奔奔。
8. 神的棋盘：塔德菈奉主母之命来杀她（绿洲的事不能有外人活着说出去）；她选择以毒箭自尽，把“不沾血”留给林晚，“请…不要…遗忘我”。马塞拉留下警告就走；林晚取翎羽。
9. 居尔城：利露帕尔告别，魔瓶从此沉默。
10. 两头挑拨：镀金旅团假称“婕德让我们招待你”袭击；芭别尔再说“婕德是叛徒”，让她去追。
11. 愚人众前哨：三份文件（撤离公文/实验个体检测/转移通知）与幸存者的讲述；塔尼特把婕德交给佛罗德洛克教授做实验。
12. 峡谷：婕德先拔刀——“用你的剑来证明”；派蒙说破两边是同一套谎话，文件摊开，她认出“同意。尽快交割。”，说“她把我卖了”。
13. 奈兰/雷兹吉奉主母之命来杀婕德，婕德亲手杀了这两个“家人”；回营对质，她把三位长老的死一件件说给芭别尔听。混战中林晚为救她杀死守卫阿迪勒、救出他妹妹妮娜；婕德杀尤夫腾、杀芭别尔——“我的部族，我的族人。”
14. 诀别（营地外一条深峡谷，不是神的棋盘）：她取回“婕德·优菲·欣迪”；丝带撕成两半，一半绕在奔奔的一只角上；“阳光更好的日子”。
15. 回须弥：妮露只听，说“她一定很疼”；空剧场一次没有音乐的花神之舞；净善宫台阶上纳西妲说“沙漠那边有东西在疼”；水边洗手，洗到皮红。

## 人物与写法边界

- **林晚**：吐槽几乎消失，更多是观察、忍耐、咽回去。她不是去“救”婕德，是去“陪”她；每次想干预都想起哲伯莱勒的教训。阿迪勒之后声音变轻：不说“我没事”，说“我需要坐一会儿”。对婕德没有浪漫箭头。
- **婕德**：明亮被压下去，对朋友软、对“家人”有执念；“主母是我唯一的家人”。杀长老时她说自己“第一次被自己吓哭”；告别不哭出声，只抱得很紧。不疯批、不一见面就背叛芭别尔。
- **芭别尔**：慢、轻、像母亲；越温柔越危险；死前还在说“我的部族，我的族人”，不忏悔。不是哈哈大笑的恶人，也不是纯工具反派——她真给沙漠建了学校。
- **塔德菈**：轻、短；“我希望，活下来的是你”。死要快，遗言比血疼。
- **马塞拉 / 利露帕尔**：马塞拉老、稳、怕，留警告就走，不是纯恶；利露帕尔傲慢嘴毒，只说“这是她自己的选择”。
- **妮露**：只在后半出现；悲伤是安静的，不怪婕德，不崩溃大哭；永远不知道花神祝福。
- **纳西妲**：只察觉“铁的味道”，不追问；阿迪勒之死的告知在 ch08（D16）；不让她说得太满。
- **派蒙**：读者的心——害怕、想问又不敢问；看见杀人时沉默，告别时哭；不只会吃，不在血面前开玩笑。

## 本章的坑

- 场景顺序按账本校正：绿洲只去一次、遗物留在那里，塔德菈在绿洲与奔奔之后（旧大纲把她排在绿洲之前）。
- 路线按 D66：南线绕阿如村，第 7 天才进千壑沙地、第 11 天到塔尼特；她每天很早扎营，是不想太早面对塔尼特，不是走不快。
- 不救婕德、不改 canon：杀芭别尔是婕德的事，林晚只杀一个忠仆阿迪勒；不替婕德杀芭别尔，不把那一剑写成爽点。
- 两次别弄反：艾方索是第一次（ch06，D41，那个“不该死”的人），阿迪勒是第二次；阿迪勒死时还有表情，林晚吐了、手抖得握不住剑。
- D16：本章林晚不告诉纳西妲阿迪勒的事，只说“好”；告知在 ch08。
- 不写两次绿洲、不写婕德把笔记/斧头带回、不重复第 4 章“我回不去”的长段：本章是母亲的笔迹，不是火边的歌。绿洲里让她先放下，林晚只在心里补完。
- 不写猎奇：不写“婕德杀光所有人”，写人、写脸、写名字；不写林晚“变强”，她只想拦住那一刀。
- D57 的责任种子要落到位：书上的旧章、芭别尔的“账”、结尾纳西妲“沙漠那边有东西在疼”、林晚的塔尼特之隐；但“沙漠的事，我欠了很多年”留给 ch06 辞行，本章不重复。
- 丝带是妮露给她的，撕成两半、不是还回去；不让妮露知道花神祝福，不写闺蜜反目。
- 不写系统词（面板/等级/HP/抽卡/命座）；提瓦特不写月份/季节；婕德的脏话短引或改写，不大段复制。
- 现实线只两小节（山脊团、沙尘“踩我踩过的地方”），做平行回响；不写陈店长不满、不写辞职去俱乐部全职的纠结。

## 结尾钩子

甘露花海；她洗不干净的手；妮露在空剧场的那一舞；“不靠牺牲也能够做到”；纳西妲那句“沙漠那边有东西在疼”指向 ch08。
