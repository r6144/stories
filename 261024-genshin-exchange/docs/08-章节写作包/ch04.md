# ch04 沙漠

> 本文件是 `docs/02` 第四章的细化场景卡，属于**派生文档**。时间以 `docs/01` 为准，人物/信息状态以 `docs/03` 为准，规则以 `docs/04` 为准，canon/AU 以 `docs/05` 为准，决策以 `docs/07` 为准。

## 开写前一句话

林晚在沙漠里遇见婕德，知道哲伯莱勒会死，却救不了；她第一次明白「知道结局」不是礼物。

**上一章事实账本**：花神诞祭的梦醒了；迪娜泽黛获救；纳西妲与林晚长谈，约定不剧透、保密；林晚知道自己借命、没有期限；四人拍下第一张全家福；林晚决定去沙漠，知道纳西妲会被囚禁。

## 时间 / 地点 / POV / 字数

- **时间**：第 +1 个月（日期见 `docs/01`）；3.1 魔神任务与「黄金梦乡」同期。
- **地点**：沙漠、阿如村、赤王陵遗迹、黄金梦乡、塔尼特边缘、须弥城。
- **POV**：林晚（主）；不切纳西妲/若娜瓦；现实线荧的限知插叙 1,200 字。
- **字数**：12,000 左右；场景完整优先，不按字数删戏。

## 本章目标

1. 走 3.1 魔神任务（压缩）：阿如村、魔鳞病医院、人质交换、赤王陵；迪希雅/赛诺/艾尔海森。
2. 走 3.1「黄金梦乡」：婕德、哲伯莱勒、提格扎德、奔奔；让婕德先以一个**明亮的、话多的、相信老爹的**女孩出现。
3. 让林晚第一次体会「知道剧情也救不了一个人」：她知道哲伯莱勒会死，试图小干预，失败；哲伯莱勒唱摇篮曲，走进黄金梦乡。
4. 哲伯莱勒死后，婕德**自己走去塔尼特投奔**；林晚不能拦，也不能告诉她未来。
5. 结尾回须弥城，接 3.2；钩子：婕德在塔尼特的背影，和「我们还会见面吗？」。

## 场景 beat（带字数）

### 1. 阿如村·3.1 开场（2,500 字）

- 热、沙、风；阿如村的土墙、水井、孩子；林晚第一次看见沙漠的普通人。
- 赛诺查失踪的守村人；迪希雅护着村民；艾尔海森出现，话少、准、毒。
- 林晚知道 3.1 的剧情，但她不敢表现太神；她说漏一句「这个机关要打三下」，被艾尔海森看了一眼。
- 魔鳞病医院：病床、药味、迪希雅不愿提的过去；林晚知道迪希雅卖剑的事，差点说漏嘴。
- **写法**：3.1 主线用侧写/蒙太奇，不逐字复述；只留「迪希雅的过去/魔鳞病医院/人质交换」三个点。

### 2. 黄金梦乡·初遇（2,500 字）

- 婕德在陷坑下抬头：「你们是新掉下来的人吗？」她话多、好奇、给奔奔取名、把林晚当朋友。
- 哲伯莱勒沉默、可靠；提格扎德又怂又酸；奔奔「哔哔」。
- 林晚认出婕德——她玩过这段剧情，知道哲伯莱勒会死，知道婕德以后会去塔尼特。她看着婕德笑，心里发紧。
- 婕德问：「你也是冒险家吗？你见过很多地方吗？」林晚说「见过一些」；她不敢说「我见过你的以后」。
- **写法**：婕德的明亮要写足；她越可爱，后面的死越疼。

### 3. 黄金梦乡·遗迹（2,000 字）

- 赤沙石板、机关、萨梅尔；婕德被挟持；林晚试图小干预：提醒哲伯莱勒、想提前拆穿萨梅尔、在挟持发生时换位置。
- 每次干预都被局势推回去：哲伯莱勒比她更懂沙漠；萨梅尔比剧情里更早动手；她的「知道」让艾尔海森起疑，也让婕德更危险。
- 3.1 主线的遗迹/人质交换并行；赛诺的冷笑话、艾尔海森的毒舌、迪希雅的直率，给这段一点呼吸。
- **写法**：不要让她「用攻略秒通」；她的干预要有代价；她越急，越像 3.0 的她。

### 4. 黄金梦乡·摇篮曲（2,000 字）

- 哲伯莱勒说出进入黄金梦乡的祷言——那不是咒语，是婕德幼时的歌谣。
- 他走进黄金梦乡；婕德喊「老爹」；林晚只能拉住她；沙暴/金光/歌声。
- 婕德哭到没有声音；林晚第一次觉得「知道结局」是诅咒，不是礼物。
- **写法**：哲伯莱勒之死要克制；不写长篇遗言；用摇篮曲/奔奔的哔哔/婕德的手。

### 5. 婕德·投奔（1,500 字）

- 婕德说「老爹只是睡着了」；她决定去塔尼特——她没有别的地方可去。
- 林晚不能拦；她给婕德水/食物/一点钱；婕德说「我们还会见面吗？」林晚说「会」。
- 婕德走向沙丘；奔奔跟着；林晚站在原地看着她变小。
- **写法**：不要写「芭别尔的人来接她」；她是自己走的；这是本文推断，见 `docs/05` 3.13。

### 6. 回程·识藏日（1,500 字）

- 回须弥城；妮露在剧场排练；林晚看着妮露的舞，想起婕德。
- 她知道 3.2 要来；她决定按计划走；但她第一次不确定「按计划走」是不是对的。
- 钩子：识藏日；妮露要跳舞；林晚知道纳西妲会被囚禁；她也知道，等她再见到婕德，婕德已经变了。

## 人物声音（只列本章出场）

### 林晚

- 内部：吐槽多，短句，游戏术语乱飞；但这一章她的吐槽会变少，因为她知道要死人了。
- 外部：对迪希雅/赛诺用敬语；对婕德会放软；对艾尔海森会收着。
- 控制欲：她想「至少救一个」，但每次都失败；她越急，越像 3.0 的她。
- **不要**：用攻略秒通；对婕德有浪漫箭头；把哲伯莱勒的死写成“剧情杀”。

### 婕德

- 明亮、话多、好奇；爱给人起外号；对“老爹”又敬又亲；对朋友掏心掏肺。
- 口头禅：「老爹说……」「你不懂啦」「奔奔，你说是不是？」
- 这一章她还没被芭别尔塑造；她的狠只在保护朋友时露一下。
- **不要**：一上来就阴郁；一上来就杀过人；把她写成“疯批”。

### 哲伯莱勒

- 短、低、少解释；「不要多管闲事。」「快走。」「婕德，别跟他废话。」
- 他不是话痨；他的爱在动作里（挡在前面、修东西、把水给婕德）。
- **不要**：长篇遗言；突然抒情；被芭别尔的人接走。

### 迪希雅 / 赛诺 / 艾尔海森

- 迪希雅：干脆、豪爽；「交给我」「别废话」；她护村民，也护林晚。
- 赛诺：短、正式；冷笑话；「这是大风纪官的判断。」
- 艾尔海森：平、准、毒；他怀疑林晚「知道太多」，但不追问；「这是效率问题。」

### 派蒙

- 吵、直接、食物比喻；「呜哇」「欸嘿」「肚子饿了」。
- 她喜欢婕德/奔奔；她在哲伯莱勒死时第一次不知道该说什么。

### 妮露

- 本章只在开头/结尾出现；她在须弥城排练；她不知道沙漠里的事。
- 不要让她说漏塔尼特/花神；她只是一个等朋友回来的舞者。

## 声音锚点

**叙述样例**：

> 阿如村的风从土墙之间穿过去，带着沙、干草和一点羊奶的酸味。林晚把围巾往上拉了拉，还是觉得嘴里有沙。她知道自己在哪里——她玩过这张地图，知道前面那个拐角有口水井，知道水井边的孩子会向她要吃的。可知道归知道，她的腿还是酸的，喉咙还是干的，太阳还是真的。

**对白样例**：

> 「你也是冒险家吗？」婕德问，「你见过很多地方吗？」
>
> 林晚看着她。她比游戏里瘦，比游戏里吵，眼睛亮得像刚磨过的刀。
>
> 「见过一些。」林晚说。
>
> 「那你知道塔尼特吗？」婕德说，「老爹说，那是他以前的部族。等我们出去，我想去看看。」
>
> 林晚的喉咙动了一下。她知道塔尼特。她知道婕德会在那里变成另一个人。
>
> 「……知道一点。」她说。
