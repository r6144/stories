# ch04 沙漠

> 状态：已按 D21/D22/D23/D24 重写 ｜ 正文：`正文/ch04.md`
> 时间以 `docs/01` 为准，人物与信息状态以 `docs/03` 为准，canon/AU 以 `docs/05` 为准，决策以 `docs/07` 为准。本卡只写本章独有的东西。

## 一句话

3.1 压成节点（魔鳞病医院、人质交换、赤王神庙、拉赫曼转向）：她守着 canon 的好结局、只插半寸。后半黄金梦乡反过来——她早知道哲伯莱勒会死、婕德会去塔尼特，能给的只有几天好日子、一张照片、在场；不能给名字、歌、警告。

## 时间 / 地点 / POV

- **时间**：第 37～40 天第一笔委托与准备 → 3.1（第 40～53 天）→ 53～55 天神庙清理交接 → 55 天前后黄金梦乡（结束日不硬编）→ 回须弥城接 3.2 识藏日。
- **地点**：须弥城/沙漠 → 阿如村、村东南魔鳞病医院、村外干河床 → 赤王神庙 → 阿如村井边 → 南边陷坑 → 绿洲 → 秘仪圣殿 → 赤王陵侧厅 → 圣显厅（赤王陵北边，悬在大坑上）→ 沙丘 → 祖拜尔剧场。
- **POV**：林晚（主）；不切纳西妲/若娜瓦；现实线荧的限知插叙。

## 本章目标

1. 走完 3.1 并压缩：医院、人质交换、赤王神庙、拉赫曼转向；她是守好结局的人，不是赶场的人。
2. 两座桥缝合两半：赤王神庙清理（AU，让教令院赤沙石板项目卷宗到场）与卷宗里优菲·欣迪的名字。
3. 让她第一次体会“知道也救不了”：小干预全被推回，知识在沙漠里不值钱。
4. 让婕德先以明亮的、话多的、信老爹的女孩出现——越可爱，后面的死越疼。

## Beat

1. 沙漠头几天：省水、掰饼、鞋里抖沙、没洗澡；她想起荧的账单：剑钝一寸，命就短一寸。
2. 阿如村/魔鳞病医院：水井、被教令院提前撤空的下层；迪希雅的过去、艾尔海森的冷；她在井边数人头；“我有钱”“教令院不卖给沙漠”。
3. 人质交换：迪希雅以右臂担保，艾尔海森自请作人质没成；拉赫曼只带来伊萨克的爷爷；刀落下时她喊了半声，迪希雅躲开；她割断老人手腕上的绳子。
4. 地震、纳西妲残留的绿光，众人沉入赤王神庙：卡萨勒遗言、大慈树王援建、赤王自我牺牲；拉赫曼信仰崩塌、当场结盟；翌日送还守村人。
5. 她数人，记住 canon 不关心的守村人哈桑——那半寸有没有用，她不确定。
6. 神庙清理（AU）：她整理教令院带来的赤沙石板项目卷宗，看见“优菲·欣迪”；艾尔海森问“你认识？”，她说“听过”；他没再问，她忽然希望有人追问。
7. 交接：她说接了个委托、找一群没回来的学者，不撒谎；迪希雅塞水囊、赛诺“别死”、艾尔海森“哦”一声低头看地图；定金转成阿如村的药。
8. 博尼法兹的委托：合伙人纳赫蒂加尔与驮兽塞琉斯随“提尔扎德·欣迪”的考古队失踪；她循足印找到陷坑。
9. 陷坑下婕德抬头：“你们是新掉下来的人吗？”她话多、给奔奔取名、送林晚一朵沙漠玫瑰；出坑后纳赫蒂加尔回村，提尔扎德往绿洲。
10. 绿洲夜：提尔扎德讲欣迪家那位“跟野小子私奔”的亲戚；婕德私下说母亲叫优菲·欣迪、不记得母亲的脸；林晚不说破。
11. 拍照：婕德、哲伯莱勒、奔奔，哲伯莱勒只留下影子。那首歌在火边响起，她背得出全文，只敢独自哼中间那一段——只有派蒙听见。
12. 哲伯莱勒点破：“你看婕德的样子，像在看她最后一眼。”他说他知道萨梅尔；她的警告没有用。
13. 秘仪圣殿/赤王陵：壁画之争（暴君/愿望/秩序）；萨梅尔抢走奔奔；她想先一步说破优菲之死，被哲伯莱勒制止；救回奔奔后他说破，婕德第一次知道母亲怎么死，提尔扎德才知道婕德是谁。
14. 圣显厅：萨梅尔挟持婕德逼祷文——祷文就是那首歌；御座反杀、萨梅尔断气（假胜利）；他取得权柄、关门；哲伯莱勒把水留给婕德，进入永恒的梦乡同归于尽，只留斧头；“老爹只是睡着了”。
15. 沙丘：她带着斧头和母亲的日记独自走向塔尼特；林晚给水、干粮、钱袋；“我们还会见面吗？”“会。”没有拍下最后一张，后来只拍到沙和脚印。回城还留影机，妮露问那道影子、又问“什么歌”，她答“沙漠里听来的”。

## 人物与写法边界

- **婕德**：明亮、话多、爱起外号，“老爹说……”。她还没被芭别尔塑造，狠只在护朋友时露一下；不写阴郁、不写杀过人，不让她自称“婕德·优菲·欣迪”。
- **哲伯莱勒**：短、低、少解释；爱在动作里（挡在前面、给水）。他知道萨梅尔杀优菲，也早已做了选择；不写长篇遗言、不突然抒情、不一阶段牺牲、不复活。
- **提尔扎德**：抱怨、学术腔、怕死、爱面子；不是纯搞笑工具，也不突然勇敢；3.1 时他手上有教令院研究许可。
- **萨梅尔**：低、慢、带笑，狠而耐心、会演；用婕德逼哲伯莱勒；不疯批、不话痨、不提前交代计划。
- **艾尔海森**：平、准、毒；本章是同事式信任——不追问、不管她、不全知。
- **派蒙**：吵、食物比喻；喜欢婕德和奔奔；哲伯莱勒死时她第一次不知道该说什么；听见那支歌，没问。

## 现实线

- **8 月·日结**：展会布展撤展三天，200/天，扫码；第三天 600——比直播一个月 400 多。母亲看她的手和鞋、翻群，“你缺钱跟我说”；“我想自己挣”；第二天她用 600 买菜。
- **9 月·外贸的诱饵**：父亲先提老赵那边的跟单“专业对口”；她夜里翻函电教材看不懂；父亲起夜看见灯，没敲门，第二天在阳台替她回绝。
- **前台**：陈店长是老赵的外甥；她踩点、抄价目表、打印简历；“国贸的来当前台”“想先找个能站住的”；试工三天，3200/月、单休。
- **第三周**：跑步机上有人晕倒，她跪下去；没有元素力，只有一双手；教练“你反应真快”。对照：林晚知道一切却救不了，荧没有力量却救了一个人。
- **不写**：AI（ch05 首次）、2026 战况、爽文逆袭/惨文、现金（日结是扫码）；人情只给试工机会，录取靠她自己；3200 不是成功，是站住。

## 本章的坑

- 先 3.1、后黄金梦乡，顺序发生、不穿插（D21）；黄金梦乡仍由奔奔打开赤王陵，不提前开。
- canon 流程的场景一律 summary：门、机关、打怪全略；每场至少带一样 canon 里没有的东西（D22）。
- 优菲的名字只出现在赤王神庙清理的教令院卷宗里（AU），不放医院、不放赤王陵；她是“确认”，不是“发现”（D23）。
- 哲伯莱勒之死两段式：御座反杀（假胜利）→ 权柄关门 → 永恒的梦乡同归于尽；不写一阶段、不写复活、不救他（D23）。
- 那首歌不是两首：祷文就是它；本章不唱整首、不把中间段给婕德，全文留到第 7 章（D24）。
- 婕德自己去塔尼特，不是芭别尔的人来接；本章不揭示她日后杀长老，也不让林晚拦她（D13）。
- 圣显厅在赤王陵北边、悬在大坑上，从赤王陵底下往北走；不是“赤王陵最深处”（D81）。
- 钱：不写汇率、不写“圣遗物”类系统词、不哭穷；沙漠里省水是错的，但不写成说教（D42）。
- 不写艾尔海森起疑、不写林晚撒谎接委托；不写系统面板/等级/伤害数字；草元素在沙漠不万能。
- 提瓦特不写月份/季节；现实线才写 8 月、9 月；父母不说破穿越。

识藏日将至，妮露要在教令院门前跳舞；林晚知道纳西妲会被囚，也知道再见到婕德时她已经变了。照片在包里，那首歌在脑子里。
