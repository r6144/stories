# ch05 虚空鼓动，劫火高扬

> 本文件是 `docs/02` 第五章的细化场景卡，属于**派生文档**。时间以 `docs/01` 为准，人物/信息状态以 `docs/03` 为准，规则以 `docs/04` 为准，canon/AU 以 `docs/05` 为准，决策以 `docs/07` 为准。

## 开写前一句话

林晚救出纳西妲，却救不了婕德；她在妮露的塔尼特记忆里，第一次知道「有些告别不能提前说」。

**上一章事实账本**：3.1 沙漠篇与「黄金梦乡」结束；哲伯莱勒两段式死亡（假胜利 → 永恒的梦乡），只留斧头；婕德带着斧头/母亲的日记独自去塔尼特；林晚回须弥城；她知道 3.2 要来，知道纳西妲会被囚禁。

## 时间 / 地点 / POV

- **时间**：第 +1.5～+3 个月（日期见 `docs/01`）。
- **地点**：须弥城、教令院、净善宫、大巴扎、维摩庄、森林。
- **POV**：林晚（主）；不切纳西妲/若娜瓦；现实线荧的限知插叙。

## 本章目标

1. 走完 3.2：识藏日、妮露的舞、救纳西妲；不逐字复述主线。
2. 给妮露高光：她在教令院门前跳舞，明知会被抓，还是跳。
3. 让林晚体验「知道剧情但无法控制」的无力；她只能跟着计划走。
4. 森林书完成：回维摩庄，拉娜获救，惟耶之实；只写一个正面场景，其余蒙太奇。
5. 妮露讲塔尼特前史：16 岁学舞、芭别尔、长老、学校/书、花神信徒；她给林晚一条丝带，托她问候；林晚不能告诉她部族要没了。
6. 3.3/3.5 侧写：林晚第一次听到「命运的织机」；她心里发冷。
7. 结尾：林晚收拾行李回沙漠；钩子：塔尼特、婕德。

## 场景 beat

### 1. 作战会议

- 艾尔海森的计划；林晚的角色；她知道妮露要跳舞；她反对/担心。
- 迪希雅：「妮露自己答应的。」
- 林晚去找妮露；妮露在练舞；「你会被抓的。」「那就被抓。总不能因为怕，就不跳。」

### 2. 识藏日·妮露的舞

- 教令院门前；卫兵；人群；妮露登台。
- 她跳的不是「花神之舞」，是更自由的一段。
- 林晚在远处/禁闭室；她听见喧闹；担心；骄傲。
- 卫兵被吸引；计划推进；妮露被抓/逃走；林晚后来抱住她。

### 3. 救纳西妲

- 禁闭室；虚空终端；意识空间；纳西妲的自我怀疑；大慈树王的声音；纳西妲醒来。
- 净善宫；纳西妲第一次用自己的身体走出牢笼；她的眼泪。
- 「原来用自己的身体走路，是这样的感觉。」「欢迎回来。」
- 「先做好自己，再做神明。」

### 4. 约定

- 纳西妲和林晚；「你还会走吗？」「会。但不知道什么时候。」
- 借命没有期限；「你随时可能消失。」「那你会告诉他们吗？」「不会。但我会陪你。」
- 不剧透的世界观依据：荧是降临者，林晚是变量中的变量；改大事后果不可预测。
- 林晚第一次在提瓦特哭得像个 22 岁的人。

### 5. 森林书·拉娜

- 回维摩庄；拉娜/死域/惟耶之实；兰那罗；林晚+派蒙+兰罗摩。
- 只写一个正面场景：拉娜醒来，先问孩子；或兰茶树把那口锅留给她。
- 兰那罗说「那菈会忘记」；林晚说「我会记得」；「森林会记住一切」。
- 其余用蒙太奇：兰那罗的歌、森林的光、林晚在树下睡着。
- **写法**：不重复任务流程；不写打怪；这是塔尼特线前的最后一次“做好事”。

### 6. 妮露·塔尼特前史

- 大巴扎/祖拜尔剧场；妮露在练一支新舞；林晚坐在台下。
- 妮露讲 16 岁那年去千壑沙地、在塔尼特学花神之舞：芭别尔主母、长老们、学校/书、孩子、真正敬花神的人；她说得很克制，尽量不说坏话，但提醒林晚「沙漠很险」。
- 她给林晚一条丝带/一小包帕蒂莎兰干花，托她问候芭别尔/老师；她说「他们教了我跳舞」。
- 林晚知道塔尼特要没了，知道芭别尔会死；她不能告诉妮露。她收下丝带，说「我会带到」。
- **写法**：温暖里带危险；妮露的“谨慎”要写出来；不要让妮露说漏花神祝福；不要让林晚哭出来。

### 7. 3.3/3.5 侧写

- 间章/卡利贝尔的传闻；林晚第一次听到「命运的织机」这个词；她心里发冷。
- 她不知道那是什么，但她知道那和自己有关；她没有告诉纳西妲全部。
- **写法**：一段话，不展开；这是第 11 章的伏笔。

### 8. 结尾·回沙漠

- 林晚收拾行李；妮露问她「你还会回来吗？」林晚说「会」。
- 她把丝带放进包里；她知道自己要去的地方，妮露再也回不去。
- 钩子：塔尼特；婕德；「我们还会见面吗？」的回声。

## 人物声音（只列本章出场）

### 林晚

- 3.2 里她 mostly 跟着计划走；她的无力感比 3.0 更深，因为她已经知道“知道”不一定有用。
- 对妮露会放软；对纳西妲会认真；对艾尔海森会收着。
- 森林书里她会短暂地像个 22 岁的普通人；这是她后面的“心理底色”。
- **不要**：用攻略秒通 3.2；对妮露有浪漫箭头；把纳西妲写成全知。

### 妮露

- 软，短句，语气词多；「欸」「唔」「嘿嘿」。
- 3.2 里她极勇敢；「那就被抓。总不能因为怕，就不跳。」
- 塔尼特前史里她谨慎、感激、避开坏话；「他们教了我跳舞。」
- 她不知道借命/死期/塔尼特覆灭；不要让她说漏。
- **不要**：写成工具人；写成傻白甜；写成“花神转世”的口吻。

### 纳西妲

- 轻，慢，比喻；「先做好自己，再做神明。」「我不能替你醒来。」
- 她知道林晚的秘密；她不是全知；她也会怕。
- **不要**：说教；幼态；替林晚解决一切。

### 艾尔海森 / 赛诺 / 迪希雅

- 艾尔海森：计划、效率、毒舌；他注意到林晚知道得比她说得多，但不追问、不管她。
- 赛诺：短、正式；冷笑话；「这是大风纪官的判断。」
- 迪希雅：干脆、豪爽；「交给我」「别废话」；她护妮露。

### 派蒙

- 吵、直接、食物比喻；她开始叫林晚「晚晚」；她在 3.2 里第一次说「你也是我的旅行者」。

### 拉娜 / 兰那罗

- 拉娜：短、务实；「死域又长了。」「孩子们还在那边。」
- 兰茶树：第三人称、重复；「那菈」「料理是自然的风味。」
- 兰那罗：孩子气、歌谣、记不住“那菈”的名字；但它们记得森林。

## 声音锚点

**叙述样例**：

> 维摩庄的森林在雨后有一种很轻的响声，像很多很小的手在拍叶子。林晚坐在兰茶树的锅边，看汤面上的泡一个一个破掉。她知道自己应该高兴——拉娜醒了，死域退了，兰那罗在唱歌。可她的包里有一条丝带，丝带的主人在须弥城等她回去，而丝带要去的那个地方，已经快要不存在了。

**对白样例**：

> 「他们教了我跳舞。」妮露说，「塔尼特的人。芭别尔主母，还有一位老师。」
>
> 林晚看着她。妮露的眼睛很亮，像在说一个很好的梦。
>
> 「他们……对你好吗？」林晚问。
>
> 「嗯。」妮露点头，「他们有自己的规矩，有些事我不懂，也不该懂。但他们教我的舞是真的。」
>
> 林晚把丝带接过来。丝带很轻，像一句她不能拆穿的谎。
