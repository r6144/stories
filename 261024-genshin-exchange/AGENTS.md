## 项目

《借来的花神诞祭》，《原神》同人长篇。

22 岁的国贸毕业生、深渊主播，在 5.8 前瞻次日（2025-07-19）穿越成荧，在提瓦特生活 1 年 9 个月，促成妮露、纳西妲、芙宁娜的幸福；穿越结束那天她回到现实并死去，原版荧回到提瓦特，赶上三人的婚礼。

15 章 + 尾声，每章 8,000–16,000 字（写作目标，不是验收指标）。初稿齐全，处于审校阶段。

## 红线（不可协商）

1. 花神诞祭是共享梦境，不是时间循环；妮露是梦境主体。
2. 神像复活是唯一特例：纳西妲感知/上报、若娜瓦按天理规则借命。不是通用复活术，不是纳西妲的能力；妮露不知道神像能做什么。
3. 女主真的死：不复活、不转生、不变系统/神明；死亡期间不写主观感受。
4. 女主对三人没有浪漫箭头；三人是无性浪漫；帕丽莎是新花灵，不是人类婴儿/女主转世。
5. 枫丹线：林尼是 B 线，不改 4.0/4.1 canon；林尼不知道穿越与死期、不出席婚礼；不写公子神之眼；公子不洗白；琳妮特不是情敌；阿蕾奇诺不洗白也不纯恶化。
6. 婕德线按 canon BE。艾方索（维摩庄）是第一次杀人，阿迪勒是第二次。
7. 林晚的知识截止 5.8 前瞻；6.6 不写、不引用、不矛盾。
8. 提瓦特正文不写年份/月份/季节，只用“第 X 天”“3.x 节点”。“第 X 天”= 到提瓦特的第 X 天（第 1 天 = 穿越日，花神诞祭 = 第 11 天，梦 = 第 12–35 天）；死亡 2027-04-30，婚礼 05-01。日常多用相对时间（D78）。
9. 荧只知道游戏存在、不玩、不主动看 3.0 后剧情；不知道 2026 年战况的是林晚。
10. 只写 3.0 这一次花神诞祭。
11. 全文引号用“”，嵌套用‘’；只有说明这条规定的文字本身保留「」。
12. PG-13：不写性/身体细节；纳西妲不幼态化；不消费死者；女主不说脏话。方位：雨林在千壑沙地以东，“北方人”只指愚人众。

## 工作流

1. **考据**：官方任务文本/角色故事/官方 PV > BWIKI/HoYoWiki/Project Amber。关键设定记来源。
2. **判 canon/AU**：偏离官方的地方登记到 `docs/05` 的 AU 表，写理由。
3. **本章卡**：确认本章目标、beat、本章特有的坑；卡里不复述 `docs/03/05` 的内容。
4. **写/改**：一次一章，不跳场景；canon 只写女主视角的增量，不复述任务流程。
5. **剧情逻辑核实（第一优先）**：因果链、动机、谁知道什么、时间地点、伤势、道具、承诺；断裂先改结构，不先润色。
6. **声音校对（按需）**：只在明显漂移时做，不数指标。
7. **交稿清单**：`docs/06` §十。
8. **提交**：见下。

## 文档规则（防止冗余再积累）

- **文档只记约束，不记文本**：行号、字数、正文引句、逐条改动清单只进 commit message，不进 docs。
- **历史进 git**：文档里不写日期式日志、不维护追加式“当前状态”；进度只改 `docs/10` 顶部进度表（覆盖式）。
- **不复制 SSOT**：派生文档写“见 `docs/0X` §Y”，不重述。
- **新决策**：`docs/07` 加一行（决定 + 一句理由 + 影响范围）；长论证进 commit message。
- **每章收尾（蒸馏）**：账本覆盖式更新（≤800 字）→ 卡标记状态、删掉已实现的写法提示 → 决策条目按需标“已实现”。
- **预算**：本文件 ≤6k 字，`docs/06` ≤8k，每张卡 ≤3k，每章账本 ≤800。超了就删。
- **改设定/大改**：`tools/refs.ps1 <关键词|D编号>` 找引用 → 只改会被误导处 → `tools/docs-lint.ps1`。

## 工具调用

- 多个独立调用放同一条消息；一个失败不影响同批其他调用。
- 同一文件的多处独立改动，一次发出多个 `edit`；改完统一跑一次校验。
- 文本为 UTF-8；读文件用 read 工具（不用 cat/head/sed），搜索用 grep/glob。
- 子代理只在能省 token 且保质量时用；派发后不轮询，结束会自动唤醒。`.agents/` 下是会话模板，按需加载。

## Git

- 提交前 `git status --short`；只 `git add` 本项目目录内的文件。
- 提交信息：`[docs]` / `[ch05]` / `[fix]` + 一句话；改动细节写在提交正文——**这就是项目的变更日志**。
- 要改的文件已有未提交修改 → 先提醒用户。
- 不 force push，不 reset 用户改动。git 权限报错直接请用户授权，不用底层命令绕过。
