# 借来的花神诞祭

> 一个关于借来的生命、未被官方记录幸福的故事。

## 一句话

22 岁的国贸毕业生、深渊主播穿越成《原神》的荧，在提瓦特生活一年零九个月，把妮露、纳西妲、芙宁娜送到彼此身边；穿越结束那天，她回到现实世界死去，而原版荧回到提瓦特，赶上三人的婚礼。
