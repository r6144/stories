# 借来的花神诞祭

> 一个关于借来的生命、未被官方记录幸福的故事。

《原神》同人长篇。22 岁的国贸毕业生、深渊主播，在 5.8 前瞻次日穿越成荧，在提瓦特生活一年零九个月，把妮露、纳西妲、芙宁娜送到彼此身边；穿越结束那天她回到现实世界死去，而原版荧回到提瓦特，赶上三人的婚礼。

15 章 + 尾声，每章 8,000–16,000 字。
